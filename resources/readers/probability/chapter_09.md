# 6.3 算法类题目


## 6.3.1 计算滚动平均值与方差


给定一个按时间顺序持续到来的数据流 $`\{x_t\}`$，在每次新数据到来时，需要实时更新最近 $`N`$ 个数据的滚动均值与方差。要求单次更新时间复杂度尽量低。

解答 使用固定长度为 $`N`$ 的滑动窗口，并维护以下两个量：
``` math
S_t = \sum_{i=t-N+1}^{t} x_i, \quad Q_t = \sum_{i=t-N+1}^{t} x_i^2.
```

当新数据 $`x_{t+1}`$ 到来，最旧数据 $`x_{t-N+1}`$ 被移出窗口时，做增量更新：
``` math
S_{t+1} = S_t - x_{t+1}, \quad Q_{t+1} = Q_t - x_{t+1}^2.
```

当新数据 $`x_{t+1}`$ 到来，最旧数据 $`x_{t-N+1}`$ 被移出窗口时，做增量更新：
``` math
S_{t+1} = S_t - x_{t+1} - x_{t-N+1}, \quad Q_{t+1} = Q_t - x_{t+1}^2 - x_{t-N+1}.
```

那么滚动增长值为
``` math
\mu_{t+1} = \frac{S_{t+1}}{N}.
```


## 6.3.2 计算滚动最大值


> 给定一个按时间顺序持续到来的数据流 $`\{x_t\}`$，在每次新数据到来时，需要实时更新最近 $`N`$ 个数据的最大值。要求单次更新时间复杂度尽量低。

**解答.** 维护一个双端队列 $`D`$，队列中存放候选最大值的下标，且对应值单调不增：

``` math
x_{D_1} \geq x_{D_2} \geq \cdots
```

并保证队首下标始终落在当前窗口 $`[t-N+1, t]`$ 内。\
更新规则如下，当新区元素 $`x_t`$ 到来时：

1.  弹出过期元素：若队首下标 $`D_1 < t - N + 1`$，则从队首弹出，直到队首在窗口内。

2.  维护单调性：从队尾开始，若队尾 $`x_{D_{back}} \leq x_t`$，则队尾弹出；重复直到队尾对应值 $`> x_t`$ 或队列为空。

3.  加入新元素：将下标 $`t`$ 入队尾。

4.  输出答案：当前窗口最大值为：

``` math
m_t = x_{D_{back}}
```

队列从队尾对应值单调不增，因此队首元素始终是当前窗口内所有候选的最大值。所有比新区元素大（或相等）的旧元素在队尾中不可能成为最大值，故可安全从队尾删除。

复杂度分析：每个下标至多入队一次，出队一次，因此对长度上界固定的序列，每次更新的时间复杂度为 $`O(1)`$。

1.  初始化:

``` math
peak \leftarrow p_1, \quad MDD \leftarrow 0.
```

1.  对 $`t = 2, 3, \ldots, n`$ 依次执行:

    - 若 $`p_t > peak`$，则更新
      ``` math
      peak \leftarrow p_t;
      ```

    - 否则计算当前回撤
      ``` math
      d_t = \frac{peak - p_t}{peak},
      ```
      并更新
      ``` math
      MDD \leftarrow \max(MDD, d_t).
      ```

复现度分析: 算法仅需一次遍历，时间复杂度为 $`O(n)`$，只使用常数个辅助变量，空间复杂度为 $`O(1)`$。

值得注意的是，把价格序列记为 $`p`$，最大回撤可以更简洁地表示为:
``` math
MDD = (p.cummax() / p - 1) \cdot cummax().
```


## 6.3.4 计算第二大回撤


给定价格序列 $`p_1, p_2, \ldots, p_n`$，请给出计算第二大回撤且时间复杂度为 $`O(n)`$ 的算法，注意其中第二大回撤的时间段不能与最大回撤的重合。

1.  初始化:

``` math
H \leftarrow p_1, \quad segMin \leftarrow p_1, \quad segDD \leftarrow 0,
```
``` math
best_1 \leftarrow 0, \quad best_2 \leftarrow 0.
```

1.  对 $`t = 2, 3, \ldots, n`$ 依次执行:

- 若 $`p_t > H`$ (出现新高, 阶段结束), 则

  用 $`segDD`$ 更新 $`best_1, best_2`$,

  即保持 $`best_1 \geq best_2`$ 为当前最大的两个阶段回报; 随后令

  ``` math
  H \leftarrow p_t, \quad segMin \leftarrow p_t, \quad segDD \leftarrow 0.
  ```

- 若 $`p_t \leq H`$ (仍在当前阶段), 则

  ``` math
  segMin \leftarrow \min(segMin, p_t),
  ```
  ``` math
  segDD \leftarrow \frac{H - segMin}{H}.
  ```

1.  扫描结束后, 用最后一段的 $`segDD`$ 再更新一次 $`best_1, best_2`$.

2.  输出:

最大回报 $`= best_1,`$\
第二大回报 (不重合) $`= best_2.`$

复杂度分析: 算法仅对序列进行一次线性扫描, 每一步为常数时间操作, 时间复杂度为 $`O(n)`$; 只使用有穷个辅助变量, 空间复杂度为 $`O(1)`$.
