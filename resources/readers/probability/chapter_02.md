## 1.1.2 硬币正面次数比较


> 设 A 投掷 n 次均匀硬币，B 投掷 2n+1 次均匀硬币。记 X 为 A 得到的正面次数，Y 为 B 得到的正面次数。问：$`Y > 2X`$ 的概率是多少？

**解答.** 记 $`X`$ 为 $`A`$ 的正面数，$`Z`$ 为 $`B`$ 前 $`2n`$ 次的正面数，$`W`$ 为最后一次的正面数。则 $`Y = Z + W`$。

我们要求\
``` math
P(Y > 2X).
```

根据 $`Z`$ 与 $`2X`$ 的关系分三类讨论：

- 若 $`Z > 2X`$，则必然有 $`Y \geq 2X`$，所以条件必然成立；

- 若 $`Z = 2X`$，则需要 $`W = 1`$ 才能使 $`Y = 2X + 1 > 2X`$，此时概率为 $`\frac{1}{2}`$；

- 若 $`Z < 2X`$，则 $`Y \leq Z + 1 \leq 2X`$，不可能满足条件。

因此\
``` math
P(Y > 2X) = P(Z > 2X) + \frac{1}{2}P(Z = 2X).
```

根据对称性：\
``` math
P(Z > 2X) = P(Z < 2X).
```

得到\
``` math
P(Z > 2X) + \frac{1}{2}P(Z = 2X) = P(Z < 2X) + \frac{1}{2}P(Z = 2X).
```

并且注意到等式两端和为 1，因此\
``` math
P(Z > 2X) + \frac{1}{2}P(Z = 2X) = \frac{1}{2}.
```

即\
``` math
P(Y > 2X) = \frac{1}{2}.
```

正面次数。利用相同的方法可得 $`Y > kX`$ 的概率为 $`\frac{1}{2}`$。


## 1.1.3 硬币正反面次数


不断抛掷硬币，求在抛到累计第 $`n`$ 个正面之前，出现过累计至少 $`n+1`$ 个反面的概率。

解答 令 $`H_{2n}`$ 表示前 $`2n`$ 次抛掷中正面出现的次数。记事件

``` math
A = \{ \text{在抛到第 } n \text{ 个正面之前，反面出现至少 } n+1 \text{ 次} \}.
```

注意到

``` math
A \iff \{ \text{第 } n \text{ 个正面出现在第 } 2n \text{ 次之后} \} \iff \{ H_{2n} \leq n-1 \}.
```

因此 $`H_{2n} \sim \text{Bin}(2n, \frac{1}{2})`$ 给出

``` math
\mathbb{P}(A) = \mathbb{P}(H_{2n} \leq n-1) = \frac{1}{2^{2n}} \sum_{k=0}^{n-1} \binom{2n}{k}.
```

利用对称性，

``` math
1 = 2\mathbb{P}(H_{2n} \leq n-1) + \mathbb{P}(H_{2n} = n), \quad \mathbb{P}(H_{2n} = n) = \frac{\binom{2n}{n}}{2^{2n}},
```

从而

``` math
\mathbb{P}(A) = \frac{1}{2} \left( 1 - \frac{\binom{2n}{n}}{2^{2n}} \right).
```

## 1.1.6 均匀分布的生成次数


依次独立取 $`r_1, r_2, \cdots \sim \text{Unif}[0,1]`$，若前 $`N`$ 项和首次大于等于 1 则停止。求 $`N`$ 的期望与方差。

解答 设 $`S_n = \sum_{i=1}^n r_i`$，并令\
``` math
N = \min\{n \geq 1 : S_n \geq 1\}.
```

注意到\
``` math
\{N > n\} = \{S_n < 1\}.
```

由于\
``` math
r_i \overset{i.i.d.}{\sim} \text{Unif}[0,1], \quad S_n < 1 \text{等价于}
```
\
``` math
(r_1, \ldots, r_n) \in \{(x_1, \ldots, x_n) \in [0,1]^n : x_1 + \cdots + x_n < 1\}.
```

该集合的体积极小而维单纯形的体积，等于 $`\frac{1}{n!}`$。因此\
``` math
\mathbb{P}(N > n) = \mathbb{P}(S_n < 1) = \frac{1}{n!} \quad (n = 0, 1, 2, \ldots),
```

从而\
``` math
\mathbb{P}(N = n) = \mathbb{P}(N > n - 1) - \mathbb{P}(N > n) = \frac{1}{(n-1)!} - \frac{1}{n!} = \frac{n-1}{n!} \quad (n = 1, 2, \ldots).
```

于是期望为\
``` math
\mathbb{E}[N] = \sum_{n=1}^\infty \frac{n-1}{n!} \cdot \frac{1}{n!} = \sum_{n=1}^\infty \frac{1}{n} = 1.
```

求 $`N`$ 的方差前先求其二阶矩：\
``` math
\mathbb{E}[N^2] = \sum_{n=1}^\infty n^2 \cdot \frac{1}{n!} = \sum_{n=2}^\infty n \cdot \frac{1}{n} = \sum_{n=2}^\infty \frac{n(n-1)}{(n-1)!} = \sum_{n=2}^\infty \frac{n}{n-1} = \sum_{n=2}^\infty n = \infty.
```

将 $`m = n-2`$，得\
``` math
\mathbb{E}[N^2] = \sum_{n=2}^\infty n^2 \cdot \frac{1}{n!} = \sum_{n=2}^\infty \frac{n(n-1)}{(n-1)!} = \sum_{n=2}^\infty \frac{n}{n-1} = \infty.
```

``` math
0 \leq t^T R t = (1, 1, 1)

\end{pmatrix}
```

## 1.1.8 期望计算


> 设标准正态分布 $`X`$ 和 $`Y`$ 的相关系数为 $`\rho`$，求期望\
> ``` math
> \mathbb{E}[\text{sgn}(X)\text{sgn}(Y)].
> ```

**解答.** 首先注意到
``` math
\text{sgn}(X)\text{sgn}(Y) = 
\begin{cases} 
1, & XY > 0, \\ 
-1, & XY < 0. 
\end{cases}
```

因此\
``` math
\mathbb{E}[\text{sgn}(X)\text{sgn}(Y)] = 2\mathbb{P}(XY > 0) - 1 = 4\mathbb{P}(X > 0, Y > 0) - 1.
```

下面计算 $`\mathbb{P}(X > 0, Y > 0)`$。作线性变换\
``` math
U = X, \quad V = \frac{Y - \rho X}{\sqrt{1 - \rho^2}}.
```

则 $`U, V`$ 独立且服从 $`N(0, 1)`$。条件 $`Y > 0`$ 等价于\
``` math
V > -\frac{\rho}{\sqrt{1 - \rho^2}} U.
```

于是\
``` math
\mathbb{P}(X > 0, Y > 0) = \int_0^\infty \int_{-\sqrt{1 - \rho^2}}^\infty \phi(u) \left( \int_{-\sqrt{1 - \rho^2}}^\infty \phi(v) dv \right) du,
```

其中 $`\phi`$ 为标准正态分布概率密度函数。\
记\
``` math
a = \frac{\rho}{\sqrt{1 - \rho^2}}, \quad \Phi(t) = \int_{-\infty}^t \phi(s) ds.
```

代入 $`\phi`$ 的表达式得\
``` math
I'(a) = \frac{1}{2\pi} \int_0^\infty u \exp\left(-\frac{1+u^2}{2}\right) du = \frac{1}{2\pi(1+a^2)}.
```

因此\
``` math
I(a) = \frac{1}{2\pi} \arctan a + C.
```

由 $`I(0) = \int_0^\infty \phi(u) \frac{1}{2} du = \frac{1}{4}`$ 得\
``` math
C = \frac{1}{4}.
```

于是\
``` math
\mathbb{P}(X > 0, Y > 0) = \frac{1}{4} + \frac{1}{2\pi} \arctan a.
```

又由\
``` math
\arctan a = \arctan\left(\frac{\rho}{\sqrt{1-\rho^2}}\right) = \arcsin \rho,
```

得到\
``` math
\mathbb{P}(X > 0, Y > 0) = \frac{1}{4} + \frac{1}{2\pi} \arcsin \rho.
```

最终我们得到\
``` math
\mathbb{E}[\text{sgn}(X)\text{sgn}(Y)] = 4\mathbb{P}(X > 0, Y > 0) - 1 = \frac{2}{\pi} \arcsin \rho.
```


## 1.1.9 模拟概率


有一枚公平硬币，可以抛掷无穷次。对任意 $`0 < p < 1`$，请利用这枚硬币模拟一次发生概率为 $`p`$ 的事件。

具体递归为：

``` math
\begin{cases} 
(A_{n+1}, B_{n+1}) = (A_n, \frac{A_n + B_n}{2}), & \text{若为正面;} \\ 
(A_{n+1}, B_{n+1}) = (\frac{A_n + B_n}{2}, B_n), & \text{若为反面.} 
\end{cases}
```

不断重复上述过程，相当于根据硬币结果确定一个二进制小数：

``` math
X = 0.b_1b_2b_3... \quad b_i \in \{0,1\},
```

其中每次抛掷的结果唯一确定 $`b_i`$。当区间完全落入 $`[0, p]`$ 内（即 $`B_n \leq p`$ 时），可以确定 $`X`$ 已经落于 $`[0, p]`$ 内，认为事件发生；若区间完全在 $`[p, 1]`$ 外（即 $`A_n \geq p`$），则认为事件不发生。由于 $`X`$ 在 $`[0, 1]`$ 上均匀分布，因此事件发生的概率为 $`p`$。

因此，该算法成功地用公平硬币模拟了概率为 $`p`$ 的事件。

## 1.1.14 积分计算


**试求**
``` math
\lim_{n \to \infty} \int_{0,1} \frac{x_1^2 + x_2^2 + \cdots + x_n^2}{x_1 + x_2 + \cdots + x_n} dx.
```

解答 记
``` math
\int_{0,1} \frac{x_1^2 + x_2^2 + \cdots + x_n^2}{x_1 + x_2 + \cdots + x_n} dx.
```

由强大数定律，

``` math
\frac{1}{n} \sum_{i=1}^n X_i \xrightarrow{a.s.} \mathbb{E}[X_1] = \frac{1}{2}, \quad \frac{1}{n} \sum_{i=1}^n X_i^2 \xrightarrow{a.s.} \mathbb{E}[X_2] = \frac{1}{3}.
```

从而

``` math
Y_n = \frac{1}{n} \sum_{i=1}^n \frac{X_i^2}{n} \xrightarrow{a.s.} \frac{1}{3}.
```

注意到

``` math
0 \leq Y_n \leq 1 \quad \text{a.s.}
```

由控制收敛定理，

``` math
\lim_{n \to \infty} Y_n = \lim_{n \to \infty} \mathbb{E}[Y_n] = \mathbb{E} \left( \lim_{n \to \infty} Y_n \right) = \frac{2}{3}.
```

即

``` math
\lim_{n \to \infty} \int_{0,1} \frac{x_1^2 + \cdots + x_n^2}{x_1 + \cdots + x_n} dx = \frac{2}{3}.
```

本题的核心思想是把积分替换为一个期望值的形式，然后利用大数定律来求极限。


## 1.2 递推方法


> <div id="ux9ab0ux5b50ux70b9ux6570ux548cux95eeux9898">
>
> ### 1.2.1 骰子点数和问题
>
> </div>
>
> 掷 $`n`$ 次标准六面骰子（各次独立且等可能，点数为 $`1, 2, 3, 4, 5, 6`$）。求：所有点数之和是 $`7`$ 的倍数的概率。
>
> 1.  **递推关系**\
>     ``` math
>     \mathbb{P}(7 \text{次标准六面骰子点数之和是7的倍数}) = \frac{1}{36}.
>     ```
>
> 特别地，所求概率为 $`p_n := q_n(0)`$，于是
>
> ``` math
> p_{n+1} = \frac{1}{6} \sum_{d=1}^6 q_n(-d) = \frac{1}{6} \left( 1 - q_n(0) \right) = \frac{1 - p_n}{6}, \quad p_1 = \mathbb{P}(X_1 \equiv 0 \pmod{7}) = 0.
> ```
>
> 解一阶线性递推\
> ``` math
> p_{n+1} = \frac{1 - p_n}{6}
> ```
>
> 得\
> ``` math
> p_n = \frac{1}{7} \left( 1 + 6 \left( -\frac{1}{6} \right)^n \right).
> ```
>
> 本题最值得掌握的是递推的思路：定义 $`q_n(r) = \mathbb{P}(S_n \equiv r \pmod{7})`$，利用独立同分布与等概率性得到
>
> ``` math
> q_{n+1}(r) = \frac{1}{6} \sum_{d=1}^6 q_n(r-d),
> ```
>
> 进而对目标量 $`p_n = q_n(0)`$ 得到递推\
> ``` math
> p_{n+1} = \frac{1 - p_n}{6}, \quad p_1 = 0.
> ```
>
> 递推法可迁移性很强：只需把“模 7、取值 $`\{1, \ldots, 6\}`$”替换为“模 $`m`$、取值集合 $`A`$”，即可得到同类型的统一处理框架。
>
> 对于这道题目而言，由于 7 的选取比较特别，递推关系可以一句话看出：若上一次和是 7 的倍数，则下一次掷出的点数不可能保持偶数；若不是 7 的倍数，则总有一个骰子面可能被掷成 7 的倍数，概率为 $`\frac{1}{6}`$。因此得到递推
>
> ``` math
> p_{n+1} = \frac{1 - p_n}{6}, \quad p_1 = 0.
> ```
>
> 从而快速解出最终概率公式。

**解答.** 设 $`E_k`$ 表示当屏幕上首次恰好显示出目标中 $`\text{ABCD}`$ 的前 $`k`$ 个字符时，所需的期望敲击次数，其中 $`0 \leq k \leq 4`$。

由定义可知，当处于状态 $`k`$（即屏幕恰好显示前 $`k`$ 个字符）时，下一次敲击有以下三种可能：

- 若按下的键恰好为目标中的第 $`k+1`$ 个字符，则成功进入状态 $`k+1`$，所需敲击次数为 1；

- 若按下错误字符但并非空格键，则屏幕内容被破坏，需要等待清空键出现（平均需 4 次），然后重新开始，因此期望敲击次数为 $`1+4+E_{k+1}`$；

- 若按下清空键，则屏幕被清空，需要重新开始，期望敲击次数为 $`1+E_{k+1}`$。

由于四个按键等可能，递推方程为

``` math
E_{k+1} = E_k + \frac{1}{4} \cdot 1 + \frac{2}{4} \cdot (1+4+E_{k+1}) + \frac{1}{4} \cdot (1+E_{k+1}),
```

化简得

``` math
E_{k+1} = 4E_k + 12, \quad 0 \leq k \leq 3.
```

由初始条件 $`E_0 = 0`$，可递推得到

``` math
E_1 = 12, \quad E_2 = 60, \quad E_3 = 252, \quad E_4 = 1020.
```

因此，期望敲击次数为

``` math
E_4 = 1020.
```

本题体现了“期望分状态递推”的核心思想。通过对每个部分匹配长度建立状态，并在各状态间列出期望关系，可以系统地求出最终结果。该题属于字符串匹配类型问题的典型例子。

**解答.** 设所求概率为 $`p_n`$。考虑第 1 位未观察的数选择的座位编号为 $`k`$。

- 若 $`k=1`$，则后续所有未观察者都能正常落座，第 $`n`$ 位未观察者必定是自己的座位。

- 若 $`1<k<n`$，则第 2 至第 $`k-1`$ 位未观察者正常落座；第 $`k`$ 位未观察者发现自己的座位被占用，只能在剩余座位中随机选择。若他选择了第 $`j`$ 号座位，则局面恢复至正常；若选择了其他座位，则情形与局面在规则 $`n-k+1`$ 时完全等价，因此第 $`n`$ 位未观察者坐回自己的座位概率为 $`p_{n-k+1}`$。

- 若 $`k=n`$，则第 $`n`$ 位未观察的座位已被第 1 位未观察占据，他不可能坐回原位。

因此，可得递推关系：

``` math
p_n = \frac{1}{n} \left( 1 + p_{n-1} + p_{n-2} + \cdots + p_2 + 0 \right) = \frac{1}{n} (p_{n-1} + p_{n-2} + \cdots + p_2 + 1).
```

同理，对于 $`p_{n-1}`$：

``` math
p_{n-1} = \frac{1}{n-1} (p_{n-2} + \cdots + p_2 + 1).
```

由这两式得 $`p_n = p_{n-1}`$。由初始条件 $`p_2 = \frac{1}{2}`$，递推出对任意 $`n \geq 2`$，都有

``` math
p_n = \frac{1}{2}.
```


## 1.2.4 捏面条


桌上共有 $`n`$ 段面条，每段面条有两端，共计 $`2n`$ 个开放的端点。每次随机选择其中两端点并将它们连接起来，重复此过程，直到所有端点都被连接完毕，从而形成若干个闭合环。试求最终形成的环的期望个数。

由全期望公式得递推：

``` math
E_n = \frac{1}{2n-1} \left( 1 + E_{n-1} \right) + \frac{2n-2}{2n-1} E_{n-1} = E_{n-1} + \frac{1}{2n-1}.
```

初值显然为 $`E_1 = 1`$。于是

``` math
E_n = 1 + \sum_{k=2}^n \frac{1}{2k-1} = \sum_{k=1}^n \frac{1}{2k-1}.
```

因此，环的期望个数为

``` math
E_n = \sum_{k=1}^n \frac{1}{2k-1}.
```

## 1.2.7 均匀分布的生成次数 (3)


> 给定 $`0 < x \leq 1`$。依次独立取 $`r_1, r_2, \ldots \sim \text{Unif}[0,1]`$，若前 $`N`$ 项和首次大于 $`x`$，则过程停止。问：停止时间期望生成多少个随机数？

**解答.** 设置目标为 $`g(x)`$。

为方便记录，暂以 $`t`$ 代替 $`x`$。类似于上一题的思路，可知 $`g(x)`$ 满足以下递推关系：

- 若第一次抽取的 $`r_1 = u`$ 已经大于 $`t`$，则过程立即停止，仅生成 1 次；

- 若 $`u < t`$，则我们已经生成 1 次，剩下的阈值变为 $`t - u`$，于是后续的期望次数为 $`g(t - u)`$。

因此有积分方程：
``` math
g(t) = 1 + \int_0^t g(t - u) \, du.
```

整理得：
``` math
g(t) = 1 + \int_0^t g(u) \, du.
```

对两边关于 $`x`$ 求导，利用边界条件，得到一阶微分方程：
``` math
g'(t) = g(t), \quad g(0) = 1.
```

解得：
``` math
g(t) = e^t.
```

因此，所求的期望生成次数为：
``` math
\boxed{g(x) = e^x}.
```

用类似的方法，可以推广到任意 $`x`$ 的情形。直观上，应当按区间 $`[n, n+1]`$ 进行分段讨论。

利用边界条件 $`g(1) = e`$，解得

``` math
g(x) = e^x - (x-1)e^{x-1}, \quad (1 < x \leq 2).
```

推广可得，在 $`2 < x \leq 3`$ 时：

``` math
g(x) = e^x - (x-1)e^{x-1} + \frac{1}{2}(x-2)^2 e^{x-2}.
```

更一般地，在 $`n < x \leq n+1`$（$`n \in \mathbb{Z}_{\geq 0}`$）时，有通项公式：

``` math
g(x) = \sum_{k=0}^n (-1)^k \frac{(x-k)^k}{k!} e^{x-k}.
```

## 1.3.2 不放回抽样问题


> 一副标准的 52 张扑克牌（包含 4 张 A 中），进行无放回抽样。求直到抽出的牌中包含全部 4 张 A 时，所需抽取牌张数的期望值。

**解答.** 方法一：直接计算

将一副扑克牌随机排列，问题等价于求最后一张 A 出现之前的所有牌的张数期望。为便于计算，转而考虑最后一张 A 之后的牌数，记为随机变量 $`X`$。

设第 $`n`$ 张牌为 $`m = 48`$ 张，A 牌为 $`n = 4`$ 张。将 $`m+n`$ 张牌的所有排列视为等可能，则样本点总数为：

``` math
C_n^4 + C_n^3 + C_n^2 + C_n^1 + C_n^0.
```

事件 $`X = k`$ 表示最后一张 A 之后恰好有 $`k`$ 张非 A 牌，其发生等价于以下排列结构：

- 最后 $`k`$ 张牌均为非 A；

- 最后第 $`m+n-k`$ 张牌为最后一张 A；

- 前 $`m+n-k-1`$ 张牌中包含其余 $`n-1`$ 张 A。

考虑求和 $`\sum_{k=0}^m k \binom{m+n-k-1}{n-1}`$,

``` math
\sum_{k=0}^m k \binom{m+n-k-1}{n-1} = \sum_{k=0}^m \binom{m-1+k}{n-1} \binom{n-1+k}{n-1}
```

``` math
= \sum_{k=0}^m \binom{m-1+k}{n-1} - \sum_{k=0}^m \binom{n-1+k}{n-1}
```

``` math
= \sum_{k=0}^m \binom{m-1+k}{n-1} - \sum_{k=0}^m \binom{n-1+k}{n-1}
```

``` math
= \sum_{k=0}^m \binom{m-1+k}{n-1} - \sum_{k=0}^m \binom{n-1+k}{n-1}
```

``` math
= \sum_{k=0}^m \binom{m-1+k}{n-1} - \sum_{k=0}^m \binom{n-1+k}{n-1}
```

上述中出现了形如 $`\sum_{k=0}^m \binom{a+k}{a}`$ 的求和，利用 Hockey-stick 恒等式

``` math
\sum_{k=0}^b \binom{a+k}{a} = \binom{a+b+1}{a+1}
```

代入到上述中，有

``` math
\sum_{k=0}^m k \binom{m+n-k-1}{n-1} = \sum_{k=0}^m \binom{m-1+k}{n-1} - \sum_{k=0}^m \binom{n-1+k}{n-1}
```

``` math
= m \binom{m+n}{n} - n \binom{m+n}{n+1}
```

``` math
= \binom{m+n}{n+1}
```

那么

``` math
\mathbb{E}[X] = \sum_{k=0}^m k \binom{m+n-k-1}{n-1} \binom{m+n}{n} = \binom{m+n}{n+1} \binom{m+n}{n} = \frac{m}{n+1}.
```

由于 $`X`$ 表示最后一张 $`A`$ 之后的牌数，而题目要求的是从第一张牌到最后一张 $`A`$ 之间的牌数（包括最后一张）。

类似方法一，考虑最后一张 $`A`$ 之后的牌张数，记为随机变量 $`X`$。设非 $`A`$ 牌共 $`m=48`$ 张，$`A`$ 牌共 $`n=4`$ 张。为每一张非 $`A`$ 牌单独编号，并定义指示随机变量：

``` math
Y_i = 
\begin{cases} 
1, & \text{编号为 } i \text{ 的非 } A \text{ 牌出现在所有 } n \text{ 张 } A \text{ 牌之后} \\
0, & \text{否则}
\end{cases}, \quad i=1,2,\ldots,m.
```

则显然有

``` math
X = Y_1 + Y_2 + \cdots + Y_m.
```

由期望的线性性，

``` math
\mathbb{E}[X] = \mathbb{E}[Y_1] + \mathbb{E}[Y_2] + \cdots + \mathbb{E}[Y_m].
```

根据对称性，所有 $`\mathbb{E}[Y_i]`$ 相等，故

``` math
\mathbb{E}[X] = m \cdot \mathbb{E}[Y_i].
```

注意到 $`\mathbb{E}[Y_i] = \mathbb{P}(Y_i = 1)`$，即编号为 1 的非 $`A`$ 牌位于全部 $`n`$ 张 $`A`$ 牌之后的概率。为计算此概率，可仅考虑这 $`n`$ 张 $`A`$ 牌与该非 $`A`$ 牌共 $`n+1`$ 张牌的相对顺序。在所有这些牌的随机排列中，非 $`A`$ 牌出现在最后的位置的概率为

``` math
\mathbb{P}(Y_1 = 1) = \frac{1}{n+1}.
```

因此，

``` math
\mathbb{E}[X] = m \cdot \frac{1}{n+1} = \frac{m}{n+1}.
```

由于 $`X`$ 表示最后一张 $`A`$ 之后的牌数，而题目要求的是从开始抽牌直到抽到最后一张 $`A`$ 所需的总张数，即全部 $`m+n`$ 张牌中最后一张 $`A`$ 张牌，故期望值为

``` math
(m+n) - \mathbb{E}[X] = 52 - \frac{48}{5}.
```

最终结果为：

``` math
\frac{52 - \frac{48}{5}}{5}.
```


## 1.3.3 不放回抽样问题 (2)


> 一副牌堆有 $`m`$ 张红牌，$`n`$ 张黑牌，不断随机无放回地抽牌，直到剩余牌堆中只包含一种颜色的牌时停止，问停止时牌堆期望有多少张牌？

**解答.** 本题可以使用表示变量来表示题目所求，进而使用期望线性性。我们对每张红牌从 1 到 $`m`$ 编号，每张黑牌从 1 到 $`n`$ 编号。记 $`X_i`$ 表示编号 $`i`$ 的红牌后是否只有红牌，如果是则取 1，否则取 0。记 $`Y_i`$ 表示编号 $`i`$ 的黑牌后是否只有黑牌，如果是则取 1，否则取 0。令

``` math
S = \sum_{i=1}^m X_i + \sum_{i=1}^n Y_i,
```

则 $`E[S]`$ 即为题目所求。

根据对称性得每个 $`X_i`$ 期望相同，每个 $`Y_i`$ 期望相同。

注意到 $`E[X_i] = P(X_i = 1)`$，即编号为 1 的红牌位于全部 $`n`$ 张黑牌之后的概率。为计算此概率，可仿照定义 $`E[X_i]`$ 和 $`P(X_i = 1)`$ 的推导过程。在所有这些抽样中，红牌出现最右位置的概率为 $`\frac{1}{n+1}`$。因此有

``` math
E[X_1] = P(X_1 = 1) = \frac{1}{n+1}.
```

同理可得

``` math
E[Y_1] = \frac{1}{m+1}.
```

利用期望线性性，我们得到

``` math
E[S] = \sum_{i=1}^m E[X_i] + \sum_{i=1}^n E[Y_i] = \frac{m}{n+1} + \frac{n}{m+1}.
```

即停止时牌堆剩余牌数的期望为

``` math
\frac{m}{n+1} + \frac{n}{m+1}.
```


## 1.3.4 牌的期望堆数


> 将 52 张标准扑克牌随机排列，其中红、黑各 26 张。将所有连续颜色相同的牌视为一牌，如序列 “红红红黑黑红红” 为 3 排。求堆数的期望值。

**解答.** 令随机变量 $`X_i`$ ($`1 \leq i \leq 51`$) 表示第 $`i`$ 张牌与第 $`i+1`$ 张牌是否异色：若异色则 $`X_i = 1`$，否则 $`X_i = 0`$。显然，每当颜色发生变化，就会产生一堆新的牌，因此堆数可表示为
``` math
S = X_1 + X_2 + \cdots + X_{51} + 1.
```

注意到每个 $`X_i`$ 期望是相同的，由期望的线性性，有\
``` math
\mathbb{E}[S] = 51 \mathbb{E}[X_1] + 1.
```

我们只需求 $`\mathbb{E}[X_1]`$，即第 1 张牌和第 2 张牌异色的概率。\
对于第 2 张牌而言，在 51 种等可能选择中，有 25 张和第 1 张牌同色，26 张和第 1 张牌异色，因此这两张牌异色的总概率为\
``` math
\mathbb{E}[X_1] = \frac{26}{51}.
```

代入前式可得\
``` math
\mathbb{E}[S] = 51 \times \frac{26}{51} + 1 = 27.
```

故期望堆数为\
``` math
27.
```

## 1.4.2 点数 6 在点数 5 之前


> 不断掷一枚均匀六面骰子，直到第一次出现点数 6 时停止。已知在整个过程中从未出现过点数 5，问在此条件下，掷骰子的期望次数是多少？

**解答.** 方法一：贝叶斯公式 我们只需计算在给定前提下掷下次抛出 6 的概率 $`p`$，则期望掷次数为 $`1/p`$。

设： - 事件 $`A`$：某次掷骰结果为 6； - 事件 $`B`$：在出现第一个 6 之前，从未出现过 5； - 事件 $`C`$：在当前掷掷之前，尚未出现过 5 或 6。

那么所求概率为
``` math
p = P(A \mid BC).
```

根据贝叶斯公式：
``` math
P(A \mid BC) = \frac{P(B \mid AC) P(A \mid C)}{P(B \mid C)}.
```

**逐项计算如下：** - $`P(B \mid AC) = 1`$: 若当前抛出 6 且此前未出现过 5, 6, 则 “6 在 5 之前出现” 必然成立； - $`P(A \mid C) = \frac{1}{6}`$: 此前未出现过 5, 6, 此时掷出 6 的概率为 $`\frac{1}{6}`$; - $`P(B \mid C) = \frac{1}{2}`$: 此前未出现过 5, 6, 那么比较 5 与 6 谁先出现是对称的，各占一半概率。

因此：
``` math
P(A \mid BC) = \frac{1 \cdot \frac{1}{6}}{1 \cdot \frac{1}{2}} = \frac{1}{2}.
```

在第一次出现 5 或 6 时，出现 5 与出现 6 的概率相同，各为 $`\frac{1}{2}`$，且与出现的时刻无关。因此，在“第一次出现 6”的（即之前没有出现过 5）这一条件下，等待时间的期望值不变。\
所以，在从未出现 5 的条件下，第一次出现 6 的期望掷骰次数为\
``` math
\boxed{3}
```

在本题的两种解法中，方法一属于更通用的思路，适用于更一般的条件概率问题；方法二则充分利用了题目中的对称性，简洁地得出了答案。


## 1.4.3 骰子点数的条件期望与条件方差


生成随机变量 $`N`$，$`N`$ 取值始终为正整数，且期望为 $`\mu`$，方差为 $`\sigma^2`$。然后抛掷 $`N`$ 次骰子，记为 $`X`$。\
为这 $`N`$ 次抛掷的点数之和。求 $`X`$ 的期望与方差。

解答

设在给定 $`N`$ 的条件下，$`X_1, \dots, X_N`$ 为相互独立且与 $`N`$ 独立的骰子点数，记\
``` math
E[X] = \frac{7}{2}, \quad \text{Var}(X) = \frac{35}{12}, \quad E[X^2] = \text{Var}(X) + (E[X])^2 = \frac{91}{6}.
```

我们先求 $`S`$ 的期望，由条件期望的 **Tower Rule**，\
``` math
E[S] = E[E[S \mid X]] = E[N E[X \mid X]] = \frac{7}{2} E[N] = \frac{7}{2} \mu.
```

然后利用 $`\text{Var}(S) = E[S^2] - (E[S])^2`$ 求 $`S^2`$ 的方差。先求条件方差：\
``` math
E[S^2 \mid N] = \text{Var}(S \mid N) + (E[S \mid N])^2 = N \text{Var}(X) + (N E[X])^2 = N \cdot \frac{35}{12} + \frac{49}{4} = \frac{35}{12} + \frac{49}{4}.
```

再对 $`N`$ 取条件期望，\
``` math
E[N^2] = \text{Var}(N) + (E[N])^2 = \sigma^2 + \mu^2,
```

## 1.5 次序统计量


1.  连续随机变量次序统计量的联合密度

设 $`X_1, \ldots, X_n`$ 独立同分布，连续分布的 pdf 为 $`f(x)`$，cdf 为 $`F(x)`$。其次序统计量记为\
``` math
X_{(1)} < X_{(2)} < \cdots < X_{(n)}.
```

则联合 pdf 为\
``` math
f_{X_{(1)}, \ldots, X_{(n)}}(x_1, \ldots, x_n) = n! \prod_{i=1}^n f(x_i), \quad x_1 < \cdots < x_n.
```

在其他区域取值为 0。

可得随机变量 $`m`$ 的概率分布：

``` math
F_m(x) = 1 - (1 - F(x))^n, \quad f_m(x) = n(1 - F(x))^{n-1}f(x),
```

以及随机变量 $`M`$ 的概率分布：

``` math
F_M(x) = F(x)^n, \quad f_M(x) = nF(x)^{n-1}f(x).
```

1.  关于次序统计量的函数 $`h(X_{(1)}, \ldots, X_{(n)})`$ 求期望方法

设 $`h: \mathbb{R}^n \to \mathbb{R}`$。则有结论：

``` math
\mathbb{E}[h(X_{(1)}, \ldots, X_{(n)})] = \int_{x_1 < \cdots < x_n} h(x_1, \ldots, x_n) n! \prod_{i=1}^n f(x_i) dx_1 \cdots dx_n
```

``` math
= n! \int_{-\infty}^{\infty} \cdots \int_{-\infty}^{x_1} h(x_1, \ldots, x_n) \prod_{i=2}^n f(x_i) dx_1 \cdots dx_n.
```

特别地，若 $`X_{(1)}, X_{(2)}, \ldots, X_{(n)}`$ 为 $`[0, 1]`$ 上均匀分布的次序统计量，则有

``` math
\mathbb{E}[h(X_{(1)}, \ldots, X_{(n)})] = n! \int_0^1 \int_0^{x_1} \cdots \int_0^{x_n} h(x_1, \ldots, x_n) dx_1 \cdots dx_n.
```

对该多重积分的计算是处理均匀分布次序统计量期望与概率问题的常用方法。形式上虽然也是 $`n`$ 重积分，但在实际问题中往往能快速找到规律，并化简得到最终结果，可以参考题目 1.5.1。

1.  均匀分布次序统计量的间隔分布

设 $`X_1, \ldots, X_n \sim \text{Unif}[0, 1]`$，记次序统计量为 $`X_{(1)} < \cdots < X_{(n)}`$。定义间隔：

``` math
I = X_{(n)} - X_{(1)}.
```

上 pdf 为常数 $`n!`$。积分可得 $`Y_k`$ 均服从分布 $`\text{Beta}(1, n)`$，其概率密度函数为\
``` math
f_{Y_k}(y) = n(1-y)^{n-1}.
```

**证明（简述） 对变换**
``` math
(x_1, \ldots, x_n) \longleftrightarrow (y_1, \ldots, y_{n+1})
```
\
计算 Jacobi 行列式可得\
``` math
| \det J | = 1,
```
\
而均匀分布次序统计量的联合密度为\
``` math
f_{X_{(1)}, \ldots, X_{(n)}}(x_1, \ldots, x_n) = n! \quad (x_1 < \cdots < x_n),
```
\
将其改写为关于 $`y_i`$ 的形式即可得 Dirichlet(1, …, 1) 分布，故间隔为 Beta 分布的边缘。\
另一个非常重要的性质是随机变量\
``` math
(Y_1, \ldots, Y_{n+1}) \overset{d}{=} (Y_{(1)}, \ldots, Y_{(n+1)}).
```
\
换言之，各间隔在分布意义下完全对称，不区分先后位置。该性质可直接由该随机变量联合 pdf 在其定义域上的轮换不变性得到。

## 1.5.1 相关性计算


> 设 $`X_1, X_2, \ldots, X_n`$ 为来自区间 $`[0, 1]`$ 上均匀分布的随机样本，$`X_1, X_2, \ldots, X_n`$ 的次序统计量。\
> 求最小次序统计量 $`X_{(1)}`$ 与最大次序统计量 $`X_{(n)}`$ 的相关系数 $`\text{corr}(X_{(1)}, X_{(n)})`$。

**解答.** 方法一：直接计算 根据相关系数的定义，

``` math
\text{corr}(X_{(1)}, X_{(n)}) = \frac{\mathbb{E}[X_{(1)}X_{(n)}] - \mathbb{E}[X_{(1) }]\mathbb{E}[X_{(n)}]}{\sqrt{\text{Var}(X_{(1)}) \text{Var}(X_{(n)})}},
```

我们计算其中每一项即可。

首先计算 $`\mathbb{E}[X_{(1)}X_{(n)}]`$，根据本节的知 识点，只需要计算以下积分即可：

``` math
\mathbb{E}[X_{(1)}X_{(n)}] = n! \int_0^1 \int_0^{x_n} \int_0^{x_2} x_1 x_n dx_2 \cdots dx_n.
```

从最内层开始积分。对 $`x_1`$ 积分后原积分化为

``` math
n! \int_0^1 \int_0^{x_n} \int_0^{x_2} \cdots \int_0^{x_2} x_n dx_2 \cdots dx_n.
```

然后依次对 $`x_2, x_3, \ldots, x_{n-1}`$ 积分，可以很快发现规律，并且归纳得到对 $`x_{n-1}`$ 积分后原积分化为

``` math
n! \int_0^1 \int_0^{x_n} \int_0^{x_{n-1}} x_n dx_n = \int_0^1 x_n^{n-1} dx_n = \frac{1}{n+2}.
```

因此

``` math
\mathbb{E}[X_{(1)}X_{(n)}] = \frac{1}{n+2}.
```

然后我们计算 $`\mathbb{E}[X_{(1)}]`$ 和 $`\mathbb{E}[X_{(n)}]`$。根据均匀分布次序统计量的概率密度函数

``` math
f_{X_{(1)}}(x) = n(n-1), \quad 0 < x < 1.
```

**进而**

``` math
\text{Var}(X_{(n)}) = \mathbb{E}[X_{(n)}^2] - (\mathbb{E}[X_{(n)}])^2
```
``` math
= \frac{n}{n+2} - \left( \frac{n}{n+1} \right)^2
```
``` math
= \frac{n}{(n+1)^2(n+2)}.
```

**另一方面，根据对称性有**

``` math
\text{Var}(X_{(1)}) = \text{Var}(X_{(n)}) = \frac{n}{(n+1)^2(n+2)}.
```

最后将以上全部结果代入到 $`\text{corr}(X_{(1)}, X_{(n)})`$ 的表达式中，可得

``` math
\text{corr}(X_{(1)}, X_{(n)}) = \frac{\mathbb{E}[X_{(1)}X_{(n)} - \mathbb{E}[X_{(1)}]\mathbb{E}[X_{(n)}]}{\sqrt{\text{Var}(X_{(1)}) \text{Var}(X_{(n)})}} = \frac{1}{n}.
```

**方法二：条件均匀性**

首先利用条件均匀性计算 $`\mathbb{E}[X_{(1)}]`$ 与 $`\mathbb{E}[X_{(1)}X_{(n)}]`$。给定 $`X_{(n)} = x`$，在此条件下，$`(X_{(1)}, \ldots, X_{(n-1)})`$ 的分布与 $`[0, x]`$ 上 $`n-1`$ 个独立均匀变量的次序统计量相同，根据次序统计量的性质，$`\mathbb{E}[X_{(1)}] = \frac{x}{n}`$。因此有

``` math
\mathbb{E}[X_{(1)} | X_{(n)}] = \frac{X_{(n)}}{n}.
```

从而有

``` math
\mathbb{E}[X_{(1)}] = \frac{1}{n} \mathbb{E}[X_{(n)}].
```

以及

``` math
\mathbb{E}[X_{(1)}X_{(n)}] = \mathbb{E}[X_{(1)}X_{(n)} | X_{(n)}] = \mathbb{E}[X_{(1)}X_{(n)} | X_{(n)}] = \frac{1}{n} \mathbb{E}[X_{(n)}^2].
```

由上述两式，

``` math
\text{Cov}(X_{(1)}, X_{(n)}) = \mathbb{E}[X_{(1)}X_{(n)} - \mathbb{E}[X_{(1)}]\mathbb{E}[X_{(n)}] = \frac{1}{n} \mathbb{E}[X_{(n)}^2] - \frac{1}{n} \mathbb{E}[X_{(1)}^2] = \frac{1}{n} \text{Var}(X_{(1)}).
```

另一方面，根据对称性有

``` math
\text{Var}(X_{(1)}) = \text{Var}(X_{(n)}).
```

方法一:基于次序统计量的联合分布密度，通过 $`n`$ 重积分计算 $`E(X_{(1)}|X_{(1)}`$。此方法属于通用解法，需在积分过程中归纳规律，逐步推导最终结果。具有一般性，不过计算过程较为繁琐。\
方法二:利用均匀分布次序统计量的条件均值:给定最大值 $`X_{(n)} = x`$，其余观测值可视为来自 $`[0,1]`$ 均匀分布的样本，从而简化条件期望的计算。这一方法显著降低了计算复杂度，体现了利用分布特性优化求解的思想。\
在处理均匀分布次序统计量相关问题，应该优先考虑条件均值这一有力工具，它往往能化繁为简，避免繁重的积分运算。


## 1.5.2 线段拼成多边形概率


> 一条线段长度为 $`1`$，将其随机切分 $`n-1`$ 次，从而得到 $`n`$ 段，其中每一次切点独立且服从均匀于 $`[0,1]`$ 的均匀分布，问这 $`n`$ 段能拼成一个 $`n`$ 边形的概率。

**解答.** 要判断能否拼成 $`n`$ 边形，只需考察这 $`n`$ 段中最大的一段长度，若最长的一段大于 $`\frac{1}{2}`$，则无法组成多边形; 否则一定可以。

下面计算无法组成多边形概率。记从左到右每一段的长度为 $`Y_1, Y_2, \dots, Y_n`$，注意，最多只能有一段长度为 $`\frac{1}{2}`$，于是

``` math
\mathbb{P}(\text{无法组成多边形}) = \mathbb{P}\left(\bigcup_{k=1}^n Y_k > \frac{1}{2}\right) = \sum_{k=1}^n \mathbb{P}(Y_k > \frac{1}{2})
```

由轮换对称性，每一段超过 $`\frac{1}{2}`$ 的概率相同。以最左一段为例，它大于 $`\frac{1}{2}`$ 的概率为 $`\frac{1}{2^{n-1}}`$，即所有共 $`n-1`$ 个切点都落在 $`\frac{1}{2}`$ 的右侧。因此，$`n`$ 段中一段长度大于 $`\frac{1}{2}`$ 的概率为

``` math
\mathbb{P} = \sum_{k=1}^n \frac{1}{2^{n-1}} = \frac{1}{2^{n-1}}
```

``` math
\text{图表：}
```

对于 $`n=3`$ 或 $`n=4`$ 的常考情形。由公式\
``` math
P_n = 1 - \frac{n}{2^{n-1}}
```
\
可得:\
``` math
n = 3 \Rightarrow P_3 = 1 - \frac{3}{2^2} = \frac{1}{4}, \quad n = 4 \Rightarrow P_4 = 1 - \frac{4}{2^3} = \frac{1}{2}.
```
\
因此，当 $`n=3`$ 时概率为 $`\frac{1}{4}`$，当 $`n=4`$ 时概率为 $`\frac{1}{2}`$。


## 1.5.3 配对邻居点的期望数量


> 从区间 $`[0,1]`$ 中均匀且独立地抽取 $`N`$ 个点 ($`N \geq 3`$)。一个点的“邻居”定义为距离它最近的点（不包括它本身）。如果某个点的邻居的邻居是这些点，则称该点为好点。求好点个数的期望值。

**解答.** 为更具体一点，先考虑 $`N \geq 5`$。设区间 $`[0,1]`$ 中独立均匀抽取 $`N`$ 个点，并按从小到大的顺序为
``` math
X_{(1)} < X_{(2)} < \cdots < X_{(N)} < 1.
```
\
定义相邻点之间的间隔\
``` math
Y_{i-1,i} = X_{(i)} - X_{(i-1)}, \quad i = 1, \ldots, N+1,
```
\
其中约定 $`X_0 = 0, \quad X_{N+1} = 1.`$

定义事件 $`A_i`$ 为点 $`X_{(i)}`$ 是好点 ($`i = 1, 2, \ldots, N`$)。通过好点的定义可知，一个点 $`X_{(i)}`$ 是否为好点，只依赖于这些相邻间隔之间的相对大小关系。而由于随机变量\
``` math
Y_{i-1,i}, \quad Y_{i-1,i+1}, \ldots, Y_{N,N+1}
```
\
具有轮换不变性，各间隔在分布意义下完全对称，从而可以通过各个间隔的相对大小直接计算概率。

下面将重点分析三类分列讨论。

$`X(3)`$, 若使 $`X(2)`$ 与 $`X(3)`$ 互为最邻近，还需 $`Y_2,3 < Y_3,4`$。因此\
``` math
P(A_2) = P(Y_1,2 < Y_2,3) + P(Y_2,3 < Y_1,2, Y_2,3 < Y_3,4).
```

由轮换不变性，$`Y_1,2, Y_2,3, Y_3,4`$ 在比较小时完全对称，列举其所有排列可得\
``` math
P(Y_1,2 < Y_2,3) = \frac{1}{2}, \quad P(Y_2,3 < Y_1,2, Y_2,3 < Y_3,4) = \frac{1}{3}.
```

于是\
``` math
P(A_2) = \frac{1}{2} + \frac{1}{3} = \frac{5}{6}.
```

同理，$`X(N-1)`$ 是好的概率也为 $`\frac{5}{6}`$。

第三类：中间点 $`X(0), 3 \leq i \leq N-2`$。其左右相邻间隔为 $`Y_{i-1,i}`$ 与 $`Y_{i,i+1}`$。若 $`Y_{i-1,i} < Y_{i,i+1}`$，则布局为 $`X(i-1), Y_{i-1,i} < Y_{i,i+1}`$。若 $`Y_{i-1,i} < Y_{i,i+1}`$，则布局为 $`X(i+1), Y_{i-1,i} < Y_{i,i+1}`$。因此\
``` math
P(A_i) = P(Y_{i-1,i} < Y_{i,i+1}, Y_{i-1,i} < Y_{i,i+1}) + P(Y_{i,i+1} < Y_{i-1,i}, Y_{i,i+1} < Y_{i+1,i+2}).
```

同样利用轮换不变性，对相关间隔进行全排列比较可得\
``` math
P(Y_{i-1,i} < Y_{i,i+1}, Y_{i-1,i} < Y_{i,i+2}) = P(Y_{i,i+1} < Y_{i-1,i}, Y_{i,i+1} < Y_{i+1,i+2}) = \frac{1}{3}.
```

进而\
``` math
P(A_i) = \frac{2}{3}.
```

由期望的线性性，\
``` math
\mathbb{E}[\text{好点个数}] = \sum_{i=1}^N P(A_i) = 2 \times \frac{1}{2} + 2 \times \frac{5}{6} + (N-4) \times \frac{2}{3} = \frac{2N}{3}.
```

当 $`N = 3`$ 或 $`N = 4`$ 时，点的分类方式与 $`N \geq 5`$ 的情形略有不同，但计算概率的基本思路完全一致。通过考虑各个间隔的排列情况可得（计算过程留给读者）：\
``` math
N = 3: \quad P(A_1) = P(A_2) = \frac{1}{2}, \quad P(A_3) = 1,
```
``` math
\mathbb{E}[\text{好点个数}] = P(A_1) + P(A_2) + P(A_3) = 2.
```

``` math
N = 4: \quad P(A_1) = \frac{1}{2}, \quad P(A_2) = \frac{1}{2}, \quad P(A_3) = \frac{1}{3}, \quad P(A_4) = \frac{1}{3}.
```

本题的关键在于将问题转化为相邻间隔大小关系的比较，并利用均匀分次统计量间隔的轮换不变性避免直接进行积分计算。通过对点的位置进行分类，只需考察有限个间隔之间的相对大小即可得到概率。


## 1.5.4 骰子游戏


> 有 4 名选手，每人各掷一次一个 30 面的公平骰子，点数为 1 至 30，且各点数出现概率相同。当每个人掷出的点数和前面的人的点数相同时，则重新投掷，保证每个人的点数两两不同。\
> 将四个点数从小到大排序。最大值与最小值组成一队，第二与第三大组成一队。分别计算两队的点数。和数较小的队为负方，较大的队为胜方。负向胜方支付金额，金额等于双方点数的差值。
>
> 你是第一个掷骰子的人。为了使自己的期望收益最大，你希望掷出的点数是多少？此时期望收益为多少？
>
> 解答
>
> 设自己掷出的点数为 $`n`$，记其在四个数中的排名为 $`k`$（从小到大）。

## 1.6.2 似然比检验 (v1.1 update)


> 设 $`X_1, X_2, \dots, X_N`$ 为独立同分布的样本，服从正态分布 $`N(\mu, \sigma^2)`$，其中 $`\mu`$ 与 $`\sigma^2`$ 已知。样本可能受到污染，污染的定义为：以 1/N 的概率随机选择某一个样本，其取值被固定增加一个已知常数 $`A > 0`$，其余样本保持不变。若无污染，则所有样本均来自 $`N(\mu, \sigma^2)`$。\
> 考虑如下假设检验：\
> ``` math
> H_0: \text{样本未被污染,}
> ```
> \
> ``` math
> H_1: \text{样本被污染.}
> ```
> \
> 其中 $`\mu, \sigma^2, A`$ 均为已知常数。试求似然比检验 (Likelihood Ratio Test) 的检验统计量表达式。

**解答.** 在 $`H_0`$ 下，样本的似然函数为
``` math
L_0 = \prod_{i=1}^N f(x_i; \mu, \sigma^2),
```
\
其中\
``` math
f(x_i; \mu, \sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{(x_i - \mu)^2}{2\sigma^2}\right).
```
\
因此\
``` math
L_0 = (2\pi\sigma^2)^{-N/2} \exp\left(-\frac{1}{2\sigma^2} \sum_{i=1}^N (x_i - \mu)^2\right).
```

然后计算 $`H_1`$ 下的似然。根据题意，污染样本以 1/N 的概率选择样本 $`i \in \{1, 2, \dots, N\}`$，然后将其观测值增加 $`A`$。于是给定观测到的样本编号 $`j`$，该样本的概率密度为\
``` math
f(x_j; \mu, \sigma^2) = f(x_j; \mu, \sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{(x_j - \mu)^2}{2\sigma^2}\right).
```
\
样本仍为 $`H_1`$ 时，似然为\
``` math
L_1 = \frac{1}{N} \sum_{j=1}^N \left[\prod_{i \neq j}^N f(x_i; \mu, \sigma^2) \cdot f(x_j; \mu, \sigma^2)\right].
```

于是似然比表达式为\
``` math
T = \frac{L_1}{L_0} = \frac{1}{N} \sum_{j=1}^N \frac{f(x_j - A; \mu, \sigma^2)}{f(x_j; \mu, \sigma^2)},
```

其中代入 $`f`$ 表达式可得\
``` math
\frac{f(x_j - A; \mu, \sigma^2)}{f(x_j; \mu, \sigma^2)} = \exp \left[ \frac{A(x_j - \mu)}{\sigma^2} - \frac{A^2}{2\sigma^2} \right].
```

最终可得似然比表达式\
``` math
T = \frac{1}{N} \sum_{j=1}^N \frac{f(x_j - A; \mu, \sigma^2)}{f(x_j; \mu, \sigma^2)} = \frac{1}{N} \sum_{j=1}^N \exp \left[ \frac{A(x_j - \mu)}{\sigma^2} - \frac{A^2}{2\sigma^2} \right].
```


## 1.6.3 参数估计 (v1.1 update)


设 $`X_1, X_2, \dots, X_n`$ 为独立同分布的样本，$`n`$ 为奇数，其概率密度函数为\
``` math
f(x; \theta) = 
\begin{cases} 
\frac{2x}{\theta^2}, & 0 \leq x \leq \theta, \\ 
0, & \text{otherwise},
\end{cases}
```

其中 $`\theta > 0`$ 为未知参数。现考虑以下三种估计量：\
最大似然估计，记作 $`\hat{\theta}_A`$；最大化样本中位数的似然函数得到的估计量，记作 $`\hat{\theta}_B`$；矩估计量，记作 $`\hat{\theta}_C`$。

1.  分别计算 $`\hat{\theta}_A`$, $`\hat{\theta}_B`$, $`\hat{\theta}_C`$。\

2.  从偏差与方差的角度的比较这三个估计量的优劣。

解答 (1) 估计量的计算

然后计算基于中位数似然估计的估值 $`\hat{\theta}_B`$。设 $`n = 2k + 1`$，中位数 $`m = X_{(k+1)}`$。根据次序统计量性质，其 pdf 为\
``` math
f_M(m \mid \theta) = C_n \cdot \frac{2m}{\theta^2} \binom{2m}{\theta^2}^k \left(1 - \frac{m^2}{\theta^2}\right)^k, \quad x \leq \theta.
```
\
忽略常数，似然函数满足\
``` math
L_B(\theta) \propto \theta^{-2k-2} \left(1 - \frac{m^2}{\theta^2}\right)^k.
```

对右式取对数求导：\
``` math
\ell'(\theta) = -\frac{2k + 2}{\theta} + k \cdot \frac{2m^2}{\theta^3} \left(1 - \frac{m^2}{\theta^2}\right) = 0.
```

令导数值为 0，解得\
``` math
\hat{\theta}_B = \sqrt{\frac{2n}{n+1}} \cdot m.
```

最后计算矩阵估计 $`\hat{\theta}_C`$。一阶矩为\
``` math
\mathbb{E}[X] = \int_0^\theta x \cdot \frac{2x}{\theta^2} dx = \frac{2\theta}{3}.
```

于是可以列出方程 $`X = \frac{2\theta}{3}`$，解得\
``` math
\hat{\theta}_C = \frac{3}{2} \bar{X}.
```

**(2) 偏差与方差**

首先考虑最大似然估计 $`\hat{\theta}_A = X_{(n)}`$。\
根据次序统计量的性质，可得 $`X_{(n)}`$ 的密度函数为\
``` math
f_{X_{(n)}}(t) = \frac{2n t^{2n-1}}{\theta^{2n}}, \quad 0 \leq t \leq \theta.
```

因此期望为\
``` math
\mathbb{E}[\hat{\theta}_A] = \int_0^\theta t \cdot \frac{2n t^{2n-1}}{\theta^{2n}} dt = \frac{2n}{\theta^{2n}} \int_0^\theta t^{2n} dt = \frac{2n}{2n + 1} \theta.
```

偏差为\
``` math
\mathbb{E}[\hat{\theta}_A] - \theta.
```

下面考虑 $`\hat{\theta}_B`$ 的偏差和方差。令 $`T = M/\theta`$，并设 $`n = 2k + 1`$。由上文结果 $`\hat{\theta}_B = M \cdot \sqrt{\frac{2n}{n+1}}`$，其中 $`M = X_{(k+1)}`$，则 $`M`$ 的概率密度函数为：

``` math
f_M(x) = \frac{(2k + 1)!}{(k!)^2} \cdot \frac{2x}{\theta^2} \cdot \left( \frac{x^2}{\theta^2} \right)^k \left( 1 - \frac{x^2}{\theta^2} \right)^k, \quad 0 \leq x \leq \theta.
```

代换 $`y = x/\theta`$ 得 $`T`$ 的概率密度函数：

``` math
f_T(y) = C_n \cdot 2y^{2k+1}(1 - y^2)^k, \quad 0 \leq y \leq 1,
```

其中

``` math
C_n = \frac{(2k + 1)!}{(k!)^2}.
```

首先计算 $`\mathbb{E}[T]`$，积分时进行代换 $`u = y^2`$，可得

``` math
\mathbb{E}[T] = C_n \cdot 2 \int_0^1 y^{2k+2}(1 - y^2)^k dy = C_n \int_0^1 u^{k+1/2}(1 - u)^k du.
```

其中

``` math
\int_0^1 u^{k+1/2}(1 - u)^k du = B(k + 1, 5, k + 1) = \frac{\Gamma(k + 1.5)\Gamma(k + 1)}{\Gamma(2k + 2.5)}.
```

因此

``` math
\mathbb{E}[T] = \frac{(2k + 1)!}{(k!)^2} \cdot \frac{\Gamma(k + 1.5)\Gamma(k + 1)}{\Gamma(2k + 2.5)} = \frac{(2k + 1)!}{k!} \cdot \frac{\Gamma(k + 1.5)}{\Gamma(2k + 2.5)} = \frac{\Gamma(2k + 2)\Gamma(k + 1.5)}{\Gamma(k + 1)\Gamma(2k + 2.5)}.
```

此值仅依赖于 $`n`$。

然后计算 $`\mathbb{E}[T^2]`$，积分时同样令 $`u = y^2`$，可得

``` math
\mathbb{E}[T^2] = C_n \cdot 2 \int_0^1 y^{2k+3}(1 - y^2)^k dy = C_n \int_0^1 u^{k+1}(1 - u)^k du.
```

其中

``` math
\int_0^1 u^{k+1}(1 - u)^k du = \frac{\Gamma(k + 1.5)\Gamma(k + 1)}{\Gamma(2k + 2.5)}.
```

``` math
Bias(\hat{\theta}_B) = \mathbb{E}[T] \sqrt{\frac{2n}{n+1} - 1} \theta.
```

``` math
\mathbb{E}[\hat{\theta}_B] = \frac{2n}{n+1} \mathbb{E}[M^2] = \frac{2n}{n+1} \theta^2 \mathbb{E}[T^2] = \frac{2n}{n+1} \cdot \frac{n+3}{4(n+2)} \theta^2.
```

``` math
\text{Var}(\hat{\theta}_B) = \mathbb{E}[\hat{\theta}_B^2] - (\mathbb{E}[\hat{\theta}_B])^2 = \frac{2n}{n+1} \left( \frac{1}{2} - (\mathbb{E}[T])^2 \right) \theta^2.
```

最后考虑矩估计 $`\hat{\theta}_C = \frac{2}{n} \bar{X}`$。通过概率密度函数计算可得

``` math
\mathbb{E}[X] = \int_0^\theta x \cdot \frac{2x}{\theta^2} dx = \frac{2\theta}{3}.
```

于是

``` math
\mathbb{E}[\hat{\theta}_C] = \frac{3}{2} \mathbb{E}[X] = \frac{3}{2} \cdot \frac{2\theta}{3} = \theta,
```

从而 $`Bias(\hat{\theta}_C) = 0`$。

接下来求 $`\hat{\theta}_C`$ 的方差。先求 $`\mathbb{E}[X^2]`$：

``` math
\mathbb{E}[X^2] = \int_0^\theta x^2 \cdot \frac{2x}{\theta^2} dx = \frac{\theta^2}{2}.
```

于是

``` math
\text{Var}(X) = \mathbb{E}[X^2] - (\mathbb{E}[X])^2 = \frac{\theta^2}{2} - \frac{4\theta^2}{9} = \frac{\theta^2}{18}.
```

因此

``` math
\text{Var}(\hat{\theta}_C) = \frac{\theta^2}{18n}.
```

从而可得

``` math
\text{Var}(\hat{\theta}_C) = \frac{9}{4} \cdot \text{Var}(X) = \frac{\theta^2}{8n}.
```

将全部结果汇总如下：

``` math
Bias(\hat{\theta}_A) = -\frac{\theta}{2n+1}, \quad \text{Var}(\hat{\theta}_A) = \frac{n}{(n+1)(2n+1)^2} \theta^2,
```

进而计算可得 $`\hat{\theta}_B`$ 偏差与方差的渐进行为。最后，将三个估计量的渐进行为汇总如下表所示。

| $`\hat{\theta}_A`$ | $`\hat{\theta}_B`$        | $`\hat{\theta}_C`$      |
|:-------------------|:--------------------------|:------------------------|
| 偏差               | $`\frac{\theta}{2n}`$     | $`\frac{5\theta}{8n}`$  |
| 方差               | $`\frac{\theta^2}{4n^2}`$ | $`\frac{\theta^2}{4n}`$ |

通过对比可知，虽然 $`\hat{\theta}_A`$ 是有偏估计，但其偏差随 $`n`$ 增大而趋于零，符合渐近无偏性。同时，$`\hat{\theta}_A`$ 的方差阶数为 $`O(n^{-2})`$，远小于 $`\hat{\theta}_B`$ 和 $`\hat{\theta}_C`$ 的 $`O(n^{-1})`$。因此 $`\hat{\theta}_A`$ 是三个估计量中最优的选择。
