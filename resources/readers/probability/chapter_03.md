## 2.1 Markov 链的基本概念


> <div id="ux786cux5e01ux8fdeux7eedux6b63ux9762ux671fux671bux629bux63b7ux6b21ux6570">
>
> ### 2.1.1 硬币连续正面期望抛掷次数
>
> </div>
>
> 独立重复抛掷一枚均匀的硬币，求首次出现连续 $`n`$ 次正面的抛掷次数的期望。

**解答.** 设期望为 $`E_n`$，考虑 $`E_{n+1}`$ 与 $`E_n`$ 的关系。为了达成连续 $`n+1`$ 次正面，首先需要达成连续 $`n`$ 次正面，设这一阶段平均需要 $`E_n`$ 次抛掷。接下来再进行一次抛掷：

- 以 $`\frac{1}{2}`$ 的概率抛出正面，此时总共抛掷次数为 $`E_n + 1`$，过程结束；

- 以 $`\frac{1}{2}`$ 的概率抛出反面，此时之前连续 $`n`$ 次正面的记录被打破，需要从头开始。从这次反面之后重新计算，期望次数仍为 $`E_n + 1`$，因此期望抛掷次数为 $`E_n + 1 + E_{n+1}`$。

于是可建立方程：
``` math
E_{n+1} = E_n + \frac{1}{2} \cdot 1 + \frac{1}{2} (1 + E_{n+1}),
```
化简得
``` math
E_{n+1} = 2E_n + 2.
```

已知 $`E_1 = 2`$（首次出现正面所需期望次数为 2），利用递推关系可得最终结果：
``` math
E_n = 2^n - 1.
```


## 2.1.2 抽球游戏


假设你有一个空盒子，以及一个装有大量球的袋子。袋子里的球共有六种不同颜色，且每种颜色出现的概率相同。你开始进行一个游戏：首先从袋子里随机抽出一个球，放在桌子上。接着继续一次抽取一个球：

- 如果抽到的玻璃球颜色与桌上已有的某个玻璃球颜色相同，那么就把这球放回原处。\

- 如果抽到的玻璃球颜色在桌上尚未出现过，则将它放在桌子上，并保持桌上的玻璃球颜色各不相同。

游戏持续进行，直到桌子上同时拥有六种不同颜色的玻璃球为止。此时游戏结束。\
问：当游戏结束时，盒子里期望数量是多少？

解答

设 $`k`$ 为当前桌上不同颜色球的数量。状态空间为 $`k = 0, 1, \ldots, 6`$，终止状态为 $`k = 6`$。\
当处于状态 $`k`$ 时：

``` math
k = k + 1 \quad \text{概率} = \frac{6 - k}{6},
```

``` math
k = k - 1 \quad \text{概率} = \frac{k}{6}.
```

设 $`E_k`$ 为从状态 $`k`$ 出发到达 $`6`$ 的期望步数，即总的抽取次数，则 $`E_0 = 0`$，且：

``` math
E_k = 1 + \frac{6 - k}{6} E_{k+1} + \frac{k}{6} E_{k-1}, \quad 1 \leq k \leq 5,
```

## 2.1.3 雨伞问题


> 某个公司职员有 $`n`$ 把伞，其中家里有 $`k`$ 把，公司里有 $`n-k`$ 把。他每天早晨从家去公司，晚上从公司回家。每一趟行程中，若下雨，他将会带上 1 把伞从家/公司带到公司/家，如果此时没有雨伞，则淋雨完成行程。已知早晨、晚上下雨的概率均为 $`p`$，且不同时间是否下雨均独立。求长 期来看，他某一次出行中被淋雨的机率。

**解答.** 方法一

以 “每天早晨家中雨伞的数量” 作为状态，建立 Markov 链。设状态空间为 $`0, 1, 2, \dots, n`$，其中状 态 $`i`$ 表示家中已有 $`i`$ 把伞（则公司有 $`n-i`$ 把）。我们要求的是状态 $`0`$ 的平稳分布 $`p_0`$，即长期来看出 发时家中没有伞的概率。题目所求的长期被淋雨概率即为 $`p_0`$。

令 $`q = 1 - p`$，统计算可得，当 $`0 < k < n`$ 时，状态转移概率如下：

``` math
P_{k, k+1} = p, \quad P_{k, k} = p^2 + q^2, \quad P_{k, k+1} = pq,
```

以及在状态 $`0`$ 和状态 $`n`$ 处的转移概率：

``` math
P_{0, 0} = q, \quad P_{0, 1} = p, \quad P_{n, n} = 1 - p, \quad P_{n, n-1} = pq.
```

根据转移概率，可以建立平稳分布 $`\{x_k\}_{k=0}^n`$ 的一组方程：

``` math
\begin{aligned}
\pi_0 &= q\pi_0 + pq\pi_1, \\
\pi_1 &= p\pi_0 + (p^2 + q^2)\pi_1 + pq\pi_2, \\
\pi_2 &= pq\pi_1 + (p^2 + q^2)\pi_2 + pq\pi_3, \\
&\vdots
\end{aligned}
```
