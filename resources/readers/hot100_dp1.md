## 母题：70. 爬楼梯

### 快速理解

**题干**
- 每次可以爬 1 阶或 2 阶，给定整数 n，返回爬到第 n 阶楼梯的不同方法数。

**触发信号**
- 一步或两步到终点
- 一维线性 DP

**代码阅读顺序**
1. 先看函数签名（参数和返回值）。
2. 看初始化变量（这些变量就是状态）。
3. 看主循环/递归（状态如何变化）。
4. 看返回语句（最终答案从哪里来）。

**手动模拟建议**
- 用一个最小样例跟着变量变化走 3~5 步。
- 重点观察：指针移动、哈希变化、栈/队列进出、DP 状态转移。

**复杂度（学习版估计）**
- 通常为 O(n) 级别（单次线性扫描），空间多为 O(1)~O(n)。


```python
# ==============================
# 母题：70. 爬楼梯
# 这段代码分两部分：
# 1) 上半部分是算法函数；

# ==============================

# 函数入口：climb_stairs。先关注输入参数，再看返回值。
def climb_stairs(n):
    # 分支判断：不同条件走不同处理路径。
    if n <= 2:
        # 返回当前函数结果。
        return n
    a, b = 1, 2
    # 循环推进状态：每一步都在逼近最终答案。
    for _ in range(3, n + 1):
        a, b = b, a + b
    # 返回当前函数结果。
    return b

# 准备测试样例：每组包含输入和期望输出。
cases = [(2, 2), (3, 3), (5, 8)]
# 逐个运行样例，观察输出并与预期对比。

    out = climb_stairs(n)
    show_case("Climbing Stairs", {"n": n}, out, expected)
    # 断言校验：若失败会抛异常，说明逻辑需要排查。
    assert out == expected
# 输出提示，帮助你确认该题样例已通过。
```

## 母题：62. 不同路径

### 快速理解

**题干**
- 机器人位于 m x n 网格左上角，每次只能向下或向右移动一步，返回到达右下角的不同路径数量。

**触发信号**
- 网格计数
- 当前位置由上方和左方转移

**代码阅读顺序**
1. 先看函数签名（参数和返回值）。
2. 看初始化变量（这些变量就是状态）。
3. 看主循环/递归（状态如何变化）。
4. 看返回语句（最终答案从哪里来）。

**手动模拟建议**
- 用一个最小样例跟着变量变化走 3~5 步。
- 重点观察：指针移动、哈希变化、栈/队列进出、DP 状态转移。

**复杂度（学习版估计）**
- 通常为 O(n^2) 级别（含多层扫描/循环），具体看数据结构。


```python
# ==============================
# 母题：62. 不同路径
# 这段代码分两部分：
# 1) 上半部分是算法函数；
# 2) 下半部分是样例与断言，便于你直接运行验证。
# ==============================

# 函数入口：unique_paths。先关注输入参数，再看返回值。
def unique_paths(m, n):
    dp = [[1] * n for _ in range(m)]
    # 循环推进状态：每一步都在逼近最终答案。
    for i in range(1, m):
        # 循环推进状态：每一步都在逼近最终答案。
        for j in range(1, n):
            dp[i][j] = dp[i - 1][j] + dp[i][j - 1]
    # 返回当前函数结果。
    return dp[-1][-1]

# 准备测试样例：每组包含输入和期望输出。
cases = [((3, 7), 28), ((3, 2), 3)]
# 逐个运行样例，观察输出并与预期对比。
for (m, n), expected in cases:
    out = unique_paths(m, n)
    show_case("Unique Paths", {"m": m, "n": n}, out, expected)
    # 断言校验：若失败会抛异常，说明逻辑需要排查。
    assert out == expected
# 输出提示，帮助你确认该题样例已通过。
print("母题通过")
```

## 母题：198. 打家劫舍

### 快速理解

**题干**
- 给定非负整数数组 nums，表示每间房屋可偷金额，不能偷相邻房屋，返回一晚能偷到的最高金额。

**触发信号**
- 相邻元素不可同时选
- 线性 DP 选/不选模型

**代码阅读顺序**
1. 先看函数签名（参数和返回值）。
2. 看初始化变量（这些变量就是状态）。
3. 看主循环/递归（状态如何变化）。
4. 看返回语句（最终答案从哪里来）。

**手动模拟建议**

- 重点观察：指针移动、哈希变化、栈/队列进出、DP 状态转移。

**复杂度（学习版估计）**
- 通常为 O(n) 级别（单次线性扫描），空间多为 O(1)~O(n)。


```python
# ==============================
# 母题：198. 打家劫舍
# 这段代码分两部分：
# 1) 上半部分是算法函数；

# 函数入口：rob。先关注输入参数，再看返回值。
def rob(nums):
    pre2, pre1 = 0, 0
    # 循环推进状态：每一步都在逼近最终答案。

    return pre1

    out = rob(nums)
    show_case("House Robber", {"nums": nums}, out, expected)
```

## 母题：322. 零钱兑换

### 快速理解

**题干**
- 给定硬币面额数组 coins 和金额 amount，求凑成 amount 所需的最少硬币数；若无法凑成则返回 -1。

**触发信号**

- 完全背包 + 最小值 DP

**代码阅读顺序**
1. 先看函数签名（参数和返回值）。
2. 看初始化变量（这些变量就是状态）。
3. 看主循环/递归（状态如何变化）。
4. 看返回语句（最终答案从哪里来）。

**手动模拟建议**
- 用一个最小样例跟着变量变化走 3~5 步。
- 重点观察：指针移动、哈希变化、栈/队列进出、DP 状态转移。

**复杂度（学习版估计）**
- 通常为 O(n^2) 级别（含多层扫描/循环），具体看数据结构。


```python
# ==============================
# 母题：322. 零钱兑换
# 这段代码分两部分：
# 1) 上半部分是算法函数；
# 2) 下半部分是样例与断言，便于你直接运行验证。
# ==============================

# 函数入口：coin_change。先关注输入参数，再看返回值。
def coin_change(coins, amount):
    INF = 10**9
    dp = [INF] * (amount + 1)
    dp[0] = 0
    # 循环推进状态：每一步都在逼近最终答案。
    for coin in coins:
        # 循环推进状态：每一步都在逼近最终答案。
        for x in range(coin, amount + 1):
            dp[x] = min(dp[x], dp[x - coin] + 1)
    # 返回当前函数结果。
    return -1 if dp[amount] == INF else dp[amount]

# 准备测试样例：每组包含输入和期望输出。
cases = [
    (([1,2,5], 11), 3),
    (([2], 3), -1),
]
# 逐个运行样例，观察输出并与预期对比。
for (coins, amount), expected in cases:
    out = coin_change(coins, amount)
    show_case("Coin Change", {"coins": coins, "amount": amount}, out, expected)
    # 断言校验：若失败会抛异常，说明逻辑需要排查。
    assert out == expected
# 输出提示，帮助你确认该题样例已通过。
print("母题通过")
```

## 母题：139. 单词拆分

### 快速理解

**题干**
- 给定字符串 s 和字典 wordDict，判断 s 是否可以被拆分为一个或多个字典中出现的单词。

**触发信号**
- 字符串可否由词典拼成
- 前缀 DP + 哈希集合

**代码阅读顺序**
1. 先看函数签名（参数和返回值）。
2. 看初始化变量（这些变量就是状态）。
3. 看主循环/递归（状态如何变化）。
4. 看返回语句（最终答案从哪里来）。

**手动模拟建议**
- 用一个最小样例跟着变量变化走 3~5 步。
- 重点观察：指针移动、哈希变化、栈/队列进出、DP 状态转移。

**复杂度（学习版估计）**
- 通常为 O(n^2) 级别（含多层扫描/循环），具体看数据结构。


```python
# ==============================
# 母题：139. 单词拆分
# 这段代码分两部分：
# 1) 上半部分是算法函数；
# 2) 下半部分是样例与断言，便于你直接运行验证。
# ==============================

# 函数入口：word_break。先关注输入参数，再看返回值。
def word_break(s, word_dict):
    st = set(word_dict)
    n = len(s)
    dp = [False] * (n + 1)
    dp[0] = True
    # 循环推进状态：每一步都在逼近最终答案。
    for i in range(1, n + 1):
        # 循环推进状态：每一步都在逼近最终答案。
        for j in range(i):
            # 分支判断：不同条件走不同处理路径。
            if dp[j] and s[j:i] in st:
                dp[i] = True
                break
    # 返回当前函数结果。
    return dp[n]

# 准备测试样例：每组包含输入和期望输出。
cases = [
    (("leetcode", ["leet", "code"]), True),
    (("applepenapple", ["apple", "pen"]), True),
    (("catsandog", ["cats", "dog", "sand", "and", "cat"]), False),
]
# 逐个运行样例，观察输出并与预期对比。
for (s, words), expected in cases:
    out = word_break(s, words)
    show_case("Word Break", {"s": s, "dict": words}, out, expected)
    # 断言校验：若失败会抛异常，说明逻辑需要排查。
    assert out == expected
# 输出提示，帮助你确认该题样例已通过。
print("母题通过")
```
