# 高频做市基本知识

## 1. 高频做市是什么

高频做市是指交易者在电子订单簿中持续提交买卖双边限价单，为市场提供流动性，并试图从买卖价差、交易所返佣、短期价格预测和库存管理中获得收益。

配套 demo：[高频做市基础模型demo](references/d7456c4952c7.md)

最简单的形式：

- 在买一附近挂买单；
- 在卖一附近挂卖单；
- 买单成交后，希望能以更高价格卖出；
- 卖单成交后，希望能以更低价格买回；
- 同时控制持仓不要过度偏离。

但真实高频做市远不只是“双边挂单”。核心难点是：什么时候挂、挂多深、挂多少量、什么时候撤、成交后如何处理库存，以及如何避免被更有信息优势的订单打中。

## 2. 限价订单簿基础

高频做市发生在 limit order book（LOB）中。

| 概念 | 含义 |
|---|---|
| bid | 当前最高买价 |
| ask | 当前最低卖价 |
| mid price | `(best bid + best ask) / 2` |
| spread | `best ask - best bid` |
| depth | 某一价格档位上的挂单量 |
| queue position | 同一价格档位中自己的排队位置 |
| market order | 主动吃单，消耗流动性 |
| limit order | 被动挂单，提供流动性 |
| cancellation | 撤单 |

做市商通常是 liquidity provider，挂限价单；taker 是 liquidity demander，主动吃单。

## 3. 做市收益从哪里来

### 3.1 Bid-Ask Spread

如果做市商在 bid 买到，又在 ask 卖出，就赚到 spread。

例子：

- bid = 99.99
- ask = 100.01
- spread = 0.02
- 买入成交在 99.99，卖出成交在 100.01，毛收益是 0.02

但这只是理想情况。真实中可能买完价格继续下跌，或卖完价格继续上涨。

### 3.2 Maker Rebate / Fee Advantage

很多交易所采用 maker/taker fee：

- maker：挂单成交，可能拿 rebate 或支付较低手续费；
- taker：吃单成交，通常支付更高手续费。

如果 maker rebate 足够高，即使 spread 很窄，做市仍可能有收益。

### 3.3 短期预测 Alpha

现代高频做市不只是被动赚 spread，也会预测极短期价格方向。

常见信号：

- order book imbalance；
- order flow；
- trade imbalance；
- cancellation pattern；
- queue depletion；
- cross-exchange price difference；
- funding / basis / futures-spot lead-lag。

如果模型判断短期价格更可能上涨，做市商可能：

- 提高 bid，积极买入；
- 抬高 ask 或减少卖单；
- 降低被逆向选择的概率。

### 3.4 库存风险补偿

做市商承担库存风险，因此报价会随持仓调整。

如果当前持仓过多：

- 降低 bid，减少继续买入；
- 降低 ask，更积极卖出；
- 让库存回到目标区间。

如果当前持仓过空：

- 提高 bid，更积极买回；
- 提高 ask，减少继续卖出。

## 4. 做市的主要风险

### 4.1 逆向选择

逆向选择是做市最核心的风险。

如果对手方比你更懂短期价格方向，他会在价格即将上涨前吃你的卖单，或在价格即将下跌前砸你的买单。你看似赚 spread，实际上被信息型订单打了。

一句话：你被成交，可能不是因为你报价好，而是因为别人知道你报价错了。

### 4.2 库存风险

做市商不断成交，会积累方向性仓位。价格波动时，库存可能带来巨大损失。

库存风险包括：

- 单边成交过多；
- 市场跳变；
- 无法及时平仓；
- 多交易所库存不平衡；
- 合约和现货对冲不完全。

### 4.3 延迟风险

高频策略非常依赖低延迟。

风险来自：

- 行情延迟；
- 下单延迟；
- 撤单延迟；
- 撮合回报延迟；
- 本地系统排队；
- 网络抖动。

延迟越高，挂单越容易变成“过时报价”。

### 4.4 Queue Risk

在同一价格档位，先挂的订单通常先成交。排队位置决定成交概率。

高频做市要关心：

- 我排在队列第几位？
- 前面还有多少量？
- 这档被打穿的概率多大？
- 撤单会不会失去排队优势？

### 4.5 Fee / Tick Size 风险

手续费和最小报价单位会改变策略收益结构。

- tick size 太大：spread 可能很宽，但队列竞争激烈；
- tick size 太小：容易被极小价格差 undercut；
- maker/taker fee 改变：可能让原本盈利的策略变亏损。

## 5. 做市策略的基本流程

一个简化的高频做市循环：

1. 接收行情：订单簿、成交、指数价、其他交易所价格。
2. 计算 fair price：估计当前真实中间价格。
3. 预测短期方向：用订单流和订单簿信号修正 fair price。
4. 计算目标 spread：考虑波动率、手续费、库存、风险。
5. 生成报价：决定 bid/ask 价格和数量。
6. 下单/撤单：根据行情变化更新订单。
7. 成交处理：更新库存、现金、PnL、风险敞口。
8. 风控检查：库存、亏损、延迟、成交异常、交易所状态。

## 6. 常见特征和信号

### 6.1 Order Book Imbalance

衡量买卖盘深度不平衡：

```text
imbalance = (bid_size - ask_size) / (bid_size + ask_size)
```

如果买盘显著大于卖盘，短期价格可能更容易上行。

### 6.2 Order Flow

关注新增挂单、撤单和成交的动态变化。

比静态 depth 更重要的是变化：

- 买盘突然增加；
- 卖盘快速撤走；
- 主动买单连续扫单；
- 某一档队列快速被消耗。

### 6.3 Trade Imbalance

比较主动买成交和主动卖成交：

```text
trade imbalance = buy_volume - sell_volume
```

主动买多，说明 taker 端短期更急于买入；主动卖多则相反。

### 6.4 Cross-Exchange Signal

Crypto 中尤其重要。

如果 Binance 上 BTC 快速上涨，而 OKX/Bybit 还没动，可能存在短暂 lead-lag 信号。

## 7. Crypto 高频做市的特点

相比股票市场，Crypto 做市有一些特殊性：

| 特点 | 影响 |
|---|---|
| 7x24 小时交易 | 风控和监控必须全天候 |
| 多交易所并存 | 跨交易所价差、库存和转账风险重要 |
| maker/taker/VIP 费率复杂 | 费率本身可能决定策略是否盈利 |
| 现货、永续、交割合约并存 | 需要考虑 funding、basis、指数价 |
| API 和撮合质量差异大 | 技术稳定性很重要 |
| tick size 经常调整 | 策略参数需要动态适配 |
| 极端行情多 | 撤单和风控比平时收益更重要 |

## 8. 回测高频做市为什么难

普通 K 线回测几乎不能验证高频做市。

需要至少考虑：

- tick-level 行情；
- Level 2 order book；
- 真实手续费；
- 排队位置；
- 撮合规则；
- 部分成交；
- 撤单延迟；
- 网络延迟；
- 交易所限频；
- 数据时间戳准确性；
- 幸存者偏差和数据缺口。

一个常见错误是：看到 bid/ask 都出现过，就假设自己能在 bid 买、ask 卖。真实中你可能排不到队，也可能成交只发生在价格即将反向时。

## 9. 高频做市和普通量化策略的区别

| 维度 | 高频做市 | 普通中低频策略 |
|---|---|---|
| 持仓周期 | 毫秒到分钟 | 分钟到数月 |
| 数据 | tick / L2 / trades | K线 / 日频 / 财报 |
| 收益来源 | spread、rebate、微观结构 alpha | 趋势、因子、风险溢价 |
| 核心风险 | 逆向选择、库存、延迟 | 因子失效、回撤、拥挤 |
| 技术要求 | 极高 | 中等到高 |
| 回测难度 | 很高 | 相对较低 |

## 10. 面试表达模板

### 什么是高频做市？

高频做市是在限价订单簿中持续提供双边报价，通过赚取 bid-ask spread、maker rebate 和短期微观结构 alpha 获利，同时需要控制逆向选择、库存和延迟风险。

### 做市为什么会亏钱？

因为成交本身可能带有坏消息。买单成交后价格可能继续下跌，卖单成交后价格可能继续上涨；如果模型无法识别信息型订单，赚到的 spread 会被 adverse selection 吃掉。

### Tick size 为什么重要？

Tick size 决定报价网格。tick 太大时 spread 和队列租金高，tick 太小时容易出现过度 undercutting。最优 tick size 是交易成本、深度、队列竞争和流动性激励之间的平衡。

### Maker/taker fee 为什么重要？

在离散价格网格下，maker/taker fee 的拆分无法被报价完全中和，所以会影响挂单和吃单的相对收益，进而影响成交量、市场份额、spread 和 depth。

### 高频做市最关键的能力是什么？

一是对订单簿和订单流的短期预测，二是库存和风险控制，三是低延迟稳定执行。模型、系统和风控缺一不可。
