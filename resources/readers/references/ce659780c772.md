# 12 网络与系统调优

> 来源：量化开发工程师.pdf（原本地参考：`../../量化开发工程师.pdf`）；物理页码：PDF 第 584-634 页；二级主题数：5；题数：18。  
> 综合依据：本章全部小节的题目、知识点、答案与拓展内容；标题和页码以 PDF 书签拆解索引为准。

## 本章定位

本章是低延迟系统的硬件—内核联合调优指南：网络旁路、CPU 前端/执行端口、NUMA、IRQ/Tick 和存储 I/O 都会进入尾延迟。调优必须先建立基准与拓扑，再逐项改变，并保留可逆配置和回归证据。

## 知识框架

### 12.1 内核Bypass技术对比

- 核心概念：DPDK、XDP/AF_XDP、RDMA 在旁路深度、协议能力和开发复杂度上不同；LRO/GRO 合包会扭曲单包时间戳。
- 工程组件：用户态 PMD、XDP_REDIRECT/UMEM、RDMA verbs、硬件时间戳、云 ENI/SR-IOV 与设备插件。
- 性能与约束：选择取决于协议和部署权限；云上核查 VF、驱动、HugePage、能力位和厂商白名单，基准时关闭会合包的 offload。

### 12.2 CPU微架构优化

- 核心概念：执行端口利用不均、Micro-op Cache miss、分支与内存布局限制每周期工作；Loop Unrolling+SIMD 需与 SoA 对齐。
- 工程组件：VTune/perf、端口事件、循环对齐与裁剪、AVX2/AVX-512、预取和超线程 A/B 基准。
- 性能与约束：优化前固定输入与频率，比较 cycles、IPC、端口、I-cache 和尾延迟；HT 共享资源可能提高吞吐却恶化单线程抖动。

### 12.3 NUMA与内存亲和性

- 核心概念：网卡、线程和内存应处于同一 NUMA 节点；first-touch 决定页的初始归属，跨节点访问会累积到撮合路径。
- 工程组件：lscpu/numactl、PCI numa_node、sched affinity、membind、并行触页和 per-node 内存池。
- 性能与约束：启动后验证实际 page placement 和迁移；不仅绑 CPU，还要绑定内存、NIC 队列和后台线程。

### 12.4 中断亲和与Tickless Kernel

- 核心概念：IRQ Affinity、isolcpus、rcu_nocbs 与 NO_HZ_FULL 共同减少调度噪声；Tickless 可能改变用户态定时器唤醒行为。
- 工程组件：GRUB 内核参数、IRQ/RPS/XPS、实时内核、高分辨率定时器、busy wait 或硬件计时替代。
- 性能与约束：保留 housekeeping 核承担中断与 RCU；测 epoll/timerfd 的实际唤醒分布，不能为减少 tick 破坏超时和心跳。

### 12.5 文件系统与磁盘I/O

- 核心概念：io_uring 通过注册文件/缓冲和 SQPOLL 降系统调用；ext4/XFS/NVMe-oF 适配不同小文件负载，DAX 绕过页缓存，写放大决定 SSD 寿命。
- 工程组件：io_uring、批量二进制日志、XFS/ext4、DAX mmap、NVMe SMART、blktrace 与 TBW/WA 模型。
- 性能与约束：持久化语义与延迟同时验证；DAX 需要正确 flush/fence，磁盘监控以主机写入、NAND 写入和剩余寿命触发容量迁移。

## 题型与答题框架

- 所有调优题先画硬件拓扑和基线，说明测量点、负载、分位数与控制变量。
- 网络方案按旁路层级、拷贝次数、协议能力、权限和运维复杂度对比。
- CPU 题用硬件计数器定位，不凭经验直接展开 SIMD。
- NUMA/IRQ 题要给启动配置、运行时验证和故障回退。
- I/O 题同时回答提交语义、吞吐/尾延迟和介质寿命。

## 高频易错点

- 开着 GRO/LRO 测单包延迟，得到批处理后的伪时间戳。
- 看到高 CPU 就盲目 SIMD，未确认前端、端口还是内存瓶颈。
- 只绑线程不绑内存和网卡队列，仍发生跨 NUMA。
- 把所有 CPU 都设为 nohz_full/isolated，没有 housekeeping 核。
- SQPOLL 忽略 CPU 占用与权限，或把提交入队误当数据持久化。
- DAX 写后不做持久化屏障，掉电恢复出现已见未落盘状态。

## 复习顺序（核心必会/进阶/查漏）

- 核心必会：旁路方案差异、硬件计数器、NUMA 三元共置、IRQ/Tick 隔离。
- 进阶：AF_XDP、微操作/端口优化、SIMD、io_uring 和 DAX。
- 查漏：云权限、HT 干扰、epoll 副作用、文件系统选择与 SSD 写放大。
