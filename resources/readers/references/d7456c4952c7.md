# 高频做市基础模型 Demo

这个 demo 用一个很小的 Avellaneda-Stoikov 风格模型帮助理解基础做市逻辑：

```text
报价中心 = mid price - inventory * gamma * sigma^2 * remaining_time
bid = 报价中心 - spread / 2
ask = 报价中心 + spread / 2
```

直觉：

- 库存为正：说明已经买多了，报价整体下移，鼓励卖出、减少继续买入。
- 库存为负：说明已经卖空了，报价整体上移，鼓励买回、减少继续卖出。
- 波动率越高：spread 越宽，因为持仓风险更大。
- 报价离 mid 越远：成交概率越低。

## 运行

在当前目录执行：

```bash
python3 market_maker_demo.py
```

会生成：

- `output/simulation.csv`：每一步报价、成交、库存和 PnL
- `output/simulation.png`：价格/报价、库存、PnL 三张图

可以调整参数：

```bash
python3 market_maker_demo.py --gamma 0.2 --sigma 2.0 --steps 500 --seed 1
```

## 看什么

重点看三件事：

1. `inventory` 偏离 0 后，`bid/ask` 会整体向反方向偏移。
2. `sigma` 调大后，spread 会更宽，成交变少但风险更保守。
3. `gamma` 调大后，库存控制更强，报价更快为了回库存而偏移。
