# 研究与回测

## 主题域主线

研究结论只有同时满足 **信息在决策时可得、假说可证伪、样本外仍成立、扣除执行摩擦后仍有经济价值、结果能够复现、实盘偏差能够逐单解释**，才具备进入生产的资格。

本主题域位于总能力闭环的中段：

> 数据可信 → **研究有效 → 回测真实** → 执行可达 → 风控可控 → 证据可审计

它不按四本资料分别复述，而是把研究员提出假说、数据工程师冻结时点数据、开发工程师实现研究流水线、回测架构师维护仿真语义这四类责任合成一条证据链。

## 共用研究对象

一次可审计研究至少冻结以下对象；缺少任何一个，都可能出现“同一策略、不同结果”。

| 对象 | 必须记录的内容 | 用途 |
|---|---|---|
| 研究假说 | 经济/微观结构机制、预测对象、持有期、适用状态、失效条件 | 防止从结果倒推故事 |
| 数据快照 | 来源、事件时间、可得时间、修订版本、股票池/合约映射、质量标签 | 排除前视、生存和修订泄漏 |
| 特征与标签 | 公式、窗口、缺失规则、标准化拟合区间、标签重叠 | 保证线上线下一致 |
| 模型与搜索 | 代码、配置、依赖、随机种子、候选数量、停止规则 | 量化选择偏差并可复现 |
| 执行模型 | 费用、基准价、盘口/队列、延迟、成交概率、冲击、交易规则 | 将信号转换为可实现净收益 |
| 组合与风险 | 暴露、协方差、限额、保证金、容量、熔断/降级 | 防止优化器放大估计误差 |
| 结果与日志 | 逐事件决策、逐订单生命周期、账户记账、指标口径、版本摘要 | 回放、归因与审计 |

## 共用验收顺序

1. **先验定义**：在看最终结果前写清假说、基线、指标、样本切分和失败条件。
2. **时点审计**：逐字段确认在决策时是否可得，检查复权、成分、公告、标签和滚动统计。
3. **统计验证**：报告效应大小、置信区间、时间/市场状态稳定性、负对照和多重尝试影响。
4. **经济验证**：加入手续费、价差、滑点、冲击、换手、容量、限制与机会成本。
5. **稳健性验证**：滚动样本外、参数扰动、块重采样、压力情景及简单基线对比。
6. **确定性回放**：冻结数据、代码、配置、随机数和事件排序，确保相同输入产生相同结果。
7. **上线前验证**：仿真、影子、灰度分层推进；异常时能够冻结、降级和回滚。
8. **实盘归因**：以同一订单生命周期对齐回测与实盘，先定位最大差异，再改一个组件并验证。

## 证据强度分级

- **L0 研究设想**：只有机制说明，尚未完成数据可得性与基线检查。
- **L1 统计证据**：存在样本外统计效果，但尚未充分模拟交易摩擦。
- **L2 可交易证据**：成本、容量、风险和交易规则后的结果仍支持假说。
- **L3 仿真证据**：事件顺序、盘口/队列、延迟和账户语义通过确定性回放。
- **L4 生产证据**：影子或灰度日志能解释实盘差异，并具备监控、降级和回滚。

这不是收益评级，也不保证未来表现；它只说明当前证据链走到了哪一步。

## 使用建议

- 第一遍按 `01 → 02 → 03 → 04 → 05 → 06` 学习，建立从假说到实盘归因的顺序。
- 第二遍从每页“典型失败模式”反向排障：先查信息时点，再查成交语义，最后查模型失效。
- 面试演练时先口述每页的“一句话主线”，再用“输入—方法—指标—边界—失败降级”展开。
- 题目给出的夏普、延迟、阈值或比例只是情景条件；除非限定市场、频率、成本和验证方法，不应写成通用参数。
