## 本章定位

本章把全书能力放到全球市场：统一 Tick/盘口与另类数据，同时保留时区、币种、交易规则和监管差异。

回答本章问题时，不应停留在工具名罗列；需要把数据语义、处理步骤、系统状态、验证指标和失败边界连成闭环。

## 知识框架

### 23.1 Tick数据处理基础

- **核心概念：**跨市场 Tick 具有格式、时区、交易日与精度差异，但仍以逐笔事件、顺序和可得时间为核心。
- **方法 / 系统组件：**接入后做 schema、序列、异常和时间标准化，统一 UTC 同时保留本地交易日，热/冷分层持久；延迟乱序用水位线/小窗和缺口标记。
- **指标 / 约束：**不能用降精度造成同序冲突；监控跨市场时钟偏差、完整率和新鲜度，并保留原始时间字段。

### 23.2 订单簿数据解析

- **核心概念：**跨市场订单簿需统一买卖档、价格/数量单位和市场微观结构定义，核心指标有中间价、价差、深度与流动性。
- **方法 / 系统组件：**各所适配器转统一事件模型，快照+增量重建，实时计算多档深度/不平衡并用规则+模型异常检测；格式与时区映射进入元数据。
- **指标 / 约束：**不同市场档位与订单类型不可硬等同；指标先做币种、合约乘数和可交易性标准化。

### 23.3 跨市场数据清洗与标准化

- **核心概念：**跨市场清洗统一代码、币种、单位、企业行动、时区/夏令时和交易日，并以经济关系验证结果。
- **方法 / 系统组件：**建立参考数据映射、汇率/合约乘数转换、交易日历与 DST 测试，网络不同步用时钟偏差估计和事件时间重排；ADR/港/A 股序列清洗后再做协整检验。
- **指标 / 约束：**协整失败不能单独证明数据坏，需考虑汇率、转换比率、交易时段和结构变化；所有转换有版本与生效时间。

### 23.4 低延迟数据管道构建

- **核心概念：**跨市场低延迟管道把各地接入、标准化、传输、计算和存储纳入统一延迟预算。
- **方法 / 系统组件：**本地接入/预处理后用紧凑协议传输，按市场/标的分区流计算，FPGA 解析、GPU 批量特征，缓存/时序库+列式历史层优化查询。
- **指标 / 约束：**物理网络、时区、格式和监管限制是约束；准确性检查、重放和降级不可省略。

### 23.5 另类数据处理与应用

- **核心概念：**全球另类数据包括 AIS、卫星和多语言社交文本，需从时空/语义原始数据构造可验证指标。
- **方法 / 系统组件：**AIS 做轨迹清洗、港口停留/速度/拥堵指标，卫星做校准分割计数，中文混合文本做归一、领域情感；用 Granger、工具变量/事件研究等检验增量关系。
- **指标 / 约束：**相关不等于因果；关注时区、定位漂移、缺报、云层、机器人文本、发布时间和数据授权。

### 23.6 全球市场数据整合策略

- **核心概念：**全球整合在一致性、延迟、覆盖和法规之间取舍，目标是统一但不抹平市场制度差异。
- **方法 / 系统组件：**建立 canonical schema、参考数据和交易日历，Tick/盘口/基本面/另类数据按实体与可得时间融合；关键状态强校验，分析副本允许异步，另类因子补充传统信息。
- **指标 / 约束：**保留来源和本地语义，评估数据价值衰减、跨境传输、汇率与交易规则；案例需给出验证而非只列组件。

### 23.7 数据质量监控与实时风控

- **核心概念：**实时质量与风控监控跨市场时区、合成价差、盘口噪声、另类质量和管道健康。
- **方法 / 系统组件：**即时层查 schema/序列/延迟，业务层查价差/深度/跨源关系，系统层报警、隔离、补数与根因；噪声模型动态过滤但保留原始，质量阈值随市场状态。
- **指标 / 约束：**完备校验与吞吐分层处理；价差异常先排时区、汇率、交易时段和非同步报价，再判断市场机会。

### 23.8 机器学习与量化数据融合

- **核心概念：**机器学习融合跨市场 Tick、盘口和另类特征，并受低延迟、非同步、隐私和 Non-IID 约束。
- **方法 / 系统组件：**流式特征服务+压缩模型低延迟推理，盘口构造价差/深度/订单流，跨市场套利输入汇率、流动性和时钟，联邦学习做域内训练与安全聚合，多模态按新鲜度动态加权。
- **指标 / 约束：**训练/标签必须按各市场可得时间，评估成本、容量、漂移、通信隐私和推理延迟；不得用插值创造同步幻象。

## 题型与答题框架

- **概念 / 说明题（6 题）：**先给出对象的精确定义与数据边界，再说明字段或组成、工作机制、量化岗位用途，最后补充不适用条件和常见混淆。
- **方案设计 / 故障处理题（24 题）：**按“输入与语义 → 清洗/计算 → 状态与存储 → 输出 → 监控与恢复”展开；排障题先建立基线并分层定位，再给验证实验、修复和回归。
- **比较 / 选型题（11 题）：**先固定负载和 SLO，再从延迟、吞吐、一致性、状态/查询模式、容错、成本、运维与合规逐维比较，给出条件化结论而非绝对优劣。
- **案例 / 复盘题（6 题）：**交代业务规模与约束，给出原始指标和证据，说明定位过程、关键改动、验证口径、剩余风险；没有亲历数据时使用明确的假设案例。

本章的答案最终要落到可验证约束，例如：不能用降精度造成同序冲突；不同市场档位与订单类型不可硬等同；协整失败不能单独证明数据坏，需考虑汇率、转换比率、交易时段和结构变化；物理网络、时区、格式和监管限制是约束；相关不等于因果；保留来源和本地语义，评估数据价值衰减、跨境传输、汇率与交易规则；完备校验与吞吐分层处理；训练/标签必须按各市场可得时间，评估成本、容量、漂移、通信隐私和推理延迟。

## 高频易错点

- 只转 UTC 不保留本地交易日。
- 忽略 DST 和节假日。
- 跨市场价差未统一币种/乘数。
- 非同步报价制造伪套利。
- 协整失败直接归因于清洗错误。

## 复习顺序

1. **核心必会：**先掌握 23.1—23.4 的跨市场标准化、盘口和低延迟管道。
2. **进阶：**再学习 23.5—23.8 的另类指标、全球融合、质量风控和联邦/机器学习。
3. **查漏：**重点回查 DST、交易日重叠、汇率/合约乘数、ADR 转换、数据衰减与跨境限制。
