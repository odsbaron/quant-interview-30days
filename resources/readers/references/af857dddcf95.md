## 本章定位

本章将数据质量从离线检查升级为分布式实时检测、归因、告警与恢复体系。

回答本章问题时，不应停留在工具名罗列；需要把数据语义、处理步骤、系统状态、验证指标和失败边界连成闭环。

## 知识框架

### 6.1 数据质量基础指标

- **核心概念：**质量指标从完整、准确、一致、及时、唯一扩展到价差/深度等业务合理性；另类数据还需覆盖清晰度、文本可用性和来源偏差。
- **方法 / 系统组件：**流式计算轻量指标，按标的和市场状态维护动态基线，跨源对价，异常分级告警并反馈到隔离、补数和根因分析。
- **指标 / 约束：**阈值要有季节性/波动状态，监控覆盖率、延迟分位、缺口、重复、跨源偏差和误报；价差扩大本身不等于坏数据。

### 6.2 数据异常类型识别

- **核心概念：**异常类型包括采集/传输故障、格式与完整性问题、统计离群和真实市场异常，识别重点是来源归因。
- **方法 / 系统组件：**用序列号/心跳/接收时间识别网络问题，以跨源、成交和订单簿关系确认行情真实性；异构数据联合检测先做各模态特征再融合判定。
- **指标 / 约束：**真实极端行情应保留并打标签；判断需结合市场状态、同类标的、上游日志和多个时间尺度。

### 6.3 实时数据监控系统

- **核心概念：**实时监控系统包括采集、指标/特征、规则/模型、状态、告警、可视化与处置闭环。
- **方法 / 系统组件：**滑窗计算收益、价差、量、延迟等特征，使用稳健统计/在线模型自适应阈值；新闻流增加实体、去重和情感突变处理，跨节点以 PTP/NTP 和事件时间校准。
- **指标 / 约束：**关键参数是窗口、基线更新率、允许迟到、告警抑制和恢复阈值；第 6.3.2 源稿无“答案”标签，应结合其知识点复习架构组成。

### 6.4 统计与机器学习异常检测

- **核心概念：**统计法可解释且轻量，孤立森林/LSTM 等模型处理多维非线性，但都受非平稳影响。
- **方法 / 系统组件：**先用稳健 Z-score/MAD 与动态分位基线筛查，再用孤立森林或注意力 LSTM 综合时序上下文；市场状态切换时重估阈值或在线更新。
- **指标 / 约束：**比较检测延迟、召回、误报、资源占用和可解释性；训练/阈值数据不能混入未来信息。

### 6.5 高频数据异常检测优化

- **核心概念：**高频异常检测要在极短预算内联合检查传输、完整性、市场结构和多档盘口。
- **方法 / 系统组件：**规则层硬件/流式快速拦截，模型层结合滑窗、波动状态和多维 Level2/3 特征复核；FPGA 适合固定价差/序列规则，深度模型处理复杂组合模式。
- **指标 / 约束：**关注尾延迟、每事件开销、状态内存、误报和漏报；强一致需求只用于必要状态，避免全链路同步阻塞。

### 6.6 分布式数据一致性监控

- **核心概念：**分布式一致性监控判断各副本/中心对同一事件与状态的版本、顺序和结果是否一致。
- **方法 / 系统组件：**用事件 ID、窗口摘要/哈希、版本向量与状态机校验，结合时钟同步、日志重放和冲突解决；审计可用不可篡改日志，跨境冲突按 CRDT 或共识协议的语义选择。
- **指标 / 约束：**CAP 权衡需按行情、订单簿和审计链路区分；比较收敛时间、错误状态暴露时长、共识延迟和分区恢复能力。

## 题型与答题框架

- **概念 / 说明题（5 题）：**先给出对象的精确定义与数据边界，再说明字段或组成、工作机制、量化岗位用途，最后补充不适用条件和常见混淆。
- **方案设计 / 故障处理题（23 题）：**按“输入与语义 → 清洗/计算 → 状态与存储 → 输出 → 监控与恢复”展开；排障题先建立基线并分层定位，再给验证实验、修复和回归。
- **比较 / 选型题（7 题）：**先固定负载和 SLO，再从延迟、吞吐、一致性、状态/查询模式、容错、成本、运维与合规逐维比较，给出条件化结论而非绝对优劣。

本章的答案最终要落到可验证约束，例如：阈值要有季节性/波动状态，监控覆盖率、延迟分位、缺口、重复、跨源偏差和误报；真实极端行情应保留并打标签；关键参数是窗口、基线更新率、允许迟到、告警抑制和恢复阈值；比较检测延迟、召回、误报、资源占用和可解释性；关注尾延迟、每事件开销、状态内存、误报和漏报；CAP 权衡需按行情、订单簿和审计链路区分。

## 高频易错点

- 把极端行情全部删除。
- 静态阈值跨所有市场状态复用。
- 只算模型准确率不算检测延迟。
- 把 CAP 一致性当数据质量准确性。
- 告警后没有隔离补数与复盘闭环。

## 复习顺序

1. **核心必会：**先掌握 6.1—6.3 的质量维度、异常分类和监控架构，能区分数据故障与真实市场异常。
2. **进阶：**再学习 6.4—6.6 的动态模型、硬件检测与跨节点一致性校验。
3. **查漏：**回查阈值状态化、告警抑制、跨源验证、时钟同步和冲突收敛。
