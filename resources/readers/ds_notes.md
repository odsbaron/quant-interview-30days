# 导读

这份文档不是简单的资料索引，而是一套围绕“数据结构如何服务笔试与面试解题”的系统学习材料。

## 核心概念

### 输入规模与增长率

算法分析关注输入规模 n 变大时，运行时间和额外空间如何增长。常数项、低阶项通常被忽略，因为它们不会改变长期增长趋势。例如 `3n + 100` 记为 O(n)，`2n^2 + n` 记为 O(n^2)。

### 大 O、Omega、Theta

- O 表示上界：算法开销最多按某个量级增长。
- Omega 表示下界：算法开销至少按某个量级增长。
- Theta 表示紧确界：上下界同阶。

笔试中如果没有特别说明，复杂度通常回答大 O。

### 时间复杂度常见判断

- 单次赋值、比较、下标访问：O(1)。
- 一层循环遍历 n 个元素：O(n)。
- 双层循环都依赖 n：通常 O(n^2)。
- 每次把搜索区间减半：O(log n)。
- 每层处理 n 个元素且递归层数 log n：O(n log n)。
- 每个元素选或不选：O(2^n)。

### 空间复杂度常见判断

空间复杂度计算额外空间，不包括输入本身。常见来源包括辅助数组、哈希表、递归调用栈。递归深度为 n 时调用栈为 O(n)，递归深度为 log n 时为 O(log n)。

### 递归三要素

1. 定义函数含义：函数返回什么、参数表示什么。
2. 终止条件：规模足够小，可以直接返回。
3. 递推关系：把原问题转化为更小的问题。

例如阶乘：`fact(n) = n * fact(n - 1)`，终止条件是 `n == 0`。

## 题型识别

- 出现“分析这段代码复杂度”：数循环次数、递归次数、额外数据结构大小。
- 出现“折半、二分、每次减半”：优先考虑 O(log n)。
- 出现“枚举所有子集、所有组合”：常见 O(2^n) 或更高。
- 出现“递归写法、分治”：写递推式，例如 `T(n)=2T(n/2)+O(n)`。
- 出现“空间优化”：区分输入空间、输出空间、辅助空间。

## 解题模板

### 复杂度分析模板

```text
1. 明确 n 的含义。
2. 找主导操作：循环体、递归调用、数据结构操作。
3. 计算执行次数：相加看最大项，相乘看嵌套。
4. 忽略常数和低阶项。
5. 说明额外空间来源：变量、数组、哈希表、调用栈。
```

### 递归函数模板

```python
def solve(problem):
    if is_base_case(problem):
        return base_value
    smaller = shrink(problem)
    sub_answer = solve(smaller)
    return combine(problem, sub_answer)
```

### 分治模板

```python
def divide_and_conquer(nums, left, right):
    if left == right:
        return nums[left]
    mid = (left + right) // 2
    a = divide_and_conquer(nums, left, mid)
    b = divide_and_conquer(nums, mid + 1, right)
    return merge(a, b)
```

## 代表习题

### 1. 分析单层循环求和

题目：给定数组 `nums`，计算所有元素之和。

思路：遍历每个元素一次，维护一个整数变量 `total`。时间复杂度是 O(n)，额外空间只有常数个变量，因此是 O(1)。

易错点：不要把输入数组算入额外空间；也不要因为 Python 的整数对象细节改变笔试级别分析。

### 2. 分析双层循环配对

题目：统计数组中所有 `i < j` 的元素对数量。

思路：外层 i 从 0 到 n-1，内层 j 从 i+1 到 n-1，总次数为 `n(n-1)/2`，复杂度 O(n^2)。额外空间 O(1)。

易错点：虽然内层不是每次都跑 n 次，但数量级仍然是二次。

### 3. 二分查找复杂度

题目：在升序数组中查找 target。

思路：每轮丢弃一半区间，最多需要 `log2(n)` 轮，所以时间 O(log n)。迭代写法额外空间 O(1)，递归写法调用栈 O(log n)。

易错点：递归二分和迭代二分时间相同，但空间不同。

### 4. 递归阶乘

题目：实现 `n!`。

思路：`fact(0)=1`，`fact(n)=n*fact(n-1)`。递归深度 n，每层做 O(1) 工作，时间 O(n)，空间 O(n)。

易错点：忘记终止条件会无限递归；终止条件写成 `n == 1` 时也要考虑 `n = 0`。

### 5. 斐波那契递归与记忆化

题目：求第 n 个斐波那契数。

思路：朴素递归会重复计算大量子问题，时间接近 O(2^n)，空间 O(n)。加入记忆化后，每个状态只算一次，时间 O(n)，空间 O(n)。

易错点：只写递归式不等于高效；遇到重叠子问题要想到缓存或动态规划。

### 6. 汉诺塔移动次数

题目：n 个盘子从 A 移到 C。

思路：先把 n-1 个从 A 移到 B，再移动最大盘，再把 n-1 个从 B 移到 C。递推式 `T(n)=2T(n-1)+1`，因此移动次数为 `2^n - 1`，时间 O(2^n)，递归栈 O(n)。

易错点：递归深度是 n，不是移动次数；空间复杂度看同时存在的调用栈。

## 复杂度速查

| 场景 | 时间复杂度 | 空间复杂度 |
|---|---:|---:|
| 常数操作 | O(1) | O(1) |
| 遍历数组 | O(n) | O(1) |
| 复制数组 | O(n) | O(n) |
| 二分查找 | O(log n) | O(1) 或 O(log n) |
| 双层枚举 | O(n^2) | O(1) |
| 归并排序思想 | O(n log n) | O(n) |
| 全子集枚举 | O(2^n) | O(n) 到 O(2^n) |

## 常见错误

- 把常数时间误写成 O(n)，例如数组下标访问。
- 嵌套循环未判断内层是否真的依赖 n。
- 忽略递归调用栈空间。
- 分析复杂度时混淆输入规模，例如矩阵应使用 m、n 两个维度。
- 只看代码行数，不看每行执行次数。
- 把输出结果占用的空间和辅助空间混在一起；面试时应说明口径。

## 核心概念

### 数组

数组用连续内存存放相同类型或引用，支持按下标 O(1) 随机访问。插入和删除如果发生在中间，需要搬移后续元素，时间 O(n)。数组的缓存局部性好，顺序遍历通常很快。

### 动态列表

Python `list` 是动态数组。`append` 均摊 O(1)，当容量不足时会扩容并搬移元素，单次扩容可能 O(n)。`pop()` 默认删除末尾是 O(1)，`pop(0)` 删除开头会移动元素，是 O(n)。

### 链表

链表由节点组成，每个节点保存值和指向下一个节点的引用。链表不支持 O(1) 下标访问，查找第 k 个节点需要 O(k)。但如果已经拿到前驱节点，插入和删除可以 O(1) 完成。

### 哨兵节点

哨兵节点是一个虚拟头节点，常用于统一删除头节点和非头节点的逻辑。很多链表题中，`dummy = ListNode(0, head)` 可以减少分支判断。

### 双指针

数组中双指针常用于有序数组、原地去重、左右夹逼。链表中快慢指针常用于找中点、判断环、删除倒数第 k 个节点。

## 题型识别

- “原地删除、原地移动、保持相对顺序”：数组双指针。
- “有序数组两数之和、接雨水类左右收缩”：左右指针。
- “删除链表节点、合并链表”：哨兵节点。
- “倒数第 k 个、链表中点、是否有环”：快慢指针。
- “反转链表、K 个一组”：指针重连，先保存 next。

## 解题模板

### 数组原地过滤模板

```python
write = 0
for read in range(len(nums)):
    if keep(nums[read]):
        nums[write] = nums[read]
        write += 1
return write
```

### 有序数组双指针模板

```python
left, right = 0, len(nums) - 1
while left < right:
    s = nums[left] + nums[right]
    if s == target:
        return left, right
    if s < target:
        left += 1
    else:
        right -= 1
return -1, -1
```

### 链表删除模板

```python
dummy = ListNode(0)
dummy.next = head
prev, cur = dummy, head
while cur:
    if should_delete(cur):
        prev.next = cur.next
    else:
        prev = cur
    cur = cur.next
return dummy.next
```

### 反转链表模板

```python
prev, cur = None, head
while cur:
    nxt = cur.next
    cur.next = prev
    prev = cur
    cur = nxt
return prev
```

## 代表习题

### 1. 删除有序数组中的重复项

题目：给定升序数组，原地保留每个元素一次，返回新长度。

思路：使用快慢指针。慢指针 `write` 指向下一个写入位置，快指针 `read` 扫描数组。遇到与前一个保留元素不同的值时写入。时间 O(n)，空间 O(1)。

易错点：空数组要返回 0；比较对象应是最后一个保留元素，而不是总和 `read - 1`。

### 2. 移动零

题目：把数组中的 0 移到末尾，保持非零元素相对顺序。

思路：第一遍把非零元素写到前面，第二遍把剩余位置填 0。时间 O(n)，空间 O(1)。也可以用交换法，但要注意交换次数。

易错点：写入非零元素后忘记补零；补零起点应是 `write`。

### 3. 有序数组两数之和

题目：升序数组中找到两个数之和为 target。

思路：左右指针。和小则左指针右移，和大则右指针左移。每次移动都会排除一批不可能答案，时间 O(n)，空间 O(1)。

易错点：如果题目返回 1-based 下标，别直接返回 0-based。

### 4. 反转单链表

题目：给定链表头节点，返回反转后的头节点。

思路：遍历时维护 `prev` 和 `cur`。每轮先保存 `cur.next`，再把 `cur.next` 指向 `prev`，然后整体前进。时间 O(n)，空间 O(1)。

易错点：重连指针前不保存 `next` 会丢失后续链表。

### 5. 合并两个有序链表

题目：合并两个升序链表为一个升序链表。

思路：使用哨兵节点和尾指针 `tail`。每次选择较小节点接到结果链表后面。任一链表为空后接上剩余部分。时间 O(m+n)，空间 O(1)。

易错点：循环结束后忘记接上剩余链表；比较时处理相等值即可任选一边。

### 6. 删除倒数第 N 个节点

题目：删除链表倒数第 n 个节点。

思路：使用哨兵节点。快指针先走 n 步，然后快慢一起走，直到快指针到末尾，此时慢指针在待删节点前驱。时间 O(L)，空间 O(1)。

易错点：删除头节点时如果没有哨兵会写很多特殊分支；快指针移动步数要和循环条件配套。

## 复杂度

| 操作 | 数组 / Python list | 单链表 |
|---|---:|---:|
| 访问第 i 个元素 | O(1) | O(n) |
| 查找指定值 | O(n) | O(n) |
| 末尾追加 | 均摊 O(1) | 有尾指针 O(1)，否则 O(n) |
| 开头插入 | O(n) | O(1) |
| 中间插入 | O(n) | 已知前驱 O(1)，否则 O(n) |
| 删除末尾 | O(1) | O(n) |
| 删除指定节点 | O(n) | 已知前驱 O(1)，否则 O(n) |

## 常见错误

- 用 `pop(0)` 实现队列，导致整体退化为 O(n^2)。
- 链表删除头节点时漏处理，建议使用哨兵节点。
- 反转链表时没有提前保存 `next`。
- 双指针循环条件写错，造成越界或漏答案。
- Python list 切片会复制新列表，空间不是 O(1)。
- 把链表“节点对象”和“节点值”混淆。

## 复盘清单

- 题目是否要求原地修改？
- 数组是否有序？如果有序，能否用双指针或二分？
- 链表是否可能删除头节点？是否需要 dummy？
- 指针重连前是否保存了后继节点？
- 返回的是新长度、新头节点，还是修改后的原数组？
- 是否明确给出时间和额外空间复杂度？

## 核心概念

### 栈

栈只允许在一端插入和删除，遵循后进先出。Python 中常用 `list.append` 和 `list.pop` 实现栈，二者均摊 O(1)。典型应用是括号匹配、函数调用栈、撤销操作、单调栈。

### 队列

队列一端入队，另一端出队，遵循先进先出。Python 中应使用 `collections.deque` 的 `append` 和 `popleft`，都是 O(1)。不要用 `list.pop(0)` 实现频繁出队。

### 双端队列

双端队列允许两端插入和删除。`collections.deque` 支持 `append`、`appendleft`、`pop`、`popleft`，适合滑动窗口、0-1 BFS、任务调度等场景。

### 单调栈

单调栈维护栈内元素单调递增或递减，用来寻找“下一个更大元素”“左侧第一个更小元素”等。每个元素最多入栈一次、出栈一次，因此整体 O(n)。

### 单调队列

单调队列常用于固定长度滑动窗口最大值。队首保存当前窗口最大值下标，队尾移除不可能成为最大值的元素。每个元素最多进出一次，整体 O(n)。

## 题型识别

- “最近的未匹配元素、括号、撤销”：栈。
- “先来先服务、层序遍历、最短步数扩散”：队列。
- “滑动窗口最大/最小值”：单调队列。
- “下一个更大、每日温度、柱状图”：单调栈。
- “两端都要操作、窗口左右移动”：双端队列。

### BFS 队列模板

```python
q = deque([start])

    node = q.popleft()
```

## 代表习题

### 1. 有效括号

题目：判断字符串中的括号是否正确闭合。

思路：左括号入栈；遇到右括号时，栈顶必须是对应左括号。最后栈为空才合法。时间 O(n)，空间 O(n)。

易错点：右括号出现时栈为空要立即返回 False；最后还要检查是否有未闭合左括号。

### 2. 最小栈

题目：设计支持 `push`、`pop`、`top`、`getMin` 均为 O(1) 的栈。

思路：用一个普通栈保存值，另一个辅助栈保存当前最小值。压入时辅助栈同步压入 `min(x, 当前最小)`，弹出时同步弹出。时间 O(1)，空间 O(n)。

易错点：辅助栈不是只在出现更小值时才压入，若这样处理重复最小值时要额外计数。

### 3. 用两个栈实现队列

题目：实现先进先出的队列。

思路：`in_stack` 负责入队，`out_stack` 负责出队。当 `out_stack` 为空时，把 `in_stack` 全部倒入 `out_stack`。每个元素最多倒一次，均摊 O(1)。

易错点：每次出队都倒栈会退化；只有 `out_stack` 空时才倒。

### 4. 最近的更大元素

题目：对数组中每个元素，求右侧第一个更大的元素。

思路：维护一个单调递减栈，栈中保存尚未找到答案的下标。当前元素大于栈顶元素时，它就是栈顶下标的答案。时间 O(n)，空间 O(n)。

易错点：栈里通常保存下标而不是值，因为需要写入对应位置答案。

### 5. 滑动窗口最大值

题目：给定数组和窗口大小 k，返回每个窗口最大值。

思路：用单调递减队列保存下标。队首过期就弹出；新元素入队前从队尾删除小于等于它的元素。队首始终是最大值下标。时间 O(n)，空间 O(k)。

易错点：判断过期用下标，不要只比较值；窗口形成后再记录答案。

### 6. 岛屿或迷宫 BFS

题目：从起点扩散，求最短步数或访问所有可达格子。

思路：队列按层扩散，首次到达某点就是最短距离。维护 visited 防止重复入队。时间 O(V+E)，网格中常写作 O(mn)。空间 O(mn)。

易错点：入队时就标记 visited，避免同一个点被多个前驱重复入队。

| 结构 / 操作 | 时间复杂度 | 空间说明 |
|---|---:|---|
| 栈 push/pop | O(1) 均摊 | 存 n 个元素 O(n) |
| deque 入队/出队 | O(1) | 存 n 个元素 O(n) |
| list pop(0) | O(n) | 频繁使用会退化 |
| 单调栈整题 | O(n) | 每个元素最多进出一次 |
| 单调队列整题 | O(n) | 队列最多保存 k 个候选 |
| BFS | O(V+E) | visited 和队列 |

## 常见错误

- 用 `list.pop(0)` 实现队列。
- 括号匹配只检查过程，不检查最终栈是否为空。
- 单调栈中保存值导致无法回填答案位置。
- 滑动窗口最大值忘记删除过期下标。
- BFS 出队后才标记 visited，导致重复入队。
- 混淆队列的 FIFO 和栈的 LIFO。

- 是否需要下标来判断距离、过期或写答案？
- 单调结构维护的是递增还是递减？

## 核心概念

### 哈希表

哈希表用哈希函数把 key 映射到数组桶位置。理想情况下，插入、删除、查找平均 O(1)。但若哈希冲突严重，最坏可能退化到 O(n)。实际语言的哈希表会通过扩容、扰动、链地址或开放寻址等方式降低冲突影响。

### 哈希冲突

两个不同 key 映射到同一桶就是冲突。常见解决方式：

- 链地址法：每个桶挂一个链表或小容器。
- 开放寻址：冲突后按照某种探测序列寻找下一个空桶。

### dict 与 set

- `dict`：从 key 到 value 的映射，适合记录频次、下标、前缀信息。
- `set`：只关心存在性，适合去重、快速 membership 查询。

Python 的 key 必须可哈希，列表、字典等可变对象不能直接作为 key；元组可以作为复合 key，前提是内部元素也可哈希。

### 查找算法

线性查找适用于无序或规模较小的数据，时间 O(n)。二分查找要求数据有序或答案具有单调性，时间 O(log n)。如果题目是“在答案范围内找最小可行值”，也常用二分答案。

### 边界二分

查找第一个大于等于 target 的位置称为 lower_bound；查找第一个大于 target 的位置称为 upper_bound。边界题要统一区间定义，推荐左闭右开 `[left, right)`。

## 题型识别

- “是否出现过、去重、频次统计”：set 或 dict。
- “两数之和、配对、补数”：哈希表记录已见元素。
- “分组异位词、坐标状态”：复合 key 或规范化 key。
- “数组有序、旋转有序、查找插入位置”：二分。
- “最大值最小、最小值最大、可行性单调”：二分答案。

## 代表习题

### 1. 两数之和

题目：给定数组和 target，返回两个数下标，使它们之和等于 target。

思路：从左到右遍历，用字典记录已见数字的下标。对当前数字 x，检查 `target - x` 是否已出现。时间 O(n)，空间 O(n)。

易错点：先查再存，避免同一个元素被使用两次；重复数字要保留合适下标。

### 2. 有效字母异位词

题目：判断两个字符串是否由相同字符及相同次数组成。

思路：统计第一个字符串频次，再扣减第二个字符串频次；或用长度为 26 的数组。时间 O(n)，空间 O(k)，k 是字符种类数。

易错点：字符集不一定只有小写英文字母，若题目没限制，应使用字典。

### 3. 最长连续序列

题目：给定无序整数数组，求最长连续序列长度。

思路：把所有数放入 set。只从没有前驱 `x-1` 的数开始向后扩展，避免重复计算。每个数最多被访问常数次，时间 O(n)，空间 O(n)。

易错点：如果从每个数都向后扩展，最坏会 O(n^2)。

### 4. 二分查找

题目：在升序数组中查找 target 的下标。

思路：维护搜索区间，每轮比较中点。若中点值小于 target，左边界右移；若大于 target，右边界左移；相等返回。时间 O(log n)，空间 O(1)。

易错点：循环条件和边界更新必须匹配；`mid` 推荐写成 `left + (right - left) // 2`，虽然 Python 不溢出，但思路通用。

### 5. 查找插入位置

题目：给定升序数组和 target，返回 target 应插入的位置。

思路：求第一个大于等于 target 的下标，即 lower_bound。左闭右开模板返回的 `left` 就是答案。时间 O(log n)。

易错点：不要在找不到时返回 -1；插入位置可以是 `len(nums)`。

### 6. 在排序数组中查找元素的第一个和最后一个位置

题目：数组有重复元素，返回 target 的左右边界。

思路：左边界是 lower_bound(target)，右边界是 lower_bound(target + 1) - 1；如果不是整数，也可以写 upper_bound(target) - 1。时间 O(log n)。

易错点：找到一个 target 后向左右线性扩展会退化为 O(n)。

## 复杂度

| 方法 | 适用前提 | 时间复杂度 | 空间复杂度 |
|---|---|---:|---:|
| 线性查找 | 无序数据 | O(n) | O(1) |
| 哈希查找 | key 可哈希 | 平均 O(1)，最坏 O(n) | O(n) |
| 二分查找 | 数据有序或单调答案 | O(log n) | O(1) |
| 频次统计 | 需要计数 | O(n) | O(k) |
| 排序后查找 | 可改变顺序或保留映射 | O(n log n) | 依实现 |

## 常见错误

- 忘记哈希表最坏复杂度可能退化，但笔试通常回答平均 O(1)。
- 使用可变对象作为 dict key。
- 两数之和先存后查，导致同一元素重复使用。
- 二分边界更新写成 `left = mid` 或 `right = mid` 时造成死循环。
- 没有确认数组是否有序就使用二分。
- 边界二分找到一个位置后线性扩展，破坏 O(log n)。

## 核心概念

二分查找每一步把候选区间缩小一半。它不是“只能查有序数组”的技巧，而是“在单调判定空间中定位临界点”的方法。只要存在一个谓词 `check(x)`，使得答案空间呈现 `False...False, True...True` 或 `True...True, False...False`，就可以考虑二分。

常见搜索对象有三类：

1. **索引二分**：在有序数组中找目标值、左边界、右边界、插入点。
2. **值域二分**：在数值答案范围中找最小可行值或最大可行值，例如最小速度、最小容量。
3. **结构二分**：在矩阵、旋转数组、山脉数组等具有局部或整体单调性的结构中查找。

闭区间模板把候选区间定义为 `left <= answer <= right`，循环条件常用 `while left <= right`。左闭右开模板把候选区间定义为 `left <= answer < right`，循环条件常用 `while left < right`。二者都可用，关键是全程保持同一个区间语义。

## 题型识别

- 题目中出现“有序数组”“升序”“非递减”“查找目标值”：优先考虑二分。
- 要求 `O(log n)`：通常是二分、堆或平衡树，数组查询类多半是二分。
- 需要找“第一个不小于”“最后一个不大于”“插入位置”：边界二分。
- 题目问“最小的最大值”“最大的最小值”“满足条件的最小 x”：答案二分。
- 给定旋转有序数组：每次至少有一半区间有序，可以二分排除。
- 矩阵每行有序且行间有序：可把二维坐标映射成一维索引二分。

## 解题模板

### 模板一：普通闭区间查找

```python
def binary_search(nums, target):
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = left + (right - left) // 2
        if nums[mid] == target:
            return mid
        if nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1
```

### 模板二：找左边界，即第一个 `>= target` 的位置

```python
def lower_bound(nums, target):
    left, right = 0, len(nums)
    while left < right:
        mid = left + (right - left) // 2
        if nums[mid] < target:
            left = mid + 1
        else:
            right = mid
    return left
```

### 模板三：答案二分，找最小可行值

```python
def min_feasible(lo, hi, check):
    left, right = lo, hi
    while left < right:
        mid = left + (right - left) // 2
        if check(mid):
            right = mid
        else:
            left = mid + 1
    return left
```

写答案二分前先明确三件事：答案范围 `[lo, hi]`、`check(mid)` 的含义、要找最小可行还是最大可行。

## 代表习题详解

### 1. 在排序数组中查找目标值

给定升序数组和 `target`，返回任意一个目标下标，不存在返回 `-1`。这是最基础的二分。每次比较 `nums[mid]` 与 `target`：若小于目标，说明左侧和 `mid` 都不可能是答案，令 `left = mid + 1`；若大于目标，令 `right = mid - 1`。复杂度 `O(log n)`，空间 `O(1)`。

### 2. 搜索插入位置

给定无重复升序数组，返回目标存在时的下标；不存在时返回应插入的位置。本质是找第一个 `>= target` 的位置。使用 `lower_bound`，最后 `left` 可能等于 `len(nums)`，表示应插入到末尾。不要在找不到时返回 `mid`，因为最后一次 `mid` 不一定是插入点。

### 3. 在排序数组中查找元素的第一个和最后一个位置

数组可含重复元素，需要返回 `[first, last]`。做两次边界二分：`first = lower_bound(nums, target)`，`after = lower_bound(nums, target + 1)` 对整数可行；更通用的写法是找第一个 `> target`，再令 `last = upper - 1`。若 `first == len(nums)` 或 `nums[first] != target`，则不存在。复杂度仍是 `O(log n)`。

### 4. 搜索旋转排序数组

数组原本升序后被旋转，如 `[4,5,6,7,0,1,2]`。每次看 `nums[left] <= nums[mid]` 是否成立，成立表示左半段有序，否则右半段有序。若目标落在有序半段内，保留该半段；否则丢弃。难点是边界比较必须使用闭区间语义，例如左有序时判断 `nums[left] <= target < nums[mid]`。

### 5. 爱吃香蕉的最小速度

给定每堆香蕉数量和时限 `h`，求吃完的最小速度 `k`。答案范围是 `[1, max(piles)]`。定义 `check(k)`：以速度 `k` 是否能在 `h` 小时内吃完。`k` 越大越容易满足，所以可找最小可行值。每次计算总小时数 `sum((p + k - 1) // k for p in piles)`。复杂度 `O(n log max(piles))`。

### 6. 有序矩阵搜索

若矩阵满足每行升序，且下一行第一个数大于上一行最后一个数，可把 `m * n` 个元素看成一维数组。给定一维下标 `idx`，映射到 `row = idx // n`、`col = idx % n`。然后执行普通二分。复杂度 `O(log(mn))`。

## 复杂度

- 普通数组二分：时间 `O(log n)`，空间 `O(1)`。
- 边界二分：通常做一到两次二分，时间仍是 `O(log n)`。
- 答案二分：时间通常是 `O(check_cost * log range)`，空间取决于 `check`。
- 递归二分：时间 `O(log n)`，递归栈空间 `O(log n)`。

## 常见错误

- 没有确认单调性，看到“查找”就二分。
- `while left < right` 和 `while left <= right` 混用，导致漏查或死循环。
- 更新边界时写成 `left = mid` 或 `right = mid`，但区间无法收缩。
- 计算右边界时忘记目标不存在的情况，访问 `nums[left]` 越界。
- 旋转数组中重复元素会破坏“哪一半有序”的判断，需要额外处理 `left += 1` 等退化逻辑。
- 答案二分的 `check` 方向写反，最小可行和最大可行模板混淆。

## 复盘清单

- 搜索空间是什么：下标、值域，还是隐式答案？
- 单调性是什么：`False -> True` 还是 `True -> False`？
- 区间语义是否从头到尾一致？
- `mid` 被排除还是保留？边界更新是否保证收缩？
- 返回 `left`、`right`、`mid` 还是 `-1`？是否处理空数组？
- 复杂度是否写成 `O(log n)` 或 `O(check_cost * log range)`？

## 核心概念

排序是把一组元素按关键字重新排列。评价排序算法时通常看五个维度：时间复杂度、空间复杂度、稳定性、原地性、对输入分布的敏感程度。

**稳定性**指相等关键字的元素在排序后相对顺序不变。例如按成绩排序后仍希望同成绩学生保持原录入顺序，就需要稳定排序。插入排序、冒泡排序、归并排序通常可写成稳定；选择排序、快速排序、堆排序通常不稳定。

**原地排序**指额外空间为 `O(1)` 或很小。选择、插入、冒泡、堆排序可原地；归并排序典型实现需要 `O(n)` 辅助数组。

比较排序仅通过元素比较确定顺序，平均时间复杂度下界是 `O(n log n)`。计数排序、桶排序、基数排序利用取值范围或位数信息，不属于纯比较排序，在特定条件下可达线性时间。

## 题型识别

- 要求“按某个字段排序”：使用语言内置排序或自定义 key。
- 问“第 k 大 / 第 k 小”：可排序、堆、快速选择；若只要一个元素，完整排序不一定最优。
- 问“合并区间”“安排会议”：通常先按起点或终点排序，再线性扫描。
- 问“逆序对数量”：归并排序过程中计数。
- 数据范围小，如分数 `0..100`：考虑计数排序。
- 链表排序要求 `O(n log n)` 和低空间：常用归并排序。
- 接近有序的小数组：插入排序常很高效。

## 解题模板

### 插入排序

```python
def insertion_sort(nums):
    for i in range(1, len(nums)):
        base = nums[i]
        j = i - 1
        while j >= 0 and nums[j] > base:
            nums[j + 1] = nums[j]
            j -= 1
        nums[j + 1] = base
    return nums
```

### 归并排序

```python
def merge_sort(nums):
    if len(nums) <= 1:
        return nums[:]
    mid = len(nums) // 2
    left = merge_sort(nums[:mid])
    right = merge_sort(nums[mid:])
    return merge(left, right)
```

### 快速排序分区

```python
def partition(nums, left, right):
    pivot = nums[right]
    i = left
    for j in range(left, right):
        if nums[j] <= pivot:
            nums[i], nums[j] = nums[j], nums[i]
            i += 1
    nums[i], nums[right] = nums[right], nums[i]
    return i
```

## 代表习题详解

### 1. 排序数组

要求实现 `sortArray(nums)`。面试中可写归并排序或随机快速排序。归并排序最坏 `O(n log n)` 更稳定，代价是 `O(n)` 空间；快速排序平均 `O(n log n)`，若 pivot 选得差会退化到 `O(n^2)`，可用随机 pivot 降低风险。若题目平台会卡递归深度，Python 中要注意递归层数。

### 2. 合并区间

给定若干区间 `[start, end]`，合并重叠区间。先按 `start` 升序排序，然后维护结果列表最后一个区间。若当前 `start <= last_end`，说明重叠，更新 `last_end = max(last_end, end)`；否则追加新区间。排序 `O(n log n)`，扫描 `O(n)`。

### 3. 数组中的第 k 大元素

直接排序后返回 `nums[-k]`，时间 `O(n log n)`。更优做法是快速选择：把目标下标设为 `len(nums) - k`，每轮分区后只递归包含目标的一边，平均 `O(n)`，最坏 `O(n^2)`。若数据流持续变化，可用大小为 `k` 的小顶堆，时间 `O(n log k)`。

### 4. 颜色分类

数组只包含 `0, 1, 2`，要求原地排序。可以使用计数排序统计三个值出现次数，再回填；也可以使用荷兰国旗三指针：`left` 放 0，`right` 放 2，`i` 扫描。遇到 0 与 `left` 交换并前进，遇到 2 与 `right` 交换但 `i` 不前进，因为换来的元素还没检查。时间 `O(n)`。

### 5. 根据频率排序

给定元素，按出现频率或自定义规则排序。先用字典计数，再用 `sorted(items, key=...)`。关键是明确同频时的次级规则，例如按数值升序或首次出现顺序。若频率范围有限，也可以桶排序，把频率作为桶下标。

### 6. 逆序对

逆序对是 `i < j` 且 `nums[i] > nums[j]`。在归并排序合并两个有序子数组时，若 `left[i] > right[j]`，则 `left[i:]` 都大于 `right[j]`，一次性增加 `len(left) - i`。归并排序完成时也得到有序数组。时间 `O(n log n)`，空间 `O(n)`。

## 复杂度与特性对比

| 算法 | 平均时间 | 最坏时间 | 空间 | 稳定 | 适用场景 |
|---|---:|---:|---:|---|---|
| 冒泡排序 | `O(n^2)` | `O(n^2)` | `O(1)` | 是 | 教学、小规模 |
| 选择排序 | `O(n^2)` | `O(n^2)` | `O(1)` | 否 | 交换次数少 |
| 插入排序 | `O(n^2)` | `O(n^2)` | `O(1)` | 是 | 小规模、近乎有序 |
| 归并排序 | `O(n log n)` | `O(n log n)` | `O(n)` | 是 | 稳定排序、链表排序、逆序对 |
| 快速排序 | `O(n log n)` | `O(n^2)` | `O(log n)` | 否 | 工程常用、快速选择 |
| 堆排序 | `O(n log n)` | `O(n log n)` | `O(1)` | 否 | 原地且最坏有保证 |

- 只背复杂度，不看稳定性和空间要求。

- 自定义排序 key 没有覆盖题目要求的并列规则。
- 荷兰国旗算法中遇到 2 后错误地让 `i += 1`，跳过未检查元素。

## 核心概念

树是由节点和边组成的层次结构。一个节点可以有若干子节点，没有父节点的节点是根节点，没有子节点的节点是叶节点。节点深度是从根到该节点的边数，节点高度是从该节点到最远叶节点的边数。

二叉树中每个节点最多有两个孩子，通常称为左子树和右子树。遍历方式包括：

- 前序：根、左、右，适合复制树、序列化树。
- 中序：左、根、右，对 BST 会得到升序序列。
- 后序：左、右、根，适合先处理子树再汇总，例如求高度、删除树。
- 层序：按层从上到下，常用队列实现。

二叉搜索树 BST 满足：任意节点左子树所有值小于该节点，右子树所有值大于该节点。若允许重复值，必须明确重复值放左还是放右。BST 中序遍历是有序序列。理想平衡时查找、插入、删除是 `O(log n)`；退化成链时是 `O(n)`。

AVL 树是自平衡 BST，任意节点左右子树高度差的绝对值不超过 1。插入或删除后，沿回溯路径更新高度并检查平衡因子。若失衡，通过旋转恢复：

- LL：左子树的左侧过高，右旋。
- RR：右子树的右侧过高，左旋。
- LR：左子树的右侧过高，先左旋左子节点，再右旋当前节点。
- RL：右子树的左侧过高，先右旋右子节点，再左旋当前节点。

```python
from collections import deque

def level_order(root):
    if root is None:
        return []
    ans, q = [], deque([root])
    while q:
        level = []
        for _ in range(len(q)):
            node = q.popleft()
            level.append(node.val)
            if node.left:
                q.append(node.left)
            if node.right:
                q.append(node.right)
        ans.append(level)
    return ans
```

### 验证 BST 模板

```python
def is_valid_bst(root, low=None, high=None):
    if root is None:
        return True
    if low is not None and root.val <= low:
        return False
    if high is not None and root.val >= high:
        return False
    return is_valid_bst(root.left, low, root.val) and is_valid_bst(root.right, root.val, high)
```

## 代表习题详解

### 1. 二叉树最大深度

若根为空，深度为 0；否则深度为 `1 + max(left_depth, right_depth)`。这是典型后序分治，因为当前节点答案依赖左右子树答案。时间 `O(n)`，空间为递归栈 `O(h)`，其中 `h` 是树高。

### 2. 二叉树层序遍历

使用队列保存当前层节点。每次循环先记录当前队列长度，只弹出这一层的节点，并把下一层孩子加入队列。常见错误是直接 `while q` 内不断追加孩子，导致无法区分层。时间 `O(n)`，空间最坏 `O(n)`。

### 3. 验证二叉搜索树

不能只检查每个节点的左孩子小于它、右孩子大于它，因为整棵左子树都必须小于根。正确做法是递归传递上下界，或中序遍历检查序列严格递增。若题目允许重复值，要根据定义调整比较符号。时间 `O(n)`。

### 4. 二叉搜索树第 k 小元素

BST 中序遍历得到升序序列。可以完整中序后返回第 `k` 个，也可以迭代中序并计数，到第 `k` 个立即返回。若树节点维护子树大小，还能在 `O(h)` 内选择第 k 小。普通做法时间 `O(h + k)`，空间 `O(h)`。

### 5. 删除 BST 中的节点

删除节点分三种情况：叶节点直接删除；只有一个孩子时用孩子替代；有两个孩子时，用右子树最小节点或左子树最大节点替代当前值，再删除那个替代节点。删除后普通 BST 不保证平衡，最坏仍可能退化。AVL 删除还需要在回溯路径上更新高度和旋转。

### 6. 判断平衡二叉树

对每个节点判断左右子树高度差是否不超过 1。朴素做法会重复计算高度，最坏 `O(n^2)`。优化做法是后序返回高度；若子树已不平衡，返回哨兵 `-1`，上层直接传播失败。这样每个节点只访问一次，时间 `O(n)`。

### 7. AVL 插入与旋转

AVL 插入先按 BST 规则插入新值，然后从插入路径向上更新高度。若某节点平衡因子 `height(left) - height(right)` 大于 1 或小于 -1，则根据新值落在外侧还是内侧选择 LL、RR、LR、RL 旋转。旋转后仍保持 BST 的中序顺序不变，同时降低局部高度。

## 复杂度

- 普通二叉树遍历：时间 `O(n)`，空间 `O(h)` 或 BFS 的 `O(w)`，`h` 是高度，`w` 是最大宽度。
- 普通 BST 查找、插入、删除：平均 `O(log n)`，最坏 `O(n)`。
- AVL 查找、插入、删除：时间 `O(log n)`，旋转次数插入通常为常数级，删除可能沿路径多次调整；空间递归实现为 `O(log n)`。
- 构造树：若用哈希表存中序位置，时间 `O(n)`，空间 `O(n)`。

## 常见错误

- 把“节点高度”和“节点深度”混淆。
- 验证 BST 只比较父子节点，忽略祖先上下界。
- 递归路径列表没有回溯，导致不同路径互相污染。
- 层序遍历没有固定当前层长度。
- 删除 BST 两孩子节点后，只替换值却忘记删除后继节点。
- AVL 旋转后没有更新相关节点高度，或 LR/RL 双旋顺序写反。
- 对空树、单节点树没有单独考虑。

- 当前节点要向父节点返回什么信息？高度、是否平衡、最大路径和，还是多个值？
- 是否能利用 BST 中序有序或上下界约束？
- 递归终止条件是否覆盖空节点？
- 路径状态是否正确回溯？
- AVL 或 BST 操作后是否仍保持中序有序？高度是否更新？

## 核心概念

### 1. 堆的定义

堆通常指二叉堆，是一棵完全二叉树，并满足堆序性质。

- 小顶堆：任意节点值都不大于其子节点值，堆顶是全局最小值。
- 大顶堆：任意节点值都不小于其子节点值，堆顶是全局最大值。
- 完全二叉树：除最后一层外每层都满，最后一层从左到右填充，因此可以用数组紧凑存储。

数组下标关系，假设节点下标为 `i`：

- 父节点：`(i - 1) // 2`
- 左孩子：`2 * i + 1`
- 右孩子：`2 * i + 2`

### 2. 基本操作

- `peek`：查看堆顶，时间复杂度 `O(1)`。
- `push`：把元素放到数组末尾，再向上调整 `sift_up`，时间复杂度 `O(log n)`。
- `pop`：交换堆顶和末尾，删除末尾，再对新堆顶向下调整 `sift_down`，时间复杂度 `O(log n)`。
- `heapify`：从最后一个非叶子节点逆序向下调整，整体 `O(n)`，不是 `O(n log n)`。
- 堆排序：先建大顶堆，再反复把堆顶换到数组末尾，时间 `O(n log n)`，原地但不稳定。

### 3. Top K 的核心思想

Top K 问题只关心前 K 个极值，不要求全量排序。固定大小堆是最常用模板：

- 求最大的 K 个：维护大小为 K 的小顶堆。堆顶是当前 Top K 中最小的候选；新元素若大于堆顶，就替换堆顶。
- 求最小的 K 个：维护大小为 K 的大顶堆。Python 中可用负数模拟。
- 若需要按顺序输出，最后再对堆中 K 个元素排序，额外 `O(K log K)`。

## 题型识别

看到以下信号优先考虑堆：

- 题目包含“第 K 大/第 K 小”“前 K 个”“Top K”“K 个最接近”。
- 数据流场景：元素不断到来，需要随时查询当前极值、中位数、Top K。
- 多路归并：合并 K 个有序链表、合并多个有序数组、最小区间覆盖 K 个列表。
- 每次都要取当前最小/最大：会议室、任务调度、Dijkstra 的优先队列版本。
- 需要保留 K 个候选而不是排序全部数据。

不一定用堆的情况：

- 需要完整有序结果：直接排序通常更简单。
- 第 K 大且允许修改数组：快速选择平均 `O(n)`，比堆的 `O(n log K)` 更优。
- K 接近 n 且只做一次查询：排序可能更直接，常数更低。

## 解题模板

### 模板 1：固定大小小顶堆求 Top K 大

```python
import heapq

def top_k_largest(nums, k):
    if k <= 0:
        return []
    heap = []
    for x in nums:
        if len(heap) < k:
            heapq.heappush(heap, x)
        elif x > heap[0]:
            heapq.heapreplace(heap, x)
    return sorted(heap, reverse=True)
```

复杂度：遍历 `n` 个元素，每次堆操作 `O(log K)`，总时间 `O(n log K)`，空间 `O(K)`。

```python
import heapq

def merge_sorted_lists(lists):
    heap = []
    for i, arr in enumerate(lists):
        if arr:
            heapq.heappush(heap, (arr[0], i, 0))
    ans = []
    while heap:
        val, i, j = heapq.heappop(heap)
        ans.append(val)
        if j + 1 < len(lists[i]):
            heapq.heappush(heap, (lists[i][j + 1], i, j + 1))
    return ans
```

## 代表习题详解

### 1. 数组中的第 K 个最大元素

题意：给定未排序数组，返回第 K 大的元素，不是第 K 个不同元素。

思路：维护大小为 K 的小顶堆。扫描数组时，堆内始终保存目前最大的 K 个数；若新数大于堆顶，说明它能进入前 K，替换堆顶。扫描结束后，堆顶就是第 K 大。

复杂度：时间 `O(n log K)`，空间 `O(K)`。若用快速选择，平均时间可到 `O(n)`，但堆写法稳定且适合数据流。

易错点：重复元素要正常计数；不能先去重。K 从 1 开始，不是数组下标。

### 2. 前 K 个高频元素

题意：给定数组，返回出现频率最高的 K 个元素。

思路：先用哈希表统计频率，再对 `(freq, value)` 使用大小为 K 的小顶堆。堆顶表示当前 Top K 中频率最低的元素。遍历频率表，若新频率更大则替换堆顶。

复杂度：统计 `O(n)`，堆处理 `O(m log K)`，其中 `m` 是不同元素个数；空间 `O(m + K)`。

易错点：如果题目要求任意顺序，则不必排序结果；如果要求按频率降序，则最后对 K 个结果排序。

### 3. 合并 K 个升序链表

题意：给定 K 个升序链表，合并为一个升序链表。

思路：每条链表先把头节点入堆，堆中元素可以是 `(node.val, list_id, node)`，其中 `list_id` 用来避免值相同时节点对象无法比较。每次弹出最小节点，把它接入结果链表，再把该节点的下一个节点入堆。

复杂度：总节点数为 `N`，链表数为 `K`，时间 `O(N log K)`，空间 `O(K)`。

易错点：Python 堆中元组前几项相同时会继续比较下一项，不能直接比较自定义节点对象，应加入唯一序号。

### 4. 数据流中的中位数

题意：不断插入数字，并能快速返回当前中位数。

思路：使用双堆。左堆是大顶堆保存较小半部分，右堆是小顶堆保存较大半部分。插入后调整堆顶顺序和堆大小。若元素个数为奇数，中位数是元素更多一侧的堆顶；若为偶数，中位数是两个堆顶平均值。

复杂度：插入 `O(log n)`，查询中位数 `O(1)`，空间 `O(n)`。

易错点：需要同时维护“左侧所有元素 <= 右侧所有元素”和“两个堆大小差不超过 1”。

### 5. 最接近原点的 K 个点

题意：给定二维点，返回距离原点最近的 K 个点。

思路：距离平方 `x*x + y*y` 即可比较，不需要开方。维护大小为 K 的大顶堆，Python 中压入 `(-dist, x, y)`。若新点距离更小，则替换当前最远点。

复杂度：时间 `O(n log K)`，空间 `O(K)`。

易错点：不要用浮点开方造成额外开销；如果结果顺序不限，不必最后排序。

### 6. 会议室 II / 最少会议室数量

题意：给定若干会议开始和结束时间，求同时进行的最大会议数。

思路：按开始时间排序，维护一个小顶堆保存当前占用会议室的结束时间。遍历会议时，如果最早结束时间 `<= 当前开始时间`，说明可复用会议室，弹出；再压入当前结束时间。堆大小最大值就是需要的会议室数量。

复杂度：排序 `O(n log n)`，堆操作总 `O(n log n)`，空间 `O(n)`。

易错点：边界通常是结束时间等于开始时间可以复用，即条件为 `<=`。

## 常见错误

- 把 `heapq` 当成最大堆使用，忘记它默认是小顶堆。
- 求 Top K 大时维护了大顶堆，导致无法高效淘汰 Top K 中最小的元素。
- `heapify` 复杂度误写为 `O(n log n)`。

## 核心概念

### 1. 图的术语

- 顶点 `Vertex`：图中的节点。
- 边 `Edge`：顶点之间的连接。
- 无向图：边没有方向，`u-v` 表示两点互相可达。
- 有向图：边有方向，`u -> v` 只能从 u 到 v。
- 带权图：边有权重，常用于最短路径、最小生成树等问题。
- 连通分量：无向图中互相可达的一组顶点。
- 入度/出度：有向图中指向某点的边数、从某点指出的边数。

### 2. 图的表示

邻接矩阵：

- 用 `n x n` 矩阵表示边是否存在或边权。
- 查询任意两点是否相邻为 `O(1)`。
- 空间 `O(V^2)`，适合稠密图或频繁查边。

邻接表：

- 用 `dict/list/set` 记录每个顶点的邻居。
- 空间 `O(V + E)`，适合稀疏图。
- 遍历某点所有邻居很自然，是 BFS/DFS 最常用表示。

### 3. BFS

BFS 使用队列，按层扩展。它的关键性质是：在无权图中，从起点第一次到达某个节点时，得到的就是最短边数路径。

适合：最短步数、层序遍历、扩散问题、多源最短距离。

### 4. DFS

DFS 使用递归或栈，沿一条路径尽量深入，走不动再回退。

适合：连通分量、路径存在性、环检测、拓扑排序、岛屿面积、回溯搜索。

## 题型识别

优先考虑 BFS：

- 问“最少几步”“最近距离”“最短转换序列”。
- 状态空间每次一步扩展，边权相同。
- 多个源头同时扩散，如腐烂橘子、01 矩阵。
- 需要按层统计。

优先考虑 DFS：

- 问“是否存在路径”“所有连通块”“岛屿数量/面积”。
- 需要深入探索并回溯。
- 需要检测有向图环、生成拓扑序。
- 树或图的结构递归性很强。

需要额外算法的情况：

- 带非负权最短路径：Dijkstra。
- 有负权边：Bellman-Ford 或 SPFA 思想。
- 最小生成树：Kruskal 或 Prim。
- 所有点对最短路径：Floyd。

### 模板 2：BFS 遍历

```python
from collections import deque

def bfs(graph, start):
    visited = {start}
    q = deque([start])
    order = []
    while q:
        node = q.popleft()
        order.append(node)
        for nei in graph.get(node, []):
            if nei not in visited:
                visited.add(nei)      # 入队时标记，避免重复入队
                q.append(nei)
    return order
```

### 模板 3：无权图最短距离

```python
from collections import deque

def shortest_steps(graph, start, target):
    if start == target:
        return 0
    q = deque([(start, 0)])
    visited = {start}
    while q:
        node, dist = q.popleft()
        for nei in graph.get(node, []):
            if nei == target:
                return dist + 1
            if nei not in visited:
                visited.add(nei)
                q.append((nei, dist + 1))
    return -1
```

### 模板 4：DFS 递归

```python
def dfs(graph, start):
    visited = set()
    order = []

    def visit(node):
        visited.add(node)
        order.append(node)
        for nei in graph.get(node, []):
            if nei not in visited:
                visit(nei)

    visit(start)
    return order
```

```python
DIRS = [(1, 0), (-1, 0), (0, 1), (0, -1)]

def in_bounds(r, c, m, n):
    return 0 <= r < m and 0 <= c < n
```

## 代表习题详解

### 1. 岛屿数量

题意：二维网格中 `1` 表示陆地，`0` 表示水，求岛屿个数。

思路：遍历每个格子，遇到未访问陆地就启动一次 DFS 或 BFS，把同一岛屿的所有陆地标记掉，答案加一。每次启动搜索代表发现一个新的连通分量。

复杂度：每个格子最多访问一次，时间 `O(mn)`，空间为访问集合或递归栈 `O(mn)`。

易错点：访问标记必须在入队或进入递归时立即设置，否则相邻格子会重复加入。

### 2. 腐烂的橘子

题意：网格中腐烂橘子每分钟感染相邻新鲜橘子，求全部腐烂所需最短时间。

思路：多源 BFS。把所有初始腐烂橘子同时入队，按层扩散。每感染一层，时间加一。最后若还有新鲜橘子则返回 `-1`。

复杂度：时间 `O(mn)`，空间 `O(mn)`。

易错点：时间计数不要对每个节点加一，而是按层加；也可以在队列中存时间戳。

### 3. 单词接龙

题意：每次改变一个字母，从 `beginWord` 转换到 `endWord`，中间词必须在字典中，求最短转换长度。

思路：无权最短路，使用 BFS。节点是单词，边表示两个单词只差一个字符。朴素建图是 `O(n^2 * L)`，常用通配符模式如 `h*t` 建立中间桶，降低找邻居成本。

复杂度：取决于建图方式；BFS 本身是 `O(V + E)`。

易错点：第一次到达终点就是最短；应避免同一个单词重复入队。

### 4. 课程表

题意：给定课程依赖，判断能否完成所有课程。

思路一：Kahn BFS 拓扑排序。统计入度，先把入度为 0 的课程入队，每弹出一门课就删除它的出边并降低后继入度。若最终弹出课程数等于课程总数，则无环。

思路二：DFS 三色标记。`0` 未访问，`1` 访问中，`2` 已完成；DFS 中遇到 `1` 说明有环。

复杂度：时间 `O(V + E)`，空间 `O(V + E)`。

易错点：依赖方向要统一。若 `[a, b]` 表示学 a 前要学 b，则边为 `b -> a`。

### 5. 克隆图

题意：给定连通无向图的一个节点，返回深拷贝后的图。

思路：BFS 或 DFS 遍历原图，用哈希表 `old_node -> new_node` 记录已创建的克隆节点。遍历邻居时，若邻居未克隆则先创建，再把克隆邻居加入当前克隆节点的邻居列表。

复杂度：时间 `O(V + E)`，空间 `O(V)`。

易错点：不能只复制值，要复制节点关系；有环时必须用哈希表避免无限递归。

### 6. 太平洋大西洋水流问题

题意：矩阵高度表示地形，水可从高处流向低处或等高处，求能同时流到两个海洋的格子。

思路：反向搜索。从太平洋边界和大西洋边界分别做 DFS/BFS，反向规则为只能从低处走到高处或等高处。两个可达集合的交集就是答案。

复杂度：两个搜索各访问每个格子一次，时间 `O(mn)`，空间 `O(mn)`。

易错点：从每个格子正向搜索到海洋会重复很多；反向从边界出发更高效。

## 复杂度总结

| 表示/算法 | 时间复杂度 | 空间复杂度 | 适用场景 |
| --- | --- | --- | --- |
| 邻接矩阵 | 查边 `O(1)`，遍历邻居 `O(V)` | `O(V^2)` | 稠密图、频繁查边 |
| 邻接表 | 遍历全图 `O(V + E)` | `O(V + E)` | 稀疏图、遍历 |
| BFS | `O(V + E)` | `O(V)` | 无权最短路、层序扩散 |
| DFS | `O(V + E)` | `O(V)` | 连通性、环检测、路径搜索 |
| 网格 BFS/DFS | `O(mn)` | `O(mn)` | 岛屿、迷宫、扩散 |

## 常见错误

- 无向图建边只加了一个方向。
- BFS 在出队时才标记访问，导致同一节点重复入队。
- DFS 没有处理图中的环，递归无限进行。
- 网格题行列边界写反，或把 `m`、`n` 混用。
- 最短路问题用了 DFS，虽然能找到路径但不保证最短。
- 课程表依赖方向建反。
- 递归 DFS 在大图上可能超过递归深度，需要改成显式栈或设置递归限制。

- 图是有向还是无向？边是否带权？
- 节点数量和边数量规模如何，邻接表还是邻接矩阵更合适？
- 问的是最短步数还是任意可达？最短步数是否无权？
- 访问标记是在入队时设置还是出队时设置？
- 是否需要处理多个连通分量，而不是只从一个起点开始？
- 网格题是否明确四方向或八方向？边界是否统一封装？
- 若使用递归 DFS，最大深度是否可能爆栈？

## 核心概念

### 1. 分治三步骤

1. 分解：把原问题拆成若干规模更小的同类子问题。
2. 解决：递归求解子问题；当规模足够小时直接返回。
3. 合并：把子问题答案组合成原问题答案。

典型递归形式：

```python
def solve(l, r):
    if l == r:
        return base_answer
    mid = (l + r) // 2
    left = solve(l, mid)
    right = solve(mid + 1, r)
    return merge(left, right)
```

### 2. 与动态规划、回溯的区别

- 分治：子问题通常相互独立，关注拆分和合并，如归并排序。
- 动态规划：子问题有重叠，需要缓存或表格，如背包、编辑距离。
- 回溯：在决策树上试探选择并撤销，常用于组合、排列、棋盘搜索。

### 3. 复杂度递推

很多分治算法可写成：`T(n) = a * T(n / b) + f(n)`。

- 二分查找：`T(n) = T(n/2) + O(1)`，所以 `O(log n)`。
- 归并排序：`T(n) = 2T(n/2) + O(n)`，所以 `O(n log n)`。
- 快速排序平均：左右较均衡，`O(n log n)`；最坏退化为 `O(n^2)`。
- 汉诺塔：`T(n) = 2T(n-1) + O(1)`，所以 `O(2^n)`。

## 题型识别

适合分治的信号：

- 数据天然可以按区间、左右子树、前后部分拆开。
- 子问题和原问题形式相同，只是规模变小。
- 合并两个子问题答案比直接求解更容易。
- 题目中出现“有序数组”“第 K 个”“逆序对”“从遍历序列构造树”。
- 需要递归处理左右部分，如树的高度、平衡性、最近公共祖先等。

不适合直接分治的信号：

- 子问题大量重叠且重复计算明显，应考虑动态规划或记忆化。
- 子问题之间依赖强，无法独立求解。
- 只是在枚举所有选择，核心更像回溯。

```python
def divide(nums, left, right):
    if left == right:
        return nums[left]
    mid = (left + right) // 2
    left_ans = divide(nums, left, mid)
    right_ans = divide(nums, mid + 1, right)
```

```python
def merge_sort(nums):
    if len(nums) <= 1:
        return nums[:]
    mid = len(nums) // 2
    left = merge_sort(nums[:mid])
    right = merge_sort(nums[mid:])
    return merge(left, right)
```

```python
def quickselect(nums, k):
    # 返回升序下标 k 的元素
    left, right = 0, len(nums) - 1
    while True:
        p = partition(nums, left, right)
        if p == k:
            return nums[p]
        if p < k:
            left = p + 1
        else:
            right = p - 1
```

## 代表习题详解

### 1. 二分查找

题意：在升序数组中查找目标值，返回下标，不存在返回 `-1`。

思路：每次比较中点与目标，排除一半区间。递归写法体现分治；迭代写法更常见。关键是统一区间定义。如果使用闭区间 `[l, r]`，循环条件是 `l <= r`，右半区间更新为 `l = mid + 1`，左半区间更新为 `r = mid - 1`。

复杂度：时间 `O(log n)`，空间递归版 `O(log n)`，迭代版 `O(1)`。

易错点：边界更新不排除 `mid` 会死循环；求中点推荐 `l + (r-l)//2` 思想，虽然 Python 不会整型溢出。

### 2. 归并排序

题意：将数组排序。

思路：把数组分成左右两半，分别排序，再用双指针合并两个有序数组。归并排序稳定，最坏时间也是 `O(n log n)`。

复杂度：时间 `O(n log n)`，空间 `O(n)`。

易错点：合并阶段要把剩余元素全部加入；若想保持稳定，相等时优先取左边元素。

### 3. 快速排序

题意：原地排序数组。

思路：选取 pivot，通过 partition 把小于 pivot 的放左边，大于 pivot 的放右边，再递归排序左右区间。平均性能好，常数低，但 pivot 选择差时可能退化。

复杂度：平均 `O(n log n)`，最坏 `O(n^2)`；递归栈平均 `O(log n)`，最坏 `O(n)`。

易错点：大量重复元素时普通二路划分可能表现差，可用三路划分；递归边界要避免包含 pivot 本身。

### 4. 数组中的逆序对

题意：统计满足 `i < j` 且 `nums[i] > nums[j]` 的数对数量。

思路：在归并排序合并阶段计数。左右两半各自内部逆序对由递归解决；跨左右的逆序对在合并时统计。当左指针元素 `<=` 右指针元素，说明左指针当前元素不会与当前右元素构成逆序；当左元素 `>` 右元素，左半剩余元素都大于右元素，贡献 `len(left) - i`。

复杂度：时间 `O(n log n)`，空间 `O(n)`。

易错点：相等不算逆序对；计数发生在合并跨区间时，不能只看相邻元素。

### 5. 从前序与中序遍历构造二叉树

题意：给定二叉树前序和中序遍历，恢复二叉树。

思路：前序第一个元素是根；在中序中找到根的位置，左边是左子树，右边是右子树。根据左子树大小切分前序数组，递归构造左右子树。用哈希表记录中序值到下标，避免每次线性查找。

复杂度：每个节点处理一次，时间 `O(n)`，空间 `O(n)`。

易错点：前序和中序切片容易错位；若用切片实现会增加额外空间，面试中可用下标区间优化。

### 6. 最大子数组和

题意：求连续子数组的最大和。

思路：分治时答案有三种来源：完全在左半、完全在右半、跨越中点。左右答案递归求，跨中点答案通过从中点向左求最大后缀和、向右求最大前缀和并相加得到。

复杂度：时间 `O(n log n)`，递归栈 `O(log n)`。实际刷题常用 Kadane 算法 `O(n)`，但分治能体现结构。

易错点：全负数时不能把空数组当作和为 0 的候选，基础情况应返回单个元素。

## 复杂度总结

| 算法/问题 | 时间复杂度 | 空间复杂度 | 备注 |
| --- | --- | --- | --- |
| 二分查找 | `O(log n)` | `O(1)` 或递归 `O(log n)` | 有序数据 |
| 归并排序 | `O(n log n)` | `O(n)` | 稳定排序 |
| 快速排序 | 平均 `O(n log n)`，最坏 `O(n^2)` | 平均 `O(log n)` | 原地、不稳定 |
| 快速选择 | 平均 `O(n)`，最坏 `O(n^2)` | `O(1)` 或递归栈 | 第 K 小/大 |
| 逆序对 | `O(n log n)` | `O(n)` | 归并计数 |

## 常见错误

- 递归没有明确基本情况，导致无限递归。
- 区间定义混乱，闭区间和左闭右开混用。
- 合并阶段遗漏剩余元素。
- 快排 partition 后递归区间仍包含 pivot，导致死循环或栈溢出。
- 快速选择中 K 的语义混乱：第 K 大通常对应升序下标 `n-k`。
- 构造树时没有用哈希表查中序位置，退化为 `O(n^2)`。
- 忽略最坏复杂度，如快排在近乎有序数组上可能退化。

## 核心概念
回溯把一个问题拆成一棵决策树。树上每一层代表一次选择，路径代表当前部分解，叶子或满足条件的节点代表候选答案。

三件事最重要：
- 选择：枚举当前位置可以放什么、选哪个数、走哪个方向。
- 约束：判断当前选择是否合法，例如不能重复使用、不能越界、不能攻击。
- 撤销：递归返回前恢复现场，让同层下一个选择看到干净状态。

典型框架：

```python
def backtrack(state, choices):
    if is_solution(state):
        ans.append(record(state))
        return
    for choice in choices:
        if not valid(choice, state):
            continue
        make(choice, state)
        backtrack(state, next_choices)
        undo(choice, state)
```

## 题型识别
- 题目要求“所有方案”“所有排列”“所有组合”“所有路径”“所有可行布局”。
- 输入规模通常较小，例如 `n <= 10`、数组长度十几、棋盘不大。
- 需要在搜索过程中满足多个约束，局部不合法后可以马上放弃。
- 结果数量本身可能很大，不能只追求多项式算法。

常见分型：
- 子集型：每个元素选或不选。
- 组合型：从候选集中选若干个，通常用 `start` 保证不回头。
- 排列型：每个位置选择一个未使用元素，通常用 `used`。
- 棋盘型：按行或按格放置，使用列、对角线、行集合做 O(1) 合法性检查。
- 路径型：网格或图中 DFS，访问后标记，返回前撤销。

## 解题模板

### 子集 / 组合模板
```python
def combine(nums, target):
    nums.sort()
    ans, path = [], []

    def dfs(start, remain):
        if remain == 0:
            ans.append(path[:])
            return
        for i in range(start, len(nums)):
            if i > start and nums[i] == nums[i - 1]:
                continue
            if nums[i] > remain:
                break
            path.append(nums[i])
            dfs(i + 1, remain - nums[i])
            path.pop()

    dfs(0, target)
    return ans
```

### 排列模板
```python
def permute(nums):
    ans, path = [], []
    used = [False] * len(nums)

    def dfs():
        if len(path) == len(nums):
            ans.append(path[:])
            return
        for i, x in enumerate(nums):
            if used[i]:
                continue
            used[i] = True
            path.append(x)
            dfs()
            path.pop()
            used[i] = False

    dfs()
    return ans
```

### 去重口诀
同一层不要选重复值，不同层可以继续使用合规值。排序后常见判断是 `if i > start and nums[i] == nums[i - 1]: continue`。排列去重还要结合 `used[i - 1]` 判断同层重复。

## 代表习题

### 1. 全排列
给定互不相同的数组，返回所有排列。每一层填写一个位置，用 `used` 防止重复使用同一元素。路径长度等于 `n` 时记录答案。时间复杂度 `O(n * n!)`，因为有 `n!` 个排列且复制路径需要 `O(n)`；空间复杂度 `O(n)` 不含结果。

### 2. 含重复元素的全排列
数组可有重复值，要求结果不重复。先排序；同一层如果当前值等于前一个值，并且前一个值本轮还未使用，则跳过当前值，避免同一层生成相同分支。复杂度最坏仍是 `O(n * n!)`，但重复值会减少实际分支。

### 3. 组合总和 / 子集和
从数组中选择若干元素使和为目标。若每个元素只能用一次，递归传 `i + 1`；若可以重复使用，递归传 `i`。排序后当 `nums[i] > remain` 可以直接 `break`。复杂度通常指数级，剪枝对实际性能很关键。

### 4. 子集 II
返回含重复数组的所有不同子集。每层可以从 `start` 开始选择下一个元素；记录节点本身而非只记录叶子。排序后同层跳过重复元素。若数组长度为 `n`，无重复时结果数是 `2^n`。

### 5. N 皇后
在 `n x n` 棋盘放置 `n` 个皇后，使它们互不攻击。按行递归，每行选择一列。使用 `cols`、`diag1 = row - col`、`diag2 = row + col` 三个集合判断冲突。复杂度上界可看作 `O(n!)` 级搜索，空间复杂度 `O(n)` 不含答案。

### 6. 单词搜索
在网格中寻找一个单词路径。对每个起点做 DFS，四方向扩展，访问过的格子临时标记，返回前恢复。剪枝包括字符不匹配立即返回、剩余长度不足提前放弃。时间复杂度约 `O(mn * 3^L)`。

## 复杂度
- 排列：`O(n * n!)`。
- 子集：`O(n * 2^n)`。
- 组合：上界通常为指数级，具体取决于候选数量、目标和剪枝。
- 棋盘搜索：通常为指数级，若每层分支随约束快速减少，实际可接受。
- 递归栈：一般 `O(depth)`，结果集另计。

## 常见错误
- 忘记 `path[:]`，导致答案里全是同一个列表的最终状态。
- `append` 后忘记 `pop`，或标记后忘记取消标记。
- 组合问题没有传 `start`，导致重复排列式枚举。
- 去重条件放错层级，把合法答案剪掉。
- 只在叶子判断合法，错过中途剪枝，导致超时。
- 在 DFS 中修改共享结构，却没有保证异常分支也能恢复。

## 核心概念
动态规划适用于一个大问题可以由若干子问题答案组合而来，并且这些子问题会被反复访问的场景。核心不是套表，而是精确定义“状态”。

五步法：
- 状态：`dp[i]` 或 `dp[i][j]` 表示什么，必须一句话说清。
- 转移：最后一步发生了什么，如何从更小状态得到当前状态。
- 初始值：空集、起点、长度为 0 或容量为 0 时答案是什么。
- 遍历顺序：保证计算当前状态时依赖状态已经算过。
- 返回值：最后答案在哪个状态里。

## 题型识别
- 题目问最值、计数、可行性，并且选择顺序影响后续状态。
- 暴力递归中同一个 `(i, j, capacity...)` 会反复出现。
- 局部贪心难以证明，每一步选择可能影响未来。
- 约束规模让指数搜索不可接受，但 `n * m`、`n * target` 可接受。

常见分型：
- 线性 DP：爬楼梯、打家劫舍、最大子数组和。
- 路径 DP：网格最小路径和、不同路径。
- 背包 DP：0-1 背包、完全背包、组合计数。
- 序列 DP：最长递增子序列、最长公共子序列、编辑距离。
- 区间 DP：合并石子、戳气球，通常按区间长度枚举。

## 解题模板

### 一维线性 DP
```python
dp = [0] * n
dp[0] = base
for i in range(1, n):
    dp[i] = transition(dp, i)
return dp[-1]
```

### 二维序列 DP
```python
dp = [[0] * (m + 1) for _ in range(n + 1)]
for i in range(1, n + 1):
    for j in range(1, m + 1):
        if a[i - 1] == b[j - 1]:
            dp[i][j] = dp[i - 1][j - 1] + 1
        else:
            dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
return dp[n][m]
```

### 0-1 背包一维优化
```python
dp = [0] * (capacity + 1)
for w, v in items:
    for c in range(capacity, w - 1, -1):
        dp[c] = max(dp[c], dp[c - w] + v)
```

0-1 背包容量倒序，防止同一个物品被重复使用；完全背包容量正序，允许当前物品继续参与后续状态。

## 代表习题

### 1. 爬楼梯
一次走 1 或 2 阶，问到第 `n` 阶有多少走法。定义 `dp[i]` 为到第 `i` 阶的走法，转移 `dp[i] = dp[i - 1] + dp[i - 2]`。可用两个变量滚动优化到 `O(1)` 空间。时间 `O(n)`。

### 2. 最小路径和
网格只能向右或向下走。定义 `dp[i][j]` 为到达 `(i, j)` 的最小路径和，来自上方或左方：`grid[i][j] + min(dp[i-1][j], dp[i][j-1])`。注意第一行和第一列只有一个来源。时间 `O(mn)`，空间可优化为 `O(n)`。

### 3. 0-1 背包
每个物品最多选一次，容量有限，最大化价值。二维定义 `dp[i][c]` 为前 `i` 个物品在容量 `c` 下的最大价值；一维优化时容量必须倒序。时间 `O(nC)`，空间 `O(C)`。

### 4. 完全背包 / 零钱兑换 II
每种硬币可无限使用，问凑成金额的组合数。外层枚举硬币、内层金额正序，可以避免不同顺序被重复计数。若问排列数，循环顺序通常改为外层金额、内层硬币。

### 5. 编辑距离
给两个字符串，允许插入、删除、替换，求最少操作数。`dp[i][j]` 表示把 `word1[:i]` 变成 `word2[:j]` 的最小操作数。字符相同则继承 `dp[i-1][j-1]`；不同则取插入、删除、替换三者最小加一。时间 `O(nm)`。

### 6. 最长递增子序列
`dp[i]` 表示以 `nums[i]` 结尾的最长递增子序列长度，枚举 `j < i` 且 `nums[j] < nums[i]`。时间 `O(n^2)`。也可以用贪心加二分维护每个长度的最小结尾，优化到 `O(n log n)`。

## 复杂度
- 线性 DP：通常 `O(n)` 时间，`O(n)` 或 `O(1)` 空间。
- 二维 DP：通常 `O(nm)` 时间和空间，可滚动优化。
- 背包：`O(nC)`，其中 `C` 是容量或目标和，不是输入位数意义上的多项式。
- 区间 DP：常见 `O(n^3)` 时间、`O(n^2)` 空间。

## 常见错误
- 状态定义含糊，导致转移式写不出来。
- 初始值没有覆盖空串、容量 0、第一行第一列。
- 0-1 背包一维优化时容量正序，误把物品用多次。
- 组合数和排列数循环顺序混淆。
- 用 `0` 初始化不可达状态，导致不可达被当成合法答案。
- 滚动数组覆盖了还没使用的旧状态。

## 复盘清单
- `dp` 的每个维度分别代表什么？
- 当前状态依赖哪些更小状态？遍历顺序满足依赖吗？
- 初始状态是否足以推出所有状态？
- 题目问的是最值、计数、可行性，还是具体方案？
- 是否需要把不可达初始化为正无穷或负无穷？
- 一维优化后，循环方向是否正确？
- 返回的是 `dp[-1]`、`max(dp)` 还是某个二维角落？

## 核心概念
贪心不是“看起来选最大的/最小的”，而是需要证明某个局部策略不会让未来变差。常用证明：
- 交换论证：任意最优解若不包含贪心选择，可交换成包含它且不变差的解。
- 反证法：假设贪心选择不能得到最优，推出矛盾。
- 前缀最优：排序后逐步维护前缀最优，后续选择只依赖当前摘要信息。
- 单调性：随着某个参数变化，最优选择方向单调。

## 题型识别
- 每一步选择后问题规模变小，且选择不会需要回头修改。
- 题目中出现最少数量、最多可安排、最大收益、最小代价、字典序最小等。
- 有自然排序关键字，如结束时间、起点、价值密度、截止时间、身高。
- 可以证明“当前最早结束”“当前最小代价”“当前最大收益”一定安全。

不宜贸然贪心的信号：
- 局部选择会强烈影响未来组合，且没有交换证明。
- 题目问所有方案或方案数，通常不是纯贪心。
- 存在容量和离散选择时，0-1 背包不能用价值密度贪心保证最优。

## 代表习题

### 1. 分数背包
每个物品可拆分，按价值密度 `value / weight` 从高到低选择。因为可拆分，若一个最优解先装了低密度物品，可以用高密度物品替换同等重量并不降低价值。排序时间 `O(n log n)`。

### 2. 区间调度
选择最多互不重叠区间。按结束时间升序排序，每次选结束最早且与已选区间不冲突的区间。结束越早，给后续留下的空间越大；交换论证可证明安全。时间 `O(n log n)`。

### 3. 合并区间
按起点排序，维护当前合并区间 `[l, r]`。若下一个区间起点不超过 `r`，更新右端点；否则输出当前区间并开启新区间。时间 `O(n log n)`，空间取决于输出。

### 4. 跳跃游戏
给定每个位置最大跳跃长度，判断能否到达末尾。维护当前可到达最远位置 `farthest`，遍历到超过 `farthest` 的位置说明不可达。每一步只保留最有用的摘要信息。时间 `O(n)`。

### 5. 加油站
总油量若小于总消耗必不可能。否则从左到右扫描，若当前累计油量变负，说明从当前起点到此处任一点都不能作为起点，于是把起点设为下一个位置。时间 `O(n)`。

### 6. 任务调度 / 最小会议室
按开始时间排序会议，用小根堆维护当前会议结束时间。新会议开始前，弹出所有已结束会议；堆大小即当前并发数，最大堆大小是所需会议室数。时间 `O(n log n)`。

## 复杂度
- 排序贪心：通常 `O(n log n)`。
- 单次扫描贪心：通常 `O(n)`。
- 堆贪心：每个元素入堆出堆一次，`O(n log n)`。
- 双指针贪心：通常 `O(n)`。

## 常见错误
- 只凭直觉选局部最优，没有证明。
- 排序关键字错，例如区间调度按开始时间排序会失败。
- 对相同关键字没有处理 tie-breaker，导致构造类题目出错。
- 把分数背包策略套到 0-1 背包。
- 维护堆时忘记弹出过期元素。
- 跳跃游戏中遍历到不可达位置仍继续更新答案。

- 能否用交换论证说明选它不亏？
- 排序关键字是什么，升序还是降序？

## 核心概念

### 并查集
并查集维护若干不相交集合，支持：
- `find(x)`：找到元素所属集合代表元。
- `union(a, b)`：合并两个集合。
- `connected(a, b)`：判断两元素是否在同一集合。

路径压缩让查询沿途节点直接指向根；按大小或秩合并让小树挂到大树下。二者结合后，均摊复杂度近似 `O(1)`。

### Trie
Trie 是按字符逐层展开的树。根到某节点路径代表一个前缀，节点上通常保存：
- `children`：字符到子节点的映射。
- `end` 或 `word_count`：是否有单词在此结束。
- `prefix_count`：经过此节点的单词数量，可支持删除和前缀计数。

### 单调结构
单调栈/队列维护一个按值单调的候选集合。新元素进入时，把已经不可能成为答案的旧元素弹出；每个元素最多入栈入队一次、出栈出队一次，所以整体线性。

## 解题模板

### 并查集
```python
class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.size = [1] * n
        self.count = n

    def find(self, x):
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]
            x = self.parent[x]
        return x

    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra == rb:
            return False
        if self.size[ra] < self.size[rb]:
            ra, rb = rb, ra
        self.parent[rb] = ra
        self.size[ra] += self.size[rb]
        self.count -= 1
        return True
```

### Trie
```python
class Trie:
    def __init__(self):
        self.root = {}

    def insert(self, word):
        node = self.root
        for ch in word:
            node = node.setdefault(ch, {})
        node["#"] = True

    def search(self, word):
        node = self.root
        for ch in word:
            if ch not in node:
                return False
            node = node[ch]
        return "#" in node
```

## 代表习题

### 1. 省份数量
给定城市连通矩阵，求连通分量个数。遍历矩阵上三角，若 `isConnected[i][j] == 1` 则合并。最后并查集中的集合数量即省份数。时间 `O(n^2 * alpha(n))`，空间 `O(n)`。

### 2. 冗余连接
无向图中边逐条加入，找第一条使图成环的边。若一条边两端点已经连通，再加入就会形成环；否则合并。时间近似 `O(E)`。

### 3. 实现 Trie
支持 `insert`、`search`、`startsWith`。每个操作复杂度 `O(L)`，其中 `L` 是单词长度。若要删除，需要维护经过节点的计数，删除时递减并清理无用节点。

### 4. 最大异或
把数字按二进制位插入 Trie。查询某个数时，每一位优先走相反位，使异或结果该位为 1。若数值位数固定为 31 位，插入和查询都是 `O(31)`，整体 `O(n)`。

### 5. 每日温度
求每一天后面还要等几天才有更高温。维护递减栈，栈内存放尚未找到更高温的日期下标。遇到更高温时不断弹栈并填答案。时间 `O(n)`。

### 6. 滑动窗口最大值
维护下标双端队列，队首是当前窗口最大值下标。新元素进入前弹出过期下标；再从队尾弹出不大于新值的下标。每个元素最多进出一次，时间 `O(n)`。

### 7. 柱状图最大矩形
维护递增栈。当遇到更低柱子时，弹出的柱子高度确定了右边界，新的栈顶确定左边界。为统一处理，可在首尾加高度 0 的哨兵。时间 `O(n)`。

## 复杂度
- 并查集：`find/union` 均摊 `O(alpha(n))`，可近似看作常数。
- Trie：插入、查询、前缀判断 `O(L)`，空间为所有字符串总字符数。
- 单调栈：`O(n)` 时间、`O(n)` 空间。
- 单调队列：`O(n)` 时间、`O(k)` 到 `O(n)` 空间。

## 常见错误
- 并查集 `union` 后忘记减少连通分量数量。
- `find` 没有压缩路径，数据大时退化。
- 合并时没有先找根，直接改父节点导致集合结构错乱。
- Trie 把前缀存在当成完整单词存在，忘记终止标记。
- 单调队列存值不存下标，无法判断元素是否过期。
- 单调栈比较符号写错，重复元素处理不符合题意。
- 柱状图问题忘记哨兵，最后栈内柱子没有结算。

## 复盘清单
- 这个问题只问连通性，还是需要具体路径？
- 并查集初始化时集合数量是否正确？
- Trie 节点是否区分“经过”和“单词结束”？
- 单调结构维护的是递增还是递减？
- 栈/队列里存下标还是值？是否需要判断过期？
- 遇到相等元素时应该保留旧元素还是新元素？
- 每个元素是否最多入结构一次、出结构一次？
