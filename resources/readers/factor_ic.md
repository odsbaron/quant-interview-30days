# 因子研究与 IC 测试 — 向量化方法详解

> 适用场景：在大量股票/品种上快速筛选 alpha 信号、评估单因子有效性、组合多因子。
> 工具栈：pandas / numpy / vectorbt / Numba / Alphalens (deprecated 但思想常用)。
> 不适用：日内、限价单、撮合细节敏感的策略 → 用事件驱动。

## 一句话总览

> **因子研究 = 把"想法"变成"数字序列"，证明它和"未来收益"有稳定相关性，然后用向量化回测在几秒内验证。**

向量化的本质是**把所有股票×所有日期的回测压成一次矩阵运算**。N 个股票 × T 天的因子 → N×T 矩阵；同样形状的未来收益矩阵 → 两个矩阵按列（每天）算相关系数 → 得到 T 个 IC 值 → 评估其均值/稳定性。

整个流程不需要 for-loop、不需要事件队列、不需要订单状态机，所以**百万级数据点秒级出结果**，是单因子筛选阶段的唯一选择。
