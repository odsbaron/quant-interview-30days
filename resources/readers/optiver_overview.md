# 2026 Optiver 三类测评知识点总览

整理时间：2026-06-05

> 说明：
> - `Beat The Odds` 的知识点大多已被现有概率笔记验证。
> - `NumberLogic` 与 `Zap-N` 的部分知识点，来自 `future/` 中题面、OCR 与录屏关键帧推断，不保证与官方说明完全一致，但足够用于复习准备。

## 1. Beat The Odds：概率建模与估算

### 1.1 这类题到底在考什么

`Beat The Odds` 不是长推导数学题，而是：

1. 把题面快速翻译成标准概率模型；
2. 用最短路径算出近似值；
3. 选出最接近答案。

它考的不是“你会不会复杂证明”，而是：

- 能不能在 `60-90` 秒内完成题型识别；
- 能不能区分 `概率`、`期望`、`风险`；
- 能不能在不完全精算的情况下做正确判断。

### 1.2 最基础的知识点

#### 1. 等可能样本空间

典型题：

- 一次掷骰子，出现 `5` 或 `6` 的概率；
- 连续抛硬币，全部相同的概率。

核心动作：

- 先数总状态数；
- 再数满足条件的状态数；
- 用 `favorable / total`。

你必须熟练：

- 骰子 `6` 面等可能；
- 硬币 `2^n` 个等可能序列；
- 小样本问题可以直接枚举。

#### 2. 对称性与交换性

典型题：

- 多个骰子点数和是偶数的概率；
- 扔掉牌堆前 `10` 张后，新顶牌是红牌的概率。

核心直觉：

- 如果结构本身对称，很多题不用硬算；
- 例如公平骰子的奇偶是平衡的，和的奇偶也常常直接是 `1/2`；
- 洗匀牌后“下一张是红牌”通常仍由对称性决定。

这类题考的是：

- 你能不能看出“不变量”；
- 能不能少算很多无意义状态。

### 1.3 重复试验类知识点

#### 3. Binomial 模型

典型信号：

- 连续抛很多次硬币；
- 问至少几次成功、恰好几次成功；
- 每次试验独立，成功率固定。

核心公式：

`P(X=k)=C(n,k)p^k(1-p)^{n-k}`

重点不是背公式本身，而是能快速识别：

- 这是不是独立重复试验；
- 成功条件是不是“至少/至多/恰好”；
- 是否可以直接转成 `binomial tail`。

#### 4. Conditional Binomial

典型题：

- `coin race` 里第一下已经知道是 `Tails`；
- 然后问最后 `Heads` 是否会领先。

关键知识点：

- 条件一旦给定，样本空间已经变了；
- 不能用无条件分布直接套；
- 要把已知条件固定，再看剩余试验。

常见错误：

- 忽略 `first`、`given`、`if ... first`；
- 直接把 `10` 次 coin toss 当作完全对称问题。

### 1.4 路径与边界类知识点

#### 5. Random Walk

典型题：

- 从 `U` 走到 `H`，每步前进或后退；
- 题里同时给了距离、边界、时间限制。

核心知识点：

- 状态会随着每一步变化；
- 你要先把“时间限制”翻译成“最多允许多少步”；
- 再判断哪些路径能到达终点。

你需要熟悉的概念：

- 前进/后退路径；
- 反射边界；
- 吸收边界；
- 最短路径；
- 带约束的路径计数。

#### 6. Gambler's Ruin

这是 Optiver 概率里最重要的一簇。

典型信号：

- `bankroll`
- `target wealth`
- `bankrupt`
- 一次赢 `+1`，输 `-1`

本质：

- 资金变化是一维随机游走；
- `0` 和目标资金是两个边界；
- 问的是“先碰上边界还是下边界”。

你必须掌握：

- 公平情形：`P_i = i/N`
- 非公平情形：`P_i = (1-(q/p)^i)/(1-(q/p)^N)`

不仅要会算，还要会解释：

- 为什么公平时概率和起点位置成线性关系；
- 为什么 biased 情况不能再用 `i/N`。

### 1.5 计数、重叠与等待时间

#### 7. Inclusion-Exclusion

典型题：

- 三场比赛中，任意连续两场赢就获奖；
- 两个成功事件可能同时发生。

核心公式：

`P(A∪B)=P(A)+P(B)-P(A∩B)`

你需要真正理解的是：

- 不是所有“加起来”都能直接相加；
- 一旦两个事件有重叠，必须减掉交集。

#### 8. Coupon Collector

典型题：

- 骰子平均要掷多少次，六个面都至少出现一次。

核心思想：

- 不是一次算完；
- 要拆成阶段：
  - 第一个新面很容易拿到；
  - 最后一个新面最难拿到。

必须掌握：

- `E[T]=nH_n`
- 每一阶段都可以看成 geometric waiting time；
- 期望可以分阶段相加。

这类题真正考的是：

- 你会不会把“等待直到全部出现”拆成多个小等待。

#### 9. Occupancy / Balls into Boxes

`future` 里已经看到了：

- `61 coins are randomly put into 15 boxes. If any box contains more than 4 coins, what is the probability that you win?`

这类题对应的知识点是：

- 球放盒模型；
- 补事件思维；
- pigeonhole principle 直觉；
- 小样本时可能用计数，大样本时更看估算能力。

真正考的不是完整组合推导，而是：

- 先判断事件是不是“几乎必然”；
- 能不能快速建立上界/下界直觉。

### 1.6 EV、风险与交易直觉

#### 10. Expected Value

典型题：

- 公平游戏长期值多少；
- 不同路径收益不同，问平均收益。

核心动作：

- 列出每种 payoff；
- 用 `payoff × probability` 加总。

必须分清：

- 高概率赚钱；
- 正期望赚钱；
- 低尾部风险；

这三件事不是一回事。

#### 11. Martingale

这是 Optiver 非常喜欢考的风险直觉题。

典型结构：

- 输了加倍下注；
- 大多数时候小赚；
- 少数时候爆仓。

核心知识点：

- `high win rate != positive EV`
- 有限资金会制造尾部大亏；
- 公平游戏里，停止策略不会凭空创造正期望。

这类题其实更接近交易风险教育：

- 不要被高胜率迷惑；
- 要看收益分布；
- 要看尾部损失有多大。

#### 12. Closest Answer / Estimation

这其实也是一个知识点。

因为 `Beat The Odds` 明确允许“选最接近答案”，所以你必须学会：

- 接受近似值；
- 不为多一位小数浪费时间；
- 先估数量级，再选答案。

真正高分的人不是算得最精，而是：

- 分类最快；
- 近似最稳；
- 跳题最果断。

## 2. NumberLogic：高速数列与模式识别

### 2.1 这类题到底在考什么

`NumberLogic` 本质不是高深数学，而是：

- 快速发现数值变化模式；
- 用尽量少的计算锁定下一个数；
- 在时间压力下避免钻牛角尖。

它考的是：

- pattern recognition；
- 心算速度；
- 工作记忆；
- 错误排除；
- 跳题策略。

### 2.2 最核心的数列知识点

#### 1. 一阶差分

先看：

`a_{n+1} - a_n`

这是第一反应。

如果差值固定，通常就是等差数列。
如果差值本身有规律，则继续看二阶差分。

#### 2. 二阶差分

当原数列差值不是常数时，再看“差分的差分”。

常见于：

- 二次增长；
- 加的数越来越大；
- `+2,+4,+6,+8` 这种模式。

#### 3. 比率 / 倍率

如果数字涨得快，优先检查：

- `×2`
- `×3`
- `×1/2`
- `×2 + c`
- `×3 - c`

很多题不是纯等比，而是“先乘后加减”。

#### 4. 交替运算

这是 NumberLogic 高频题型。

例如：

- `+2, ×2, +2, ×2`
- `÷2, ×3, ÷2, ×3`

你看到序列跳动忽大忽小时，第一反应要不是复杂递推，而是“交替规则”。

#### 5. 奇偶位拆分

很多表面混乱的数列，其实是两条子序列交织：

- 奇数位一条规律；
- 偶数位另一条规律。

这是 NumberLogic 最值得优先检查的套路之一。

#### 6. 分组规律

有些题不是逐项变化，而是：

- 两个一组；
- 三个一组；
- 前半段生成后半段。

例如：

- 一组里先乘，下一组里再平移；
- 每三项内部有局部关系。

#### 7. 递推关系

常见形式：

- `a_n = a_{n-1} + a_{n-2}`
- `a_n = 2a_{n-1} - a_{n-2}`
- `a_n = a_{n-1} + f(n)`

这类题不一定是标准 Fibonacci，但常常是其变体。

#### 8. 幂与特殊数

要敏感识别：

- 平方：`1,4,9,16`
- 立方：`1,8,27,64`
- 三角数：`1,3,6,10,15`
- 阶乘或双阶乘变体；
- 质数、合数、因数个数变化。

#### 9. 符号与方向变化

如果序列里有负数，重点看：

- 正负交替；
- 差值越来越负；
- 绝对值是否有自己的规律。

像 `12,10,7,2,-5,-16` 这种，就非常像“差值自身有递减规律”。

#### 10. 拆位与数位规律

有些题会用：

- 各位数字和；
- 各位数字积；
- 数字反转；
- 拼接；
- 乘积和拆位混合。

OCR 很容易把这类题看坏，所以做题时也要对“数位规则”保持敏感。

### 2.3 NumberLogic 真正考的能力点

#### 11. 最小计算路径

你不是要证明唯一规律，而是要在选项里找最合理规律。

所以要优先选：

- 最简单；
- 最局部；
- 最稳定；
- 最符合前几项变化节奏；

而不是最花哨的解释。

#### 12. 速度与跳题

这类题非常讲究止损。

如果你在 `20-30` 秒内没有明显方向：

- 不要继续深挖；
- 先跳；
- 保证整体得分。

#### 13. 错误排除

有选项时，可以反过来试：

- 哪个选项让差分最顺；
- 哪个选项让交替规律闭合；
- 哪个选项让奇偶位分别成立。

这比从零硬推更快。

### 2.4 你应该形成的固定检查顺序

面对任何 NumberLogic 题，脑内固定成：

`差分 -> 二阶差分 -> 倍率 -> 奇偶位 -> 交替 -> 分组 -> 递推 -> 幂/数位`

谁先形成这条肌肉记忆，谁在正式测试里就更稳。

## 3. Zap-N：游戏化认知测评

### 3.1 这类题到底在考什么

`Zap-N` 不是知识问答，也不是数学卷子。

它更像一组小游戏，用来测：

- 规则学习速度；
- 工作记忆；
- 视觉模式识别；
- 注意力稳定性；
- 风险偏好；
- 速度准确率平衡；
- 多任务切换。

所以这里的“知识点”更准确地说，是：

- 任务机制；
- 能力点；
- 操作原则。

### 3.2 从当前录屏推断出的子任务知识点

#### 1. Trading Indicator

关键帧中出现了：

- `When the needle of the trading indicator is in the grey, you don't want to buy the stock.`

这类任务的知识点不是金融公式，而是：

- 阈值规则识别；
- 根据信号位置做二元决策；
- 快速抑制错误点击。

考的是：

- 你是否能稳定执行简单规则；
- 在节奏变快后是否还会误触。

#### 2. Balloon Risk Task

关键帧中出现了：

- `PUMP`
- `TAKE CASH`
- 当前 reward 和 total

这类任务典型对应：

- 风险收益权衡；
- 逐步加码决策；
- 止盈纪律。

它考的不是你会不会算 EV 公式，而是：

- 你能不能在不确定爆炸点前控制贪婪；
- 你的风险偏好是否稳定；
- 连续成功后是否会失控加仓。

#### 3. Building / Pattern Reconstruction

关键帧里有楼层样例和 A/B/C 选项。

这类任务的知识点包括：

- 局部规则复制；
- 顺序记忆；
- 多属性映射；
- 样例到目标的迁移。

考的是：

- 你能不能快速读懂规则；
- 能不能在视觉信息较多时保持正确重建。

#### 4. Shape / Color / Pattern Verification

关键帧里出现了：

- `Previous created figures`
- `Shape / Color / Pattern`
- `VERIFY`

这明显是多属性记忆核验。

核心知识点：

- shape
- color
- pattern
- 多属性绑定
- 延迟回忆

真正考的是：

- 你不是记住一个图，而是记住“图形 + 颜色 + 纹理”的组合。

#### 5. YES / NO Quick Decision

关键帧里能看到：

- 算式判断；
- 箭头序列是否一致；
- `Press NO` 等即时提示。

这类任务的知识点包括：

- 快速布尔判断；
- 反应抑制；
- 规则切换；
- 同时处理多个局部信息。

考的是：

- 你能不能在高速度下保持低错误率；
- 能不能在 “YES” 和 “NO” 之间稳定切换。

### 3.3 Zap-N 对应的底层能力点

#### 6. Rule Acquisition

每个小游戏上来都会给一个很短的 instruction。

第一能力不是答题，而是：

- 在几秒内吃透规则。

如果规则没完全理解，后面速度越快，错得越多。

#### 7. Working Memory

尤其在图形记忆、模式核验、顺序重建类任务里，你需要短时间内保留多个信息块。

#### 8. Attention Control

这类测评通常会通过重复和高节奏让人走神。

一旦注意力漂移：

- 会漏掉条件；
- 会误触；
- 会把上一个任务规则带到下一个任务。

#### 9. Inhibitory Control

很多任务都在测“能不能忍住第一反应”。

比如：

- 不该买的时候别点 buy；
- 提示你按 `NO` 时不要被界面别的刺激带偏；
- 图形相似但不完全相同时不要误判为对。

#### 10. Speed-Accuracy Tradeoff

Zap-N 的关键不在于疯狂提速，而在于：

- 在足够快的前提下，把错误率压住。

高速度但高错误，未必比中速稳定更好。

#### 11. Task Switching

不同小游戏之间规则变化很快。

你需要做到：

- 当前任务只用当前规则；
- 任务切换时把上一套规则“清空”。

#### 12. Risk Preference Stability

尤其在气球类、加码类任务中，系统可能不只看平均分，还看你的行为稳定性。

它想知道：

- 你是不是被连续成功冲昏头；
- 你是不是每轮都极端保守或极端激进；
- 你的风险取向是否可预测。

### 3.4 Zap-N 的复习重点

这类任务没有一套公式表能背完，所以复习重点应是：

1. 先读懂规则，再求速度；
2. 对每个小游戏先建立一个稳定决策原则；
3. 尽量压低低级失误；
4. 防止疲劳后规则漂移；
5. 避免被连续成功或连续失败改变操作风格。

## 4. 三类测评共同的元知识点

### 4.1 读题关键词识别

无论哪一类，都要对关键词非常敏感：

- `first`
- `until`
- `before`
- `at least`
- `average`
- `bankrupt`
- `target`
- `same`
- `different`

这些词通常直接决定模型。

### 4.2 时间管理

三类题都不是“慢慢做就能高分”的类型。

必须接受：

- 有些题要快速拿下；
- 有些题要快速放弃；
- 总分比单题执念重要。

### 4.3 稳定性胜过炫技

Optiver 这类测评并不奖励花哨解法，它更像在看：

- 你是否能在时间压力下保持稳定判断；
- 你是否能区分机会和噪音；
- 你是否会在高压下变形。

## 5. 最重要的复习顺序

如果从备考收益最大化出发：

1. 先把 `Beat The Odds` 的概率模型全部打熟；
2. 再把 `NumberLogic` 的固定检查顺序练成反射；
3. 最后单独针对 `Zap-N` 做任务机制和状态管理训练。

因为：

- `Beat The Odds` 最标准，最容易通过题型训练提分；
- `NumberLogic` 是你当前资料库的主要空白；
- `Zap-N` 更依赖任务熟悉度和稳定执行，不是纯知识背诵能解决的。
