# Day 25—28：一个最小回测练习

目标是把时间顺序、收益计算、交易成本和保留样本串起来。只有一个标的、80 个合成价格观察点，练习总预算为四天各 60 分钟。

## 输入

[synthetic_prices.csv](../data/synthetic_prices.csv) 包含 `date,close`。价格由确定性公式生成，日期只是观察点标签，包含连续日历日，不对应真实交易日或真实资产。前 60 行用于开发，后 20 行保留；后 20 行不能用于选择参数。

起步程序：[mini_project.py](../mini_project.py)。先运行：

```bash
python3 exercises/mini_project.py
```

## 明确时间顺序

只使用收盘数据，约定：

1. 在第 `t-1` 个观察点收盘后，根据 `prices[:t]` 生成信号。
2. 在第 `t` 个观察点收盘执行，持仓为 `positions[t]`。
3. 获得第 `t` 到 `t+1` 个观察点的价格收益。

因此 `positions[t]` 不能读取 `prices[t]` 或后续价格。若过去不足 `lookback` 个观察点，持仓为 0。否则比较 `prices[t-1]` 与最近 `lookback` 个已知价格的平均值：严格大于时持仓 1，否则为 0。

这是教学执行约定，忽略盘中交易、实际排队、停牌、冲击和涨跌停等真实问题。不要把它用于声称实盘可达收益。

## 收益与成本

第 `t` 个持有区间的净收益定义为：

```text
asset_return[t] = prices[t+1] / prices[t] - 1
turnover[t] = abs(positions[t] - positions[t-1])
net_return[t] = positions[t] * asset_return[t] - turnover[t] * cost_bps / 10000
```

初始 `positions[-1]` 在这条公式中约定为 0，不能直接读 Python 列表的最后一项。单边成本分别用 0、5、10 bps；净值逐期按 `wealth *= 1 + net_return` 复利。输出 `N-1` 个区间收益，最后一个价格处不强制平仓、不额外计算末尾平仓费；报告中注明这一点。
