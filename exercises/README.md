# 起步练习

Day 01 提供一份可运行的 Python 起步模板，只依赖标准库。先独立推导和编码，再使用检查器；初始文件没有填写答案。

每天 60 分钟统一分配为 **5 / 10 / 35 / 10**：

| 时间 | Day 01 要做的事 |
| --- | --- |
| 5 分钟 | 快速确认期望定义、数组索引与“两个位置必须不同”的约束。 |
| 10 分钟 | 阅读题面，写出公平骰子每个结果的概率及期望表达式；梳理两数之和的输入和输出。 |
| 35 分钟 | 完成两个 TODO；建议骰子推导及模拟 10 分钟，两数之和与变式 25 分钟。 |
| 10 分钟 | 检查实现，记录错误、独立程度和一句口述，安排 48 小时后的重做。 |

从仓库根目录运行：

```bash
python3 exercises/day01.py
```

这条命令只打印题面和使用方法，退出码为 0，不调用待填写函数，也不会写入学习进度。

完成 `expected_die_value` 和 `two_sum` 后运行：

```bash
python3 exercises/day01.py --check
```

**初始 TODO 抛出 `NotImplementedError`、检查退出码为 1，是尚未作答的预期表现。** 写完以后，检查器会验证理论期望、重复元素、负数、多解、无解、空数组，以及不能复用同一索引。检查通过仅表示这些测试样例通过，独立程度需要在每日笔记中如实记录。

`two_sum` 有解时返回含两个索引的 tuple 或 list，可以任意顺序，也可以返回任意一组有效解。无解时返回 `None`。返回的索引必须对应原始输入，不能直接返回元素值。

在完成理论推导后，用固定种子的模拟做比较：

```bash
python3 exercises/day01.py --simulate
```

模拟使用 `random.Random(42)` 生成 10,000 次投掷，规模足够小且可复现。模拟均值是一个样本结果，不是理论期望的证明；相同种子得到相同结果也不代表推导正确。默认命令不执行模拟。

<details>
<summary>提示 A：公平骰子的理论期望（独立尝试后再展开）</summary>

列出随机变量的所有取值及对应概率，检查概率之和为 1，再按“取值乘概率后求和”的定义计算。公平骰子的六个取值具有相同概率。不要把模拟得到的浮点均值作为本题的理论返回值。

</details>

<details>
<summary>提示 B：两数之和（独立尝试后再展开）</summary>

先考虑枚举两个不同下标的暴力方法，解释时间复杂度。随后思考：扫描到一个数时，怎样快速知道与它配对的另一个值是否已经出现？记录的应当包含索引信息。重复值可以来自不同位置，不能让当前元素与自身配对。

</details>
